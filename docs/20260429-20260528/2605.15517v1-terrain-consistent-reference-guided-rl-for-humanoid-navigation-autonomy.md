## 摘要
我们提出了一种方法，用于训练人形机器人的参考引导、感知强化学习行走策略，其中参考轨迹在训练中被调制以与地形几何一致。为了将我们的方法与标准导航自主基础设施部署，我们在强化学习训练循环内合成SE(2)可控参考轨迹，将期望的落脚点投影到有效立足点上，并调整摆动脚和质心轨迹以匹配地形。所得策略暴露出一个干净的SE(2)速度接口，与标准导航规划器兼容。在仿真中，与地形无关的参考相比，环境条件化的参考显著提高了参考跟踪性能。在硬件上，我们将该策略与MPC+控制障碍函数规划器集成，并在Unitree G1上展示了通过包含粗糙地形和连续楼梯的户外环境进行长时域（>70m）闭环自主导航，所有感知和计算均在机载上完成。

## Abstract
We present a method for training reference-guided, perceptive reinforcement learning locomotion policies for humanoid robots in which reference trajectories are modulated in training to be consistent with terrain geometry. Aiming to deploy our method with standard navigation autonomy infrastructure, we synthesize SE(2)-controllable reference trajectories inside the RL training loop, projecting desired footsteps onto valid footholds and adjusting swing-foot and center-of-mass trajectories to match the terrain. The resulting policy exposes a clean SE(2) velocity interface compatible with standard navigation planners. In simulation, environmentally-conditioned references significantly improve reference tracking performance compared to environment agnostic references. On hardware, we integrate the policy with an MPC + control barrier function planner and demonstrate long-horizon (>70m) closed-loop autonomous navigation on the Unitree G1 through outdoor environments containing rough terrain and consecutive flights of stairs, with all sensing and computation onboard.

### 1. 核心问题与整体含义（研究动机和背景）
- **核心问题**：现有参考引导的强化学习（RL）人形机器人行走策略在训练时未充分利用地形几何信息，导致在复杂地形（如楼梯、粗糙地面）上跟踪性能下降；同时，这些策略往往缺乏与标准导航规划器的兼容接口，难以集成到完整的自主导航堆栈中。
- **整体含义**：本文旨在通过在线合成与地形一致的参考轨迹，训练一个感知型RL行走策略，使其暴露标准的SE(2)速度接口，从而无缝集成到现有导航基础设施中，实现人形机器人在真实户外环境中的长距离自主导航。

### 2. 方法论：核心思想、关键技术细节
- **核心思想**：在RL训练循环内，基于线性倒立摆（LIP）模型快速合成SE(2)可控的参考轨迹，并通过地形几何信息动态调整落脚点、摆动脚和质心（CoM）轨迹，使参考与地形一致。策略输出直接映射为SE(2)速度指令，兼容标准导航规划器。
- **关键技术细节**：
  - **参考生成**：使用LIP模型解耦矢状面和横向步态，通过固定步周期（0.4s）和期望速度计算落脚点与CoM轨迹。摆动脚使用贝塞尔曲线插值，CoM高度和手臂摆动加入速度相关的正弦调制。
  - **地形一致性调整**：
    - 将期望落脚点投影到有效立足点（利用GPU并行多边形投影）。
    - 根据地形倾角调整摆动脚滚动/俯仰，并沿摆动路径扫描地形高度，修正摆动脚z向轨迹（取上凸包）。
    - 调整CoM z向高度以匹配连接当前支撑脚与投影落脚点的直线高度。
    - 参考轨迹修改在RL循环内实时完成，支持楼梯、斜坡、离散立足点等多种地形。
  - **奖励设计**：采用CLF-RL（Control Lyapunov Function for Reward Design），对每个跟踪目标设计二次型李雅普诺夫函数，奖励项包含函数值和其递减条件，实现稠密化奖励引导学习。
  - **网络架构**：单阶段非对称Actor-Critic，Actor为MLP（无历史状态），输入含噪的 proprioception、深度图（26×30）及无噪声速度命令和相位变量。Critic获得无噪声观察和特权信息。
