## 摘要
基于物理的人形机器人控制中，从自然语言指令出发是实现通用具身智能体的关键步骤。然而，现有方法仍受限于语义表达性与物理可行性之间的张力，往往难以同时实现忠实的指令遵循、高质量的运动以及稳定的长周期控制。本文提出SCRIPT，一种面向语言驱动物理人形机器人控制的多阶段训练可扩展扩散策略。SCRIPT的核心是联合动作-状态-文本扩散Transformer（JAST-DiT），它将动作、物理状态和文本表示为专门的令牌流，并通过联合注意力机制耦合它们，从而实现语言语义与控制动态的直接交互。为了稳定自回归控制，我们引入非线性历史条件机制，该机制保留密集的近期上下文，并从长期历史中采样越来越稀疏的线索。除了监督模仿预训练，我们提出后训练阶段，通过混合奖励的强化学习（RLHR）进一步提升性能。通过将可学习噪声注入流程采样过程，RLHR利用混合物理反馈和文本奖励，在闭环模拟中有效提升运动质量和指令遵循。定量评估表明，SCRIPT在文本对齐、运动质量和物理真实性指标上均优于先前最先进方法。此外，在1200小时MotionMillion数据集上的扩展研究表明，模型扩展带来一致性的性能提升，突显SCRIPT在大规模预训练中的稳健可扩展性。我们的代码将公开供未来研究使用。

## Abstract
Controlling physics-based humanoids from natural-language instructions is a critical step toward general-purpose embodied agents. However, existing methods remain constrained by a tension between semantic expressiveness and physical feasibility, often failing to jointly achieve faithful instruction following, high-quality motion, and stable long-horizon control. We propose SCRIPT, a scalable diffusion policy with a multi-stage training framework for language-driven physics-based humanoid control. The core of SCRIPT is a Joint Action-State-Text Diffusion Transformer (JAST-DiT), which represents actions, physical states, and text as dedicated token streams and couples them through joint attention, enabling direct interaction between language semantics and control dynamics. To stabilize autoregressive control, we introduce a nonlinear history conditioning mechanism, which preserves the dense recent context and samples increasingly sparse cues from long-term history. Beyond supervised imitation pre-training, we propose a post-training stage, further improving the performance using Reinforcement Learning with Hybrid Rewards (RLHR). By injecting learnable noise into the flow-sampling process, RLHR effectively improves motion quality and instruction following within closed-loop simulations using hybrid physical feedback and text rewards. Quantitative evaluations demonstrate that SCRIPT outperforms prior state-of-the-art methods, with gains across text alignment, motion quality, and physical realism metrics. Furthermore, scaling studies on the 1200-hour MotionMillion dataset demonstrate consistent performance gains with model scaling, highlighting SCRIPT's robust scalability for large-scale pre-training. Our code will be publicly available for future research.

## 2. 方法论
### 2.1 整体框架
- **多阶段训练**：第一阶段：基于流匹配（Flow Matching）的监督模仿预训练（行为克隆）；第二阶段：基于混合奖励的在线强化学习后训练（RLHR）。
- **核心架构**：Joint Action-State-Text Diffusion Transformer（JAST-DiT），将动作、状态、文本作为独立令牌流，通过联合注意力实现密集跨模态交互。

### 2.2 关键技术细节
- **JAST-DiT架构**：
    - 输入：噪声轨迹块中提取的动作令牌、状态令牌，以及CLIP文本编码器倒数第二层的文本令牌。
    - 每个Transformer块中：三个流分别经过流特定的投影和AdaLN-Zero调制（注入flow时间τ和池化文本嵌入c_pool），生成各自的Q、K、V，然后拼接进行联合自注意力（无因果掩码，保留文本填充掩码），再将输出分割回三个流。
    - 并行：在联合注意力后，使用非线性历史条件机制进行交叉注意力。

- **非线性历史条件机制**：
    - 维护一个密集的历史缓冲区B_t（长度L_max），但为避免计算浪费，采用非线性下采样策略：保留最近N_s帧为密集历史；从剩余远距离历史中稀疏采样N_l帧，采样概率随时间指数衰减（控制参数α）。
    - 层次化交叉注意力：动作和状态流先与稀疏远距离历史交叉注意力，再与密集近期历史交叉注意力。

- **数据构建**：
    - 从HumanML3D和MotionMillion等数据集出发，先用PHC（Perpetual Humanoid Control）跟踪得到物理状态-动作演示，并加入扰动（perturbed rollouts）以增强鲁棒性。过滤掉跟踪误差过大或跌倒的轨迹，最终保留约550K条物理轨迹，覆盖近1200小时运动数据。

- **RL后训练（RLHR）**：
    - 通过向Euler积分步的动作子空间注入可学习高斯噪声，将确定性流采样转化为随机马尔可夫链，从而可计算策略似然用于PPO优化。
    - 奖励设计：物理奖励（指数形式，惩罚与参考运动在位置、朝向、速度、角速度上的偏差）和文本奖励（稀疏的轨迹级对比学习得分）。
    - 优化目标：PPO损失 + 值函数损失 + 熵正则 + 行为克隆锚定损失（L_BC = 预测速度场与冻结预训练速度场之间的MSE）。

### 2.3 关键公式（文字说明）
- 流匹配目标：在τ∈[0,1]上，预测速度v_θ与真实速度u_τ = x1 - x0的MSE。
- 随机Euler更新：x_{k+1} = x_k + v_θ(x_k, τ_k, y)Δτ + M_a ⊙ σ_φ(τ_k, H_t) ⊙ ε_k，仅在动作维度加噪。

## 6. 主要结论与发现
- SCRIPT在所有指标上全面超越现有方法（PDP、UniPhys、CLoSD），特别是在FID（0.203 vs 0.487/1.536）和Duration time（97.67% vs 89.54%~94.81%）上有显著优势。
- 模型规模从0.2B扩展到1.2B带来了语义对齐（Top-3从0.633→0.701）和运动质量（FID从1.057→0.645）的一致提升，验证了可扩展性。
- JAST-DiT中的多模态流联合注意力至关重要，任一模态缺失都会导致性能暴跌（无文本流Top-3下降至0.563，无历史流崩溃至0.278）。
- 非线性历史采样优于均匀采样或更长历史（避免过拟合近期或引入过多远距离噪声）。
- RL后训练结合混合奖励能同时提升物理稳定性和语义对齐，而单一奖励会导致偏向（无物理奖励时Floating和Jerk上升，无文本奖励时R-Precision显著下降且运动退化）。
- 1200小时大规模训练可支持多样化语言指令下的运动生成（如打高尔夫、芭蕾舞、泰拳踢等）。

## 7. 优点

- **历史处理**：受认知工作记忆和遗忘曲线启发，非线性历史采样平衡了计算效率与上下文丰富度。

- **实验充分**：消融实验设计全面，控制了变量，并给出统计误差（标准差），结果可信。
- **应用前景**：代码开源，为后续语言驱动物理控制研究提供了可复现基准。
