## 摘要
离线目标条件强化学习（GCRL）在长视界任务中具有挑战性，其中遥远的状态-目标对提供弱监督，且价值估计易受累积自举误差的影响。分层方法通过引入中间子目标缓解了这一困难，但固定的时间抽象或固定的分层深度可能与具有不同可达范围的状态-目标对不匹配。我们提出了粗到细分层目标强化学习（CFHRL），这是一个完全离线的GCRL框架，在执行前自适应地细化遥远目标。从最终目标开始，CFHRL递归地提出中间目标，这些目标从回放支持候选中进行训练，并在当前目标被估计为可通过学习的可达性成本本地执行时停止细化。关键思想是，子目标不需要是精确的中点或全局最优路径点；它只需要提供可靠的进展并减少剩余到达难度，使得能够在更短的视界上进行后续细化。一个风格化的分析进一步支持近似递归收缩的鲁棒性。在OGBench上的实验显示，在多个长视界任务上有显著提升，消融实验验证了所提出的细化和停止机制。

## Abstract
Offline goal-conditioned reinforcement learning (GCRL) is challenging in long-horizon tasks, where distant state--goal pairs provide weak supervision and value estimates become vulnerable to accumulated bootstrapping errors. Hierarchical methods mitigate this difficulty by introducing intermediate subgoals, but fixed temporal abstractions or fixed hierarchy depths can be mismatched to state--goal pairs with different reachability horizons. We propose Coarse-to-Fine Hierarchical Goal Reinforcement Learning (CFHRL), a fully offline GCRL framework that adaptively refines distant goals before execution. Starting from the final goal, CFHRL recursively proposes intermediate targets, trained from replay-supported candidates, and stops refinement once the current target is estimated to be locally executable by a learned reachability cost. The key idea is that a subgoal need not be an exact midpoint or globally optimal waypoint; it only needs to provide reliable progress and reduce the remaining reaching difficulty, enabling subsequent refinement over shorter horizons. A stylized analysis further supports the robustness of approximate recursive contraction. Experiments on OGBench show substantial gains on several long-horizon tasks, with ablations validating the proposed refinement and stopping mechanisms

- **研究问题**：离线目标条件强化学习（Offline Goal-Conditioned RL, GCRL）在长视界任务中面临严峻挑战。当目标状态与当前状态相距很远时，稀疏奖励导致长程价值估计的弱监督，且自举更新中近似误差会沿备份链累积，使得对遥远目标的评估不可靠。直接训练扁平策略基于这些不准确的价值估计进行长程决策不可靠。
- **现有方法的不足**：分层方法通过引入中间子目标将长程问题分解为短程子问题。但现有方法通常使用固定的时间抽象（如固定的子目标视界或固定的高层决策步数），这种固定尺度与不同可达范围的状态-目标对不匹配：过于局部的子目标进步小，价值差异被噪声淹没；过于遥远的子目标可能超出底层策略的可执行范围。
- **论文动机**：能否让离线分层智能体自适应地为每个状态-目标对确定合适的中间目标？核心思想是粗到细（coarse-to-fine）地求解问题：初始阶段只需较大尺度的方向性信号，不需要精细区分；选中的子目标不必最优，只需提供有意义的进展并减少剩余可达性困难，从而允许后续在更短视界上进一步细化。

## 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想

- 提出**粗到细分层目标强化学习（CFHRL）**框架，一种完全离线的 GCRL 方法，在执行前自适应地细化遥远目标。
- 从最终目标开始，递归地用规划器提出的中间目标替换当前规划目标，直到目标被一个学习到的可达性成本（reachability cost）估计为本地可执行为止。
- 关键洞察：子目标不需要是精确中点或全局最优路径点，只需可靠进展并降低剩余到达难度，使后续细化能在更短视界上进行。

### 关键技术细节

1. **共享的可达性成本**：基于 GCIVL 学习一个目标条件价值函数 \(V_\phi(s,g)\)，并转换为非负可达性成本 \(D_\phi(s,g) = [-\hat{V}_\phi(s,g)]_+\)。更小的 \(D_\phi\) 表示从 \(s\) 到达 \(g\) 更容易。
2. **自适应粗到细细化**：
   - 初始化规划目标 \(g^{(0)} = g\)。
   - 递归检查当前目标是否满足可执行条件 \(D_\phi(s, g^{(\ell)}) \le \epsilon_{\text{exec}}\)。
   - 若满足，停止细化，将 \(g^{(\ell)}\) 传递给执行模块；否则通过规划器 \(\pi_p(\cdot|s,g^{(\ell)})\) 采样中间目标 \(u^{(\ell)}\)，更新 \(g^{(\ell+1)} = u^{(\ell)}\)。
   - 细化深度由估计的可达性动态决定，而非固定层数。
3. **离线学习规划器**：
   - 构建回放支持候选集 \(\mathcal{C}_D(s,g)\)，从离线数据集中采样完整观测作为候选子目标。
   - 每个候选通过瓶颈可达性成本 \(C_\phi(\tilde{s}_i|s,g) = \max\{D_\phi(s,\tilde{s}_i), D_\phi(\tilde{s}_i,g)\}\) 评分。
   - 训练规划器通过值引导加权模仿学习：权重 \(w_i\) 基于 softmax 归一化的负 \(C_\phi\)，损失为交叉熵 \(\mathcal{L}_p = -\mathbb{E}[\sum_i \text{sg}(w_i) \log \pi_p(\tilde{s}_i|s,g)]\)。
   - 推理时规划器直接采样，无需测试时回放缓冲区搜索。
4. **执行策略**：
   - 细化后，抽象策略 \(\pi_z(z|s,\bar{g})\) 将细化目标转换为本地命令，底层策略 \(\pi_a(a|s,z)\) 输出原始动作。
   - 两者通过值改进加权行为克隆（progress-weighted imitation）训练：从离线数据集采样短视界片段 \((s_t,a_t,s_{t+h})\)，使用权重 \(\omega_t = \min\{\exp(\alpha[V_\phi(s_{t+1},s_{t+h}) - V_\phi(s_t,s_{t+h})]), \omega_{\max}\}\)，损失为 \(\mathcal{L}_z = -\mathbb{E}[\omega_t \log \pi_z(z_t|s_t,s_{t+h})]\)，\(\mathcal{L}_a = -\mathbb{E}[\omega_t \log \pi_a(a_t|s_t,z_t)]\)。
5. **推理时**：循环执行“细化目标 → 抽象策略采样命令 → 底层策略执行若干步 → 重新规划”。

### 算法流程（文字说明）

- **训练（Algorithm 1）**：
  1. 采样离线过渡和事后目标。
  2. 使用 GCIVL 更新价值网络 \(V_\phi\)。
  3. 采样高层元组 \((s_t,g)\)，构建候选集，计算 \(C_\phi\)，更新规划器 \(\pi_p\)。
  4. 采样本地片段，构建命令 \(z_t = \psi(s_t,s_{t+h})\)，更新抽象策略 \(\pi_z\) 和底层策略 \(\pi_a\)。
- **推理（Algorithm 2）**：
  1. 对于每个规划循环：初始化 \(g^{(0)}=g\)。
  2. 逐层检查 \(D_\phi(s,g^{(\ell)}) \le \epsilon_{\text{exec}}\)，若满足则停止；否则采样子目标。
  3. 得到细化目标 \(\bar{g}\)，执行 \(H_{\text{exec}}\) 步（采样命令、执行动作），然后重新规划。

## 论文的主要结论与发现

- **主要结论**：CFHRL 在 OGBench 上取得最高聚合分数（37.5），显著优于 HIQL（23.2）等基线，尤其是在长视界迷宫类任务上（如 PointMaze-Giant-Stitch 从 0% 提升到 57%）。
- **关键发现**：
  - 固定深度细化（如 K=2,3）反而降低性能，说明自适应停止是必要且有效的。
  - 规划器必须依赖可达性成本引导（随机子目标失败）。
  - 抽象策略对性能有贡献，能更好将细化目标转化为本地命令。
  - 候选数 \(N_c\) 存在权衡：太小监督弱，太大降低训练吞吐量，16 为合理默认值。
  - 在接触丰富的操作任务（Cube）上，扁平价值方法表现更好，表明当前假设可能不适合需要精确接触动力学的场景。

## 不足与局限：包括实验覆盖、偏差风险、应用限制等

1. **依赖可达性成本质量**：如果价值函数在非分布或接触丰富状态上严重失调，规划器可能选择差子目标。
2. **操作任务表现弱**：在 Cube 任务上不如扁平方法，说明当前基于路径点分解的假设不适用于需要精确接触序列的精细操作。
3. **计算开销**：推理时递归细化需要多次调用规划器、价值网络、抽象策略和底层策略，虽无候选枚举，但计算成本仍高于扁平方法。
4. **后端通用性未验证**：仅使用 GCIVL 作为价值后端，未在 GCIQL、CRL 等后端上测试，通用性有待证明。
5. **理论分析的局限性**：动机分析基于一维理想化和独立性假设，并非针对高维离线 RL 的一般性定理。
6. **实验覆盖**：缺少与更新分层方法（如 Option-aware Temporally Abstracted Value、Chain-of-Goals）的比较；另外，每个方法只使用 8 个种子，可能对高方差任务稳定性不足。
7. **应用限制**：当前抽象命令是环境特定的本地目标表示，对机器人操作任务可能不足；框架假设子目标可以从离线数据中的完整观测中采样，可能不适用于非欧几里得目标空间。
