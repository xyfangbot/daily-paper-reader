## 摘要
视觉-语言-动作（VLA）模型是有效的机器人动作执行器，但由于扩展的闭环规划与多样化物理操作的双重负担，它们在长程任务上仍然受限。因此，我们提出VLAs-as-Tools策略，将该负担分配至用于时间推理的高层视觉语言模型（VLM）智能体与用于多样化局部物理操作的专用VLA工具族。VLM处理场景分析、全局规划与恢复，而每个VLA工具执行有界子任务。为了在长程任务中紧密耦合智能体规划与VLA工具执行，我们引入VLA工具族接口，该接口暴露显式工具选择与执行中进度反馈，从而实现无需连续智能体轮询的高效事件触发式智能体重规划。为了获得能够忠实遵循智能体调用的多样化专用VLA工具，我们进一步提出工具对齐后训练（TAPT），该方法构建用于指令遵循的调用对齐训练单元，并采用工具族残差适配器实现高效工具特化。实验表明，VLAs-as-Tools在LIBERO-Long上将$π_{0.5}$的成功率提升4.8个百分点，在RoboTwin上提升23.1个百分点，并通过无偏率衡量将调用保真度进一步提升15.0个百分点。代码将开源。

## Abstract
Vision-language-action (VLA) models are effective robot action executors, but they remain limited on long-horizon tasks due to the dual burden of extended closed-loop planning and diverse physical operations. We therefore propose VLAs-as-Tools, a strategy that distributes this burden across a high-level vision language model (VLM) agent for temporal reasoning and a family of specialized VLA tools for diverse local physical operations. The VLM handles scene analysis, global planning, and recovery, while each VLA tool executes a bounded subtask. To tightly couple agent planning with VLA tool execution in long-horizon tasks, we introduce a VLA tool-family interface that exposes explicit tool selection and in-execution progress feedback, enabling efficient event-triggered agent replanning without continuous agent polling. To obtain diverse specialized VLA tools that faithfully follow agent invocations, we further propose Tool-Aligned Post-Training (TAPT), which constructs invocation-aligned training units for instruction following and adopts tool-family residual adapters for efficient tool specialization. Experiments show that VLAs-as-Tools improves the success rate of $π_{0.5}$ by 4.8 points on LIBERO-Long and 23.1 points on RoboTwin, and further enhances invocation fidelity by 15.0 points as measured by Non-biased Rate. ## 2. 论文提出的方法论

### 2.1 核心思想：VLAs-as-Tools
- 将VLA模型视为可调用的、专用化的执行器（工具），而非单一的长时域政策。
- 构建一个**VLA工具族接口**（Agent–Tool Interface），包含双向通信：
  - **调用消息 C**：包含工具族标签 \(g\)（如grasp, open, place）和场景化指令 \(z\)（指定对象、关系、局部效果）。
  - **反馈消息 R**：工具在执行过程中返回连续进度信号 \(p_t \in [0,1]\)，用于进度监控和事件触发的重规划。

- 高层VLM智能体负责场景分析、全局规划、状态跟踪和恢复；每个VLA工具执行一个有界子任务，并返回进度反馈。

### 2.2 关键技术细节：Tool-Aligned Post-Training (TAPT)
- 目标**将VLA训练成可靠的、可调用的工具**，忠实遵循智能体的调用。
- **调用对齐训练单元**：将演示数据切分成有界窗口，每个窗口标注调用 \(c=(g,z)\) 和进度目标，使模仿学习和强化学习均基于相同的调用单位。
- **工具族残差参数化**（Tool-Family Residual Adapters）：
  - 在共享的VLA骨干上，为每个工具族 \(g\) 添加LoRA低秩残差适配器 \(\Delta W_g = B_g A_g\)。
  - 推理时根据工具族标签选择对应适配器，参数高效，避免遗忘预训练语义。

- **训练目标**（公式化）：
  - 模仿学习：联合优化动作克隆项和进度预测项：
    \[
    \mathcal{L}_{\text{TAPT}} = \mathbb{E}\left[ -\sum_t \log \pi_{\theta, \phi_g}(a_t|\cdot) + \lambda_{\text{prog}} \sum_t \|\hat{p}_t - p^*_t\|^2 \right]
    \]
  - 强化学习：基于调用的有界子任务MDP，奖励为子任务完成标志，采用GRPO优化。

### 2.3 算法流程（文字说明）
1. **预处理**：使用自动标注管道将原始轨迹切分为调用对齐的片断（基于抓手状态变化、相对运动等），赋予工具族标签和进度信号。
2. **后训练（TAPT）**：
   - 在大型中间数据集（如DROID）上进行调用对齐的中间后训练（IA Post-train）。
   - 在目标benchmark数据上完成下游调用对齐SFT（IA SFT）。
   - 可选RL阶段：以子任务MDP进行GRPO强化学习。
3. **推理**：高层VLM根据任务分解生成工具调用序列；通过VLA工具族接口调用对应工具执行有界窗口；工具返回进度信号，智能体根据阈值决定继续、重规划或切换工具。

## 6. 论文的主要结论与发现

1. **VLAs-as-Tools策略显著提升长时域任务成功率**：在LIBERO-Long上，π0.5成功率提升4.8百分点（97.2% vs 92.4%）；在RoboTwin上提升23.1百分点（62.5% vs 39.4%）。OpenVLA-OFT在RoboTwin上提升高达35.5百分点。
2. **单纯使用规划器+VLA而不做工具对齐不足**：Direct Planner部署反而造成性能下降（-0.2~-12.0百分点），证明工具对齐训练是关键。
3. **TAPT提升调用保真度**：在LIBERO-CF-Long上，Faithful Rate从19.4%提升至54.0%（OpenVLA-OFT），Non-biased Rate从31.2%提升至47.4%；π0.5类似。
4. **参数效率高**：工具族残差适配器仅增加约9%参数和7%推理时间（OpenVLA-OFT）。
5. **代理规划效率提升**：基于进度的重规划大幅减少高层调用次数（从超过50次降至约1-2次），同时保持高重规划成功率（34.4%-61.4%）。
6. **few-shot适应能力强**：TAPT在10-shot和20-shot下均显著优于基线，最多提升11.5百分点。
7. **不依赖于特定VLM规划器**：四个不同VLM规划器（GPT、Gemini、Qwen等）下成功率波动仅0.6百分点。
