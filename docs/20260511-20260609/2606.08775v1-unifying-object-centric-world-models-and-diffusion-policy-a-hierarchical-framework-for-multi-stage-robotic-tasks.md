## 摘要
视觉世界模型在学习复杂系统动力学方面展现出巨大潜力。最近的研究进展将这些模型作为模型预测控制（MPC）框架内的转移函数，用于解决各种控制任务。然而，当应用于机器人时，它们仅限于单阶段任务（如抓取或触碰），难以应对需要复杂序列规划的多阶段任务。在这项工作中，我们提出了WorldDP，一个专为多阶段机器人操作设计的世界模型框架。我们的分层方法利用高层世界模型作为转移函数，在运行时优化可行的子目标，随后由低层扩散策略执行这些子目标。为了进一步辅助动力学学习和规划，我们引入了以对象为中心的表征，将环境实体解耦，并能够针对每个实体进行序列规划。在多个机器人基准测试中，WorldDP持续优于现有基线，验证了将世界模型的物理基础规划与扩散策略的高效执行相结合能够产生卓越的多阶段性能。

## Abstract
Visual world models have shown great potential in learning complex system dynamics. Recent advancements leverage these models as transition functions within Model Predictive Control (MPC) frameworks to solve various control tasks. When applied to robotics, however, they are limited to single-stage tasks such as reaching or grasping, and struggle with multi-stage ones that demand complex sequential planning. In this work, we introduce WorldDP, a world model framework designed for multi-stage robotic manipulation. Our hierarchical approach utilizes a high-level world model as a transition function to optimize for feasible subgoals during runtime, which are subsequently reached by a low-level Diffusion Policy. To further aid in learning dynamics and planning, we incorporate object-centric representations that decouple environmental entities and enable us to plan sequentially with respect to each. Evaluated across several robotics benchmarks, WorldDP consistently outperforms existing baselines, validating that coupling the world model's physically grounded planning with diffusion policy's efficient execution yields superior multi-stage performance.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有视觉世界模型在机器人领域仅适用于单阶段任务（如抓取、触碰），难以处理需要复杂序列规划的多阶段操作（如多物体捡放、开抽屉前先按按钮等顺序依赖任务）。这类任务要求长时间序列决策，且存在因果依赖，单层规划容易失败。
- **研究动机**：当前世界模型方法（如DINO-WM、LeWM）依赖patch级特征，缺失细粒度信息；分层规划（如HWM）在低层仍使用世界模型进行物理动作优化，对子目标选择敏感、执行慢；同时机器人动作空间具有多模态性，优化方式（如CEM）单一高斯分布难以捕获多种可行解。
- **整体含义**：提出一种层次化框架，将世界模型的高层规划能力与扩散策略的鲁棒、快速执行相结合，以解决多阶段机器人操作问题，并引入物体中心表示和接触预测来提升子目标质量。

## 2. 论文提出的方法论

### 核心思想
- 构建**层次化框架WorldDP**：
  - **高层**：一个以物体为中心的潜空间世界模型，在MPC框架内使用粒子滤波器优化潜动作序列，生成可行的子目标状态。
  - **低层**：一个目标条件扩散策略（Diffusion Policy），负责跟踪并执行这些子目标。
- **物体中心表示**：通过槽注意力（Slot Attention）从DINOv2 patch特征中聚合成每个环境实体（机器人、背景、各物体）的离散嵌入，使模型能够针对每个物体单独规划。
- **接触预测器**：训练轻量级MLP预测机器人何时与物体接触，将接触概率信号融入MPC代价函数，鼓励生成关键操作帧（如抓取前瞬间）作为子目标。
- **粒子滤波器优化**：替代常见的交叉熵方法（CEM），用多模态粒子集表示多种有效动作序列，提高规划鲁棒性。

### 关键技术细节
1. **物体中心编码器（OCE）**：
   - 输入：图像 → 冻结DINOv2得到patch特征 `z_k`。
   - 初始化N个槽 `s̄_k`（代表机器人、背景、物体），通过Slot Corrector（交叉注意力+GRU）迭代细化得到 `s_k`。
   - Slot Decoder预测逐槽重建 `ẑ_nk` 和掩码 `m̂_k`，最终重建 `ẑ_k`。
   - 损失函数：`L_oce = L_l2_oce + λ_oce * L_tv`，其中 `L_l2_oce` 是patch特征重建均方误差，`L_tv` 是Tversky损失，利用SAM2生成的GT掩码进行监督（解决小物体欠表示问题）。

2. **动力学模型**：
   - 基于条件扩散Transformer（CDiT），输入物体中心状态 `s_k` 和动作序列（通过Transformer动作编码器压缩为32维潜变量）。
   - 训练时随机采样5帧（间隔随机），预测下一帧状态，使用教师强制和MSE损失。

3. **分层执行**：
   - **规划阶段**：粒子滤波器初始化Q个潜动作序列（从空间轨迹种子生成），通过动力学模型自回归滚动得到预测状态轨迹，使用物体中心代价函数评估：`C = C_dist + λ_plan * C_ce`，其中 `C_dist` 为目标物体嵌入的MSE，`C_ce` 为接触预测交叉熵。选择前M个候选作为新均值，迭代L次，得到最优子目标序列。
   - **执行阶段**：目标条件扩散策略（基于Transformer）以当前观测和子目标为条件，生成40步动作序列，由逆运动学控制器执行。支持顺序重规划：完成一个物体的子目标后，捕获新图像，再规划下一个物体。

4. **低层扩散策略**：
   - 输入：当前物体中心状态（展平向量）和目标状态，加上末端执行器位姿和速度。
   - 输出：40步动作（末端效器位移和夹爪开合）。
   - 训练时采用随机目标采样和零填充，提升时间泛化性；测试时结合深度相机进行抓取位姿修正。

## 3. 实验设计

### 数据集与场景
- 基于**OGBench**基准，使用Maes et al.修改的变体（相机视角和末端颜色不同）。包含四个多阶段任务：
  1. **Cube-Single**：单红色方块，机器人需将其移动到目标位置。
  2. **Cube-Triple**：三个不同颜色方块，需顺序重排。
  3. **Scene-Single-Direct**：环境含抽屉、滑动窗、方块、两个按钮（控制锁），目标仅改变一个实体状态（如按按钮、移动抽屉等）。
  4. **Scene-Single-Composite**：同一环境，需先按按钮解锁再操作抽屉/窗，包含因果依赖。
- 训练数据：每个环境配置收集**200万帧**“玩耍”数据集（无奖励、无目标标注，包含次优轨迹）。

### 对比基线
- **DINO-WM**：经典JEPA世界模型，使用冻结DINOv2 patch特征。
- **LeWM**：联合优化编码器和潜动力学模型。
- **HECRL\***：HECRL改进版（用扩散模型生成子目标，用目标条件DP跟踪低层，单视图输入）。
- **DP40 / DP100**：单独的目标条件扩散策略，分别训练40步和100步轨迹。

### 评估设置
- 测试集：每个任务50条独立轨迹（保持与训练集分离）。
- 成功判定标准：Cube任务按欧氏距离（<12cm），Scene任务按按钮状态和抽屉/窗位置误差。

## 6. 论文的主要结论与发现

1. **层次化框架有效**：WorldDP在三物体放置任务（Cube-Triple）上达到30%全成功（3-Cubes），是次优方法（HECRL\*, 12%）的2.5倍；在Scene-Single-Composite全任务成功率达20%，而基线中最好仅14%（DP100）。
2. **物体中心表示优于patch表示**：去掉OCE后，在场景任务中性能下降（特别是抽屉、窗口操作）。
3. **粒子滤波器优于CEM**：PF相比CEM能更好捕捉多模态动作分布，提升长期规划成功率。
4. **接触预测关键**：去掉接触预测器后性能显著下降（图6），说明它帮助生成了关键子目标。
5. **短执行周期更优**：40步子目标执行比100步更好，因为高层提供了精确的中间目标。
6. **统一世界模型与扩散策略**：单独使用世界模型（w/o DP）或单独使用扩散策略（DP Only）均不及完整框架。
