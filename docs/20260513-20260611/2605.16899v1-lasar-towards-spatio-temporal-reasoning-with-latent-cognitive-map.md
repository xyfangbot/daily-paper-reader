## 摘要
具身智能中的一个基本挑战是验证智能体是否构建了空间结构的内部模型，还是仅仅学会了模仿特定任务的专家轨迹。这一点至关重要，因为基于行动中心任务（如VLN）和推理中心任务（如EQA）的基础方法通常有一个共同局限：它们缺乏一种学习信号，使得智能体在长期、片段化的经验中被迫编码细粒度的空间关系（如拓扑或距离）。为解决这一问题，我们首先提出了LASAR，一种具有双记忆系统的架构，旨在同时维护情节体验和语义认知地图。然后，我们引入了时空上下文表征学习（ST-CRL），这是一种对比学习目标，用于训练该架构。ST-CRL利用通过模拟中标注的时空上下文生成的认知查询中的时空线索来构建样本对，从而从智能体的经验中形成内部认知地图。实验表明，我们的方法在标准VLN-CE和VSI-Bench基准的零样本泛化中分别获得了2%-3.5%的提升。我们还证明了所提出的认知地图具有高自一致性。

## Abstract
A fundamental challenge in embodied AI is verifying if agents build internal models of spatial structure or merely learn to mimic task-specific expert trajectories. This is critical as foundational approaches rooted in action-centric tasks (e.g., VLN) and reasoning-centric tasks (e.g., EQA) often share a common limitation: they lack a learning signal that forces them to encode fine-grained spatial relationships (like topology or distance) over long-range, fragmented experiences. To address this, we first propose LASAR, an architecture featuring a dual-memory system designed to maintain both episodic experiences and a semantic cognitive map. We then introduce Spatio-temporal Contextual Representation Learning (ST-CRL), a contrastive objective designed to train this architecture. ST-CRL leverages spatio-temporal cues from cognitive queries generated through annotated spatio-temporal context in simulation to build sample pairs, thereby forming the internal cognitive map from the agent's experiences. Experiments demonstrate that our method achieves 2\%-3.5\% gains in both zero-shot generalization on standard VLN-CE and VSI-Bench benchmarks. We also demonstrate that our proposed cognitive map has high self-consistency.

# LASAR: 基于隐式认知地图的时空推理——论文总结

## 1. 核心问题与研究动机
- **背景**：具身人工智能（Embodied AI）面临一个根本挑战：智能体是否真正构建了空间结构的内部模型，还是仅仅学会了模仿专家轨迹的统计偏差？当前主流方法分为两类：
  - **行动中心任务**（如视觉语言导航 VLN）：侧重于决策和行动，但缺乏对空间关系的显式理解。
  - **推理中心任务**（如具身问答 EQA）：侧重于理解与推理，但常常脱离具身世界模型。
- **共同局限**：两者都缺少一种学习信号，迫使其在长期、碎片化的经验中编码细粒度的空间关系（如拓扑、距离、相对方位）。
- **核心问题**：如何让智能体从片段化的观察-动作流中构建一个可查询的、结构化的世界模型，从而支持鲁棒的时空推理与泛化？
- **解决思路**：学习一个认知地图（Cognitive Map），将原始经验转换为查询友好的世界模型，并在此过程中注入时空逻辑。

## 2. 方法论
### 2.1 整体架构：LASAR（Latent Spatial Reasoner）
- **输入编码器**：
  - 视觉语义特征 \(F_{vis,t}\)：使用冻结的 Siglip 编码器从 RGB 图像提取。
  - 几何特征 \(F_{geo,t}\)：使用冻结的 VGGT 模型从同一 RGB 图像推断三维结构（深度、布局等）。
  - 几何-语义融合：通过 8 头交叉注意力 + 残差连接得到融合特征 \(F'_{vis,t}\)。
- **双记忆系统**：
  1. **情节记忆（Episodic Memory）** \(M_{epi,t}\)：记录所有历史融合特征的时间序列（采样固定 32 帧以控制计算量）。
  2. **语义记忆（Semantic Memory）**：
     - **空间语义图集（Spatial Semantic Atlas）**：一个可学习的码本 \(E_{world}\)，包含 \(N_w=512\) 个世界基元（如“灯在沙发旁”）。
     - **隐式认知地图（Latent Cognitive Map）** \(m_t\)：通过注意力池化生成上下文向量 \(z_t\)，再以 \(z_t\) 为查询、\(E_{world}\) 为键值进行交叉注意力得到。
- **统一决策头**：
  - 基于 Qwen2-7B 的 LLM 骨干。
  - 输入：语言指令 \(T\) + 情节记忆 \(M_{epi,t}\) + 隐式认知地图 \(m_t\)。
  - 输出：导航动作 \(a_t\) 和/或查询答案 \(ans_t\)（通过统一词汇表实现）。
  - 额外机制：在 LLM 输入序列中添加特殊 token `[MAP]`，将其嵌入替换为 \(m_t\)，从前向传播的最后一层提取“激活的认知地图” \(m'_t\)，用于后续对比学习。

### 2.2 核心训练目标：ST-CRL（Spatio-temporal Contextual Representation Learning）
- **目标**：通过对比学习塑造认知地图，使其编码细粒度空间关系，而非简单共现统计。
- **样本对构建**：
  - **锚点**：当前时间步的激活认知地图 \(m'_t\)。
  - **正样本**：来自另一段经验，其查询语义等价（共享相同查询模板 ID）且答案相同。
  - **负样本（三种类型）**：
    - 空间硬负样本：同一查询模板但答案不同（不同空间上下文）。
    - 语义硬负样本：相同区域 ID 但不同查询与答案。
    - 无关干扰项：区域 ID 和查询模板均不同。
  - 负样本从重放缓冲区中挖掘，共 32 个（8 空间、8 语义、16 无关）。
- **损失函数**：InfoNCE。

### 2.3 其他辅助损失
- **空间语义图集学习（\(L_{sem}\)）**：向量量化 + 熵正则化，确保码本基元代表真实视觉特征且分布均匀。
- **情节判别性（\(L_{epi}\)）**：对比损失，拉近同轨迹特征，推开不同轨迹特征。
- **总损失**：\(L_{total} = \frac{1}{T}\sum_t (L_{MindCraft,t} + \lambda_c L_{crl,t} + \lambda_s L_{sem,t}) + \lambda_r L_{epi}\)，其中 \(L_{MindCraft}\) 包含动作模仿损失和查询回答损失。

### 2.4 MindCraft 任务与数据集
- **定义**：在标准 VLN 过程中注入并行的认知查询，要求智能体同时进行导航和回答。
- **查询层级**（三级六类）：
  - L1 回顾型：对象属性回忆、时序关系回忆。
  - L2 内省型：自定位、局部空间关系。
  - L3 前瞻型：拓扑邻接预测、未来地标预测。
- **数据集生成**：基于 VLN-CE 专家轨迹和 Matterport3D 环境，通过程序化管道注入查询并记录地面真值。
