## 摘要
视觉-语言-动作（VLA）模型已成为通用机器人操作的一种有前景的范式。当前架构的常见设计是将语言指令和视觉观测映射为单次前向传递中的动作。虽然概念上简单，但这种表述将指令理解、空间场景感知和运动控制纠缠在单一学习目标中。结果，动作专家必须隐式地重新学习预训练VLM中已存在的认知和感知能力，这可能限制学习效率和泛化能力。我们提出AVP（基于视觉基元的动作），一种端到端架构，实现了这种以视觉基元为中心的接口：VLM推断下一阶段目标并发出视觉基元标记，这些标记条件化一个流匹配动作专家，其监督来自末端执行器运动学。在通用拾取和放置任务上的真实机器人实验表明，AVP相比pi_0.5将成功率提高了27.61%，并优于其他近期方法，在数据效率、空间组合泛化和对象级迁移方面取得一致增益。

## Abstract
Vision-Language-Action (VLA) models have emerged as a promising paradigm for generalist robotic manipulation. A common design in current architectures maps language instructions and visual observations to actions in a single forward pass. While conceptually simple, this formulation entangles instruction comprehension, spatial scene understanding, and motor control within a single learning objective. As a result, the action expert must implicitly relearn cognitive and perceptual capabilities already present in the pretrained VLM, which can limit both learning efficiency and generalization. We introduce AVP (Action with Visual Primitives), an end-to-end architecture that implements this visual-primitive-centric interface: the VLM infers the next-stage target and emits visual-primitive tokens that condition a flow-matching action expert, with supervision derived from end-effector kinematics. Real-robot experiments on general pick-and-place tasks show that AVP improves the success rate by 27.61% over pi_0.5 and outperforms other recent methods, with consistent gains in data efficiency, spatial-compositional generalization, and object-level transfer.

## 1. 核心问题与整体含义（研究动机与背景）

现有 Vision-Language-Action (VLA) 模型通常将语言指令、视觉观测和动作生成混合在单一前向传播中。这种设计使得指令理解、空间场景感知和运动控制纠缠在同一个学习目标里，导致**动作专家必须隐式地重新学习 VLM 已具备的认知和感知能力**，从而限制了学习效率和泛化能力。尤其在对象、布局或环境变化时，动作专家难以分离可迁移的运动技能与任务相关的视觉上下文。为解决此问题，论文提出 **AVP（Action with Visual Primitives）**，通过在 VLM 与动作专家之间引入**显式的视觉基元接口**，实现职责解耦：VLM 负责“做什么、在哪里”，动作专家专注于“如何执行”。

## 2. 方法论：核心思想与关键技术细节

### 核心思想
AVP 采用**视觉基元（visual primitives）中心接口**。VLM 在感知语言指令和视觉观测后，推断下一阶段的目标，并输出**离散的视觉基元标记**（如点、边界框、掩码等），这些标记被投影回视觉 token 空间，作为条件驱动动作专家生成机器人动作。

### 架构组成
- **预训练 VLM**：处理语言指令和视觉观测，产生多模态上下文 token。
- **自回归解码器**：从 VLM 特征中预测离散的视觉基元 \( p_t = D_\psi(\text{VLM}(o_t, l)) \)。
- **动作专家**：基于融合了视觉基元 token 的增强多模态表示 \( z_t^{\text{aug}} \) 和机器人状态 \( s_t \)，使用**流匹配（flow matching）** 模型预测动作序列 \( a_{t:t+h} \)。

### 监督方式
- 视觉基元解码器使用**辅助分类损失** \( \mathcal{L}_{\text{vp}} = \mathcal{L}_{\text{CE}}(p_t, y_t^{\text{vp}}) \)，其中真值 \( y_t^{\text{vp}} \) 来自末端执行器运动学投影（3D 机器人位姿 → 2D 图像平面）。
- 动作专家使用标准动作预测损失 \( \mathcal{L}_{\text{act}} \)。
- 总损失：\( \mathcal{L} = \mathcal{L}_{\text{act}} + \lambda \mathcal{L}_{\text{vp}} \)。

### 推理流程
仅需原始观测、语言指令和机器人状态，视觉基元由模型内部生成，无需外部检测器或分段器。

## 6. 主要结论与发现

1. **AVP 在三个任务上均显著优于 π0.5 基线**，整体成功率平均提升 **27.61%**（象棋：AVP 90.28% vs π0.5 62.67%；多米诺：88.19% vs 81.94%；通用物体：86.18% vs 64.96%）。
2. **强烈空间组合泛化能力**：在从未见过的直接过渡任务上，AVP 成功率为 100%（8/8），而 π0.5 为 0%。
3. **零样本跨域泛化出色**：在完全新的物体、背景和指令下，AVP 保持 8/8 或 7/8 成功率，π0.5 严重退化（多在 0/8）。
4. **视觉基元设计关键**：框+掩码+记忆的基元形式效果最佳（91% 平均成功率 vs 无基元 78%）。
5. **端到端内部生成基元**避免了外部模块的延迟和误差传递。

## 7. 优点

- **职责解耦清晰**：VLM 负责空间推理，动作专家专注运动生成，学习更高效。
- **端到端训练**：无需外部检测器、分段器或人工标注，视觉基元监督自动从末端执行器运动学获取。
- **可扩展性**：基元形式紧凑（点/框），可自然引入时间记忆或顺序索引，且对新的平台只需一次相机标定即可产生标签。
- **实验验证充分**：在真实机器人上进行了多种任务和泛化测试，结果一致优于强基线。
- **消融研究全面**：分析了基元类型、透明度等设计选择，指导实践。

## 8. 不足与局限

- **推理延迟增加**：两阶段（基元预测 + 动作生成）比单次传递慢（AVP 0.27s vs π0.5 0.16s）。
- **对手眼标定敏感**：监督依赖精确的 3D→2D 投影，相机外参漂移或物理扰动会影响性能。
- **消融实验仅基于象棋任务**，未在多米诺和通用物体上验证不同基元设计的泛化性。
- **未在更大规模异质数据集上测试**（如 Open X-Embodiment），泛化范围仍限于特定任务。
- **与 DM0、LDA 等方法的对比不够充分**（它们在象棋任务上表现差，但可能在其他领域有优势）。
- **未讨论失败模式分析**：例如基元预测错误如何影响后续动作，以及错误传播边际。
