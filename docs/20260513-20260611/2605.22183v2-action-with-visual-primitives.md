## 摘要
视觉-语言-动作（VLA）模型已成为通用机器人操作的一种有前景的范式。当前架构中的一种常见设计是将语言指令和视觉观察映射到单次前向传递中的动作。虽然概念上简单，但这种表述将指令理解、空间场景理解和运动控制纠缠在一个单一的学习目标中。因此，动作专家必须隐式地重新学习预训练VLM中已经存在的认知和感知能力，这可能限制学习效率和泛化能力。我们提出AVP（基于视觉基元的动作），这是一种端到端架构，实现了这种以视觉基元为中心的接口：VLM推断下一阶段目标并发出视觉基元标记，这些标记条件化一个流匹配动作专家，其监督信号来源于末端执行器运动学。在通用抓取和放置任务上的真实机器人实验表明，AVP比π_0.5的成功率提高了27.61%，并优于其他近期方法，在数据效率、空间组合泛化和物体级别迁移方面持续取得改进。

## Abstract
Vision-Language-Action (VLA) models have emerged as a promising paradigm for generalist robotic manipulation. A common design in current architectures maps language instructions and visual observations to actions in a single forward pass. While conceptually simple, this formulation entangles instruction comprehension, spatial scene understanding, and motor control within a single learning objective. As a result, the action expert must implicitly relearn cognitive and perceptual capabilities already present in the pretrained VLM, which can limit both learning efficiency and generalization. We introduce AVP (Action with Visual Primitives), an end-to-end architecture that implements this visual-primitive-centric interface: the VLM infers the next-stage target and emits visual-primitive tokens that condition a flow-matching action expert, with supervision derived from end-effector kinematics. Real-robot experiments on general pick-and-place tasks show that AVP improves the success rate by 27.61% over pi_0.5 and outperforms other recent methods, with consistent gains in data efficiency, spatial-compositional generalization, and object-level transfer.

## 1. 核心问题与整体含义（研究动机与背景）

- **现有 VLA 模型的问题**：当前主流的视觉-语言-动作（VLA）模型（如 π₀.₅、OpenVLA）将语言指令理解、空间场景感知与运动控制三者耦合在单一学习目标中。这导致动作专家（action expert）必须隐式地重新学习预训练 VLM 已有的认知与感知能力，从而限制了学习效率与泛化性能。
- **已有改进方案的不足**：
  - 规划为中心的方法（如 π₀.₅ 的子任务分解）依然依赖纯语言接口，难以表达细粒度的空间差异。
  - 子目标图像方法（如 π₀.₇）提供像素级信息，但动作专家仍需自行判断图中哪些内容与任务相关。
  - 视觉提示方法（如 Point-VLA、VP-VLA）依赖外部模型生成空间标记，形成多阶段管线，增加了延迟和误差累积。
- **AVP 的切入点**：重新划分 VLM 与动作专家的职责——VLM 负责“做什么”和“在哪里”，动作专家只负责“怎么做”。通过引入 **视觉基元（Visual Primitives）** 作为两者间的显式通信接口，实现端到端解耦。

## 2. 方法论：核心思想、关键技术细节与流程

### 核心思想
- 使用 **视觉基元**（如点、边界框、掩码、记忆等）作为 VLM 输出给动作专家的显式空间引导。VLM 推断下一阶段目标并发出视觉基元 token，这些 token 条件化一个流匹配（flow-matching）动作专家，最终生成机器人动作。

### 模型架构（三部分）
1. **预训练 VLM**：接收语言指令 `l` 和视觉观测 `o_t`，生成多模态上下文 token。
2. **视觉基元解码器**：基于 VLM 的输出，自回归预测当前下一阶段的离散化视觉基元 `p_t`（编码了子任务及其空间目标）。
3. **动作专家（流匹配）**：将预测的视觉基元投影到视觉 token 空间（得到 `z_vp_t`），与原始多模态 token 融合后，用于预测动作序列 `a_{t:t+h}`。

### 监督与训练
- **视觉基元监督**：从真实的末端执行器运动学中自动生成标签，无需人工标注或外部检测模型。三步流程：
  1. 基于夹爪状态变化提取关键帧；
  2. 从机器人自身姿态获取 3D 末端执行器位置 `P_t`；
  3. 通过相机内外参投影到 2D 图像平面，得到空间锚点，再离散化为视觉基元标签。
- **总体损失**：`L = L_act + λ * L_vp`，其中 `L_vp` 为交叉熵损失（预测视觉基元 vs. 真实基元），`L_act` 为标准动作预测损失。

### 推理流程
- 只需原始观测、语言指令和机器人状态。视觉基元由模型内部生成，无需外部检测器或分割器。

## 6. 主要结论与发现

- **性能提升**：在三个任务上，AVP 的平均成功率相比 π₀.₅ 提升 **27.61%**（中国象棋：90.28% vs. 62.67%；多米诺：88.19% vs. 81.94%；通用物体：86.18% vs. 64.96%）。
- **泛化能力**：AVP 能组合已学的子轨迹完成未见过的直接过渡（π₀.₅ 完全失败）；零样本跨域泛化到 45 个未见过的物体时保持高成功率，而 π₀.₅ 严重退化。
- **视觉基元的作用**：消融实验证明，引入视觉基元（特别是 box + mask + memory）能显著提升操作性能；背景掩码和记忆机制进一步增强了泛化与稳定性。

## 7. 优点

1. **端到端、无需外部模型**：视觉基元的生成和监督全部集成在模型内部，避免了多阶段管线带来的延迟和错误传播。
2. **自动标签生成**：监督信号直接从末端执行器运动学推导，无需人工标注或依赖分割模型，可扩展性强。
3. **明确解耦认知与动作**：VLM 负责推理和空间定位，动作专家专注于运动执行，提升了数据效率和泛化能力。
4. **空间组合泛化表现突出**：能组合已知子轨迹处理未见过的新任务，而基线无法做到。
5. **跨域零样本泛化能力强**：在物体外观、背景变化下表现鲁棒。

## 8. 不足与局限

1. **两阶段推理增加延迟**：相比单次前向的 π₀.₅，AVP 的推理延迟稍高（0.27s vs. 0.16s），尽管远低于级联方法。
2. **对手眼标定敏感**：视觉基元监督依赖精确的相机-机器人外参标定，标定误差或物理扰动会直接影响空间标签质量，从而降低系统鲁棒性。
3. **训练算力未完全披露**：论文未说明训练所使用的 GPU 数量、型号及总耗时，使得复现和成本评估不够透明。
4. **任务范围有限**：实验局限于桌面拾放任务（中国象棋、多米诺、通用物体），未涉及更复杂的操作（如工具使用、装配等），泛化到更开放场景有待验证。
