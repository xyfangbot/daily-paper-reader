## 摘要
现有的物体导航基准通常告诉具身智能体需要找到哪类物体，例如微波炉或椅子。面向人类的具身AI常常被问到一些不那么直接的问题：“我需要加热食物”或“房间感觉很闷”。智能体必须推断出能够满足需求的物体，找到一个场景中的实例，并判断目标是否已经达到。我们将这一设定研究为意图驱动的物体导航，并引入IntentionNav，这是一个从隐含人类指令中进行主动物体搜索的诊断性基准。每个episode提供一个自由文本的意图、RGB-D观测值和位姿，但不提供目标物体名称。IntentionNav包含覆盖176个Isaac Sim场景和64个目标类别的500个意图。每个意图以四种受控指令风格重新编写，并标注四种意图模式之一，从而在匹配的几何条件下将表面措辞与语义提示类型分开。这种配对设计支持目标推理、语言鲁棒性、邻域可达性以及终止成功（而不仅仅是总成功率）的分析。我们使用一个固定的主动导航智能体评估了三个VLM。模型在48.3%的episode中识别出预期目标，在68.7%中进入其2米邻域，但仅在24.9%中成功终止，并在5.5%中达到接地1米成功。事件脚本意图的成功率最高（28.7%），物理状态和可负担性意图的成功率较低（分别为19.2%和18.5%），这表明间接的人类意图仍然是主动具身搜索中目标选择、视觉验证和终端定位的瓶颈。

## Abstract
Existing object navigation benchmarks usually tell an embodied agent which object category to find, such as microwave or chair. Human-facing embodied AI is often asked something less direct: "I need something to warm this food" or "the room feels stuffy." The agent must infer the object that can satisfy the need, find a scene-grounded instance, and decide whether the goal has been reached. We study this setting as intent-driven object navigation and introduce IntentionNav, a diagnostic benchmark for active object search from implicit human instructions. Each episode provides a free-text intent, RGB-D observations, and pose, but withholds the target object name. IntentionNav contains 500 intents over 176 Isaac Sim scenes and 64 target categories. Each intent is rewritten in four controlled instruction styles and annotated with one of four intent modes, separating surface phrasing from semantic cue type under matched geometry. This paired design supports analysis of target inference, language robustness, neighborhood reachability, and terminal success rather than only aggregate success. We evaluated three VLMs using a fixed active-navigation agent. Models identify the intended target in 48.3 percent of episodes and enter its 2 m neighborhood in 68.7 percent, but terminate successfully in only 24.9 percent and achieve grounded 1 m success in 5.5 percent. Success is highest for event-script intents (28.7 percent) and lower for physical-state and affordance intents (19.2 percent and 18.5 percent), showing that indirect human intent remains a bottleneck for target selection, visual verification, and terminal localization in active embodied search.

## 1. 核心问题与整体含义（研究动机和背景）
- **研究动机**：现有物体导航（ObjectNav）基准通常直接指定目标类别（如“微波炉”），但人类在实际交互中常使用隐含意图的指令（如“我需要加热食物”“房间很闷”），智能体必须从这类间接需求中推断出目标物体，并完成导航和终止。
- **背景**：现有基准如Category-goal ObjectNav、REVERIE、SOON均假设目标显式给出；Demand-driven Navigation（DDN）虽研究隐含目标，但缺乏对指令措辞和语义线索类型的系统分析。缺少一个能够诊断意图到导航全链条失败模式的基准。
- **整体含义**：本文提出IntentionNav，旨在评估具身智能体在隐含人类意图下的主动目标搜索能力，揭示目标推断、视觉验证和终止定位的瓶颈。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：将意图驱动的物体导航形式化为一个在目标模糊性下的主动搜索问题。智能体接收自由文本意图、RGB-D观测和位姿，但目标类别从未给出；必须通过主动探索和场景级视觉证据推断目标类别并定位到物理实例。
- **关键技术细节**：
  - **任务定义**：每个episode包含场景s、意图u（自由文本）、固定起始位姿q₀、隐藏真实目标(o⋆, c⋆, p⋆)。约束：u不能包含c⋆，且o⋆必须是场景中唯一可满足u的实例。
  - **语言轴设计**：两个正交诊断轴——
    - **指令风格（Instruction Style）**：同一意图的四种措辞变体：正式（formal）、自然（natural）、随意（casual）、情感（emotional）。用于测试措辞鲁棒性。
    - **意图模式（Intent Mode）**：四种语义锚点类型：事件脚本（event-script）、内在状态（inner-state）、物理状态（physical-state）、功能/可负担性（affordance）。用于测试推理难度。
  - **基准构建**：两阶段流程：
    1. 自动候选生成：利用VLNVerse模拟器从176个室内场景中提取支撑面、视图-目标对，生成17,624个意图集（含四种风格）。
    2. 人类验证精选：筛选500个高质量意图（2000条指令），通过词汇泄漏检查、目标唯一性、风格区分度验证（使用VLM法官打分，低于阈值迭代修订至少三轮）。最终一致性审计替换了17个非唯一和10个视觉无效项。
  - **评估指标**：四阶段指标链匹配任务链：意图匹配（IM）、邻域可达性（OSR）、终端成功（SR）、接地成功（GSR）。诊断间隙：ginfer = IM − SR, gterm = OSR − SR, gprec = SR − GSR。
  - **参考智能体**：固定模块化导航策略，使用VLM估计目标可见性和探索方向，结合开放词汇检测（Grounding DINO）、地图规划和终止条件。仅替换VLM后端进行对比。

## 3. 实验设计
- **数据集/场景**：
  - 使用VLNVerse模拟环境下的176个Isaac Sim室内场景（客厅、卧室、浴室、厨房等）。
  - 精选500个意图，覆盖64个目标类别（电器133、小物体115、大型家具113、照明/装饰81、浴室物体58）。
- **Benchmark**：IntentionNav本身即为诊断基准，包含配对的语言轴和评估协议。
- **对比方法**：评估三个VLM作为智能体的VLM后端：GPT-5.4、Qwen3.6-Plus、Gemini-3.1-Flash-Lite。所有模型共享相同参考智能体、提示、检测器、地图构建和终止条件，仅VLM不同。
- **实验配置**：每个模型在全部500个意图×4种风格=2000个episode上进行零样本评估。额外进行了显式目标消融实验（将隐含意图替换为目标类别）以隔离意图推断贡献。

- 未提及训练成本（所有模型为零样本推理），仅报告了推理计算量。

## 5. 实验数量与充分性
- **实验数量**：主实验3个模型×2000 episode = 6000次运行；显式目标消融（Gemini formal设置）额外500 episode；风格和模式分层分析；诊断间隙分解；半径敏感性（1m/2m/3m）；交叉风格稳定性（CSR）。共计约10余组实验分析。
- **充分性与客观性**：实验设计系统，覆盖多个维度（风格、模式、间隙、半径、消融）。固定导航策略仅换VLM，确保公平对比。但是，仅评估3种VLM，且均使用同一参考智能体（非端到端方法），可能无法代表所有架构；但作者明确声明不作为模型排名，而是诊断意图链瓶颈。实验较充分。

## 6. 主要结论与发现
- **意图推断和邻域可达远优于终端成功**：总体IM=0.483，OSR=0.687，SR=0.249，GSR=0.055。间隙分析显示：gterm（0.438）是最大瓶颈，远超ginfer（0.234）和gprec（0.194）。智能体常进入目标邻域但未能正确终止。
- **显式目标消融**：提供目标类别时SR提升16.8个百分点（0.448），但GSR仍仅0.124，说明视觉证据收集和近距离定位仍是严重瓶颈。
- **意图模式影响显著**：事件脚本意图成功率最高（0.287），物理状态和功能意图最低（0.192/0.185），表明推理难度差异大。
- **指令风格影响较小**：平均SR跨风格仅差2.8个百分点，但每项意图的四风格一致成功率（CSR）仅5.6-9.6%，暴露逐例不一致性。
- **三个VLM结果非常接近**：SR仅1.6个百分点差异，突出共同瓶颈而非模型差异。

## 7. 优点
- **诊断性设计**：通过配对语言轴（风格×模式）和阶梯式指标链，可精准定位失败链中的具体环节（意图推断、视觉验证、近距离定位），而不仅仅是整体成功。
- **高质量数据**：严格的人工验证和唯一性过滤，防止词汇泄漏和歧义，确保基准测试的是真实的意图理解而非表面匹配。
- **可控性**：固定场景、起始位姿、导航策略，仅变VLM，且风格变体共享相同几何，使结果可归因于语言因素。
- **透明性与可复现**：提供了详细的构建流程、验证标准、同义词词表、评估协议和代码（包括提示、配置），便于后续研究者使用和扩展。

## 8. 不足与局限
- **实验覆盖有限**：仅评估3种VLM（且均为商业闭源模型），缺少对开源VLM、端到端学习式智能体、不同检测器或规划策略的对比；可能不足以概括全貌。
- **场景与任务限制**：只使用静态公寓场景、英语单目标指令、无对话交互、固定30步预算、单一参考智能体。不涉及多语言、多目标、互动或真实家庭部署。
- **指标依赖**：IM依赖于有限同义词表，可能低估意图理解；自动评判和改写也可能引入偏差。指标未完全覆盖“接近但未正确确认”的情况。
- **仿真到现实鸿沟**：仿真中纹理、光照、传感器噪声与真实环境存在差异，结论推广需谨慎。
- **伦理考虑**：论文指出隐含意图可能导致不安全假设，但未进行实际安全性或公平性分析。
- **资源报告不够全面**：仅报告了推理耗时，未提供模型参数量、内存占用等细节。
