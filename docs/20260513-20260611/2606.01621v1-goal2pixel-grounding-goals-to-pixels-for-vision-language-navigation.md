## 摘要
视觉语言模型（VLM）已成为连续环境中视觉语言导航（VLN-CE）的常见基础。然而，大多数基于VLM的方法将导航视为低级动作预测，这种接口具有歧义性、依赖于短视运动基元，并且由于重复的VLM查询而效率低下。我们提出Goal2Pixel，一种纯像素的范例，将VLN-CE重新表述为可导航像素锚定。Goal2Pixel不是预测动作，而是将图像平面作为VLM推理与机器人运动之间的统一空间接口：模型预测一个对智能体可见的可导航像素，该像素被反向投影为3D航点以进行前向导航。对于非前向动作，我们在图像平面上附加辅助指令区域，其中左/右/下区域分别被解释为左转、右转和停止。为了实现长视距导航，我们提出一种可见性感知的关键帧记忆，用于紧凑且信息丰富的历史表示。为了将预训练的VLM适应于可导航像素锚定，我们引入语义嵌入和坐标感知辅助损失。Goal2Pixel在达到竞争性最新性能的同时，所需的VLM推理调用次数少于先前方法。在R2R-CE Val-Unseen上，它以每次情节仅7.75次VLM调用实现了54.1%的SR和52.5%的SPL，比直接动作预测（32.9% SR需要46.62次调用）少了6倍。同样的趋势在RxR-CE上成立。项目页面：https://baobao0926.github.io/Goal2Pixel/。

## Abstract
Vision-language models (VLMs) have become a common foundation for vision-and-language navigation in continuous environments (VLN-CE). Yet most VLM-based methods cast navigation as low-level action prediction, an interface that is ambiguous, tied to short-horizon motion primitives, and inefficient due to repeated VLM querying. We propose Goal2Pixel, a pure pixel-based paradigm that reformulates VLN-CE as navigable pixel grounding. Rather than predicting actions, Goal2Pixel uses the image plane as a unified spatial interface between VLM reasoning and robot motion: the model predicts a visible navigable pixel to the agent, which is back-projected into a 3D waypoint for forward navigation. For non-forward actions, we append auxiliary directive regions to the image plane, where the left/right/bottom regions are interpreted as turning left, turning right, and stopping, respectively. To enable long-horizon navigation, we propose a visibility-aware keyframe memory for compact and informative history representation. To adapt pretrained VLMs to navigable pixel grounding, we introduce semantic embeddings and coordinate-aware auxiliary losses. Goal2Pixel achieves competitive state-of-the-art performance while requiring fewer VLM inference calls than prior methods. On R2R-CE Val-Unseen it achieves 54.1% SR and 52.5% SPL with just 7.75 VLM calls per episode, 6x fewer than the 46.62 required by direct action prediction at 32.9% SR. The same trend holds on RxR-CE.Project Page: https://baobao0926.github.io/Goal2Pixel/.

## 1. 核心问题与整体含义（研究动机和背景）
- **现有缺陷**：视觉语言模型（VLM）应用于连续环境中的视觉语言导航（VLN-CE）时，主流方法将导航任务建模为**低级动作预测**（如左/右转15°、前进25cm、停止）。这种接口存在三大根本问题：
  - **歧义性**：同一目标可通过多种动作序列达成，使得专家轨迹作为训练目标过于严格。
  - **短视**：优化下一小步移动而非长程空间推理。
  - **高推理成本**：每次预测仅推进几厘米或几度，导致每个情节需调用VLM数十次（如46.62次）。
- **核心问题**：如何设计VLM推理与机器人可执行运动之间的**合适接口**？
- **整体含义**：提出纯像素范式**Goal2Pixel**，将导航重构为**可导航像素接地**，把图像平面作为统一空间接口，一个像素即可锚定前向导航目标，并可通过相机几何反投影为3D航点，非前进动作由图像四周的辅助区域编码。从而简化接口、提升效率和长程规划能力。

## 2. 方法论：核心思想、关键技术细节、算法流程
### 核心思想
- 将VLN-CE转换为像素级目标预测：VLM输出一个像素坐标字符串“XXX, YYY”。
- **前向导航**：若像素落在常规RGB区域，通过相机几何（带深度）反投影为3D航点，由轻量局部规划器执行至多5步低层动作。
- **非前向导航**：在图像左、右、下侧附加辅助指令区域，左/右/下区域分别解释为左转、右转、停止。所有动作统一在像素预测接口中。

### 关键技术细节
1. **数据收集**：从R2R-CE和RxR-CE训练集构建2.64M样本（每样本：指令+当前图像+历史图像+目标像素）。
   - **真值像素构造**：取沿着专家轨迹的**最远可见未来航点**投影到当前图像，并检查投影-反投影一致性（误差<0.6m）。当终点<1.0m时，像素分配到底部辅助区域（停止）；当无未来航点可见时，根据平均方向分配到左/右辅助区域（转向）。
2. **ViKeyMem（可见性感知关键帧记忆）**：
   - 用于构建紧凑历史记忆。条件：候选帧对后续航点可见性变化明显，且至少两个后续航点落在45°前向视场内。
   - 通常每个情节仅保留4-5个关键帧（100步内），并在每帧上绘制蓝色轨迹点表示过去运动轨迹。
   - 无需额外网络模块，可即插即用。
3. **视觉语义嵌入**：为辅助区域和轨迹叠加token添加可学习的语义嵌入，帮助预训练VLM区分导航特定模式。
4. **训练目标**：
   - 主损失：标准token级交叉熵损失 \( L_{CE} \)。
   - 辅助损失：利用生成logits获得可微的**软预测坐标**，然后计算：
     - **数值损失** \( L_{num} \)：L1距离（归一化到[0,1]）。
     - **角度损失** \( L_{ang} \)：1 - cos(预测方向与真值方向之差)，方向从图像底边中心锚点(0.5,1.0)指向像素。
   - 最终损失：\( L = L_{CE} + \lambda_{num} L_{num} + \lambda_{ang} L_{ang} \)，权重分别为0.3和0.03。
5. **推理流程**：
   - VLM每步预测一个像素 → 若在常规区域，反投影为3D航点 → 局部规划器执行至多5步低层动作 → 重复直至停止或达到最大长度。
   - 防振荡机制：若连续20步左右振荡，强制输出前向偏置像素(500,970)。
