## 摘要
物体导航要求机器人在未知环境中搜索未观察到的目标，通过在部分可观测条件下决定下一步探索的位置。有效的搜索类似于人类探索：选择性探索视觉上有希望的前沿，同时依赖空间记忆以避免重复访问。我们提出IntentNav，这是一个空间-视觉模仿框架，能够从人类演示中学习类人的物体导航策略。为了从低级人类动作中推断高级搜索意图，我们引入了基于前沿的人类意图标注，该方法前瞻人类演示，并标注最能解释演示者未来搜索方向的前沿。我们构建了一个空间-视觉候选空间，其中BEV记忆跟踪已探索区域、未探索前沿和轨迹历史，而自我中心视觉记忆为每个候选提供语义线索。训练了一个VLM策略，在这些有依据的候选中进行选择，使用意图对齐目标来鼓励一致且类人的探索。IntentNav在MP3D、HM3D-v1和HM3D-v2物体导航基准上取得了最先进的性能。所提出的候选级导航接口无需进一步的VLM微调即可零样本迁移到轮式、四足和人形机器人。\href{https://anonymous.4open.science/w/IntentNav/}{项目页面}。

## Abstract
Object navigation requires a robot to search for an unobserved target in an unknown environment by deciding where to explore next under partial observability. Effective search resembles human-like exploration: selectively probing visually promising frontiers while relying on spatial memory to avoid redundant revisits. We propose IntentNav, a spatial-visual imitation framework that learns human-like ObjectNav policies from human demonstrations. To infer high-level search intent from low-level human actions, we introduce Frontier-based Human-Intent Labeling, which looks ahead in human demonstrations and labels the frontier that best explains the demonstrator's future search direction. We construct a spatial-visual candidate space, where BEV memory tracks explored regions, unexplored frontiers, and trajectory history, while egocentric visual memory provides semantic cues for each candidate. A VLM policy is trained to select among these grounded candidates, using Intent-Aligned Objective to encourage consistent and human-like exploration. IntentNav achieves state-of-the-art performance on the MP3D, HM3D-v1 and HM3D-v2 ObjectNav benchmarks. The proposed candidate-level navigation interface transfers zero-shot to wheeled, quadruped, and humanoid robots without further VLM fine-tuning. \href{https://anonymous.4open.science/w/IntentNav/}{Project page}.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究问题**：物体导航（ObjectNav）要求机器人在未知环境中、在部分可观测条件下自主搜索并导航到目标物体实例。现有方法（尤其是基于VLM的方法）缺乏长时程、目标导向的类人搜索策略：它们或依赖于第一人称RGB图像而丢失全局空间结构，或依赖文本化地图总结而丢失几何细节与视觉上下文，导致决策短视、重复回溯（如原地打转、反复检查同一区域）。
- **核心动机**：人类擅长利用空间记忆与视觉线索进行高效、有方向的搜索（如先判断厨房区域再找杯子），因此学习人类演示中的**高层搜索意图**是提升ObjectNav性能的关键。
- **整体含义**：本文提出IntentNav——一个从人类演示中学习的空间-视觉模仿框架，旨在让机器人像人类一样：选择性探索视觉上有希望的前沿，同时利用空间记忆避免冗余重访，从而实现稳定、高效、可迁移的长时程搜索。

## 2. 方法论

### 2.1 核心思想
- 将ObjectNav建模为**BEV（鸟瞰图）空间中的候选级路径点选择**：每个决策时间步，从BEV地图中提取一组候选（包括前沿候选和目标候选），每个候选关联其首次观测时的自我中心RGB图像（视觉记忆）和**智能体中心相对几何特征**（距离、相对方位）。
- 从人类低层动作序列中恢复**高层搜索意图**，通过“未来前沿演变”自动标注哪个候选最能解释演示者的后续探索方向。
- 训练VLM策略在候选集合中选择下一个路径点，使用**意图对齐目标函数**（方向平滑+硬分类）鼓励决策方向一致性和目标承诺。

### 2.2 关键技术细节

#### A. 基于前沿的人类意图标注（Frontier-based Human-Intent Labeling）
- 在人机演示回放中，若当前候选集存在已验证的目标候选，直接使用其索引作为监督。
- 否则，通过**前沿演变**推断意图：从当前步进t向前推进至少6个前进动作，找到最早步骤t⁺，其中至少有一个当前前沿与未来前沿集不匹配（距离大于阈值σ_evo）。
- 选择距离未来前沿集最远的当前候选（即该候选最不可能在未来前沿集中出现）作为意图标签，因为演示者很可能已经穿过该区域。

#### B. BEV底层的空间-视觉候选策略
- **BEV地图**：维护全局栅格地图（分辨率0.05m，范围67.2m×67.2m），包含占用层、已探索层、智能体足迹、轨迹历史。每次裁剪22.4m×22.4m的局部BEV作为输入。
- **候选视觉记忆**：每个候选关联其首次被实例化时的自我中心RGB图像（224×224），提供局部视觉上下文（房间类型、附近物体等）。
- **智能体中心几何特征**：归一化距离、相对方位的正弦和余弦值。
- **VLM输入**：共享的BEV图像 + 序列化的候选块（每个块包含候选ID、视觉记忆图像、几何特征）。使用双ViT路径分别处理BEV和ego图像。
- **候选ID令牌**：预留32个特殊令牌<id 0>–<id 31>，将路径点预测转化为受限候选分类。

#### C. 意图对齐目标函数
- **角度软目标**：对除目标候选外的所有候选，根据相对于标注候选的方位角差构造软标签（高斯分布，带宽σ=25°），使得方向相近的候选获得部分奖励，方向差异大的候选受惩罚。
- **损失组合**：当标签为前沿候选时，结合硬交叉熵（监督GT候选）和角度软交叉熵（λ=0.3）；当标签为目标候选时，仅使用硬交叉熵以鼓励决定性承诺。

### 2.3 算法流程（文字说明）
1. 在每个决策步t，接收RGB-D观测，更新全局BEV地图M_t。
2. 提取前沿候选（已探索/未探索边界）和已确认的目标候选，组成候选集C_t。
3. 每个候选i关联：首次观测时的ego RGB图像I_ego_i，和智能体中心相对几何特征f_i。
4. 构造VLM输入：固定系统指令 + BEV图像 + 序列化候选块（包含ID、类型、坐标、视觉记忆图像）。
5. VLM预测候选ID令牌，策略选择对应路径点。
6. 路径点交由平台特定的局部规划器执行，直到接近路径点触发下一次查询。

## 6. 主要结论与发现

1. **从人类演示中学习高层搜索意图**显著优于纯VLM推理或最短路径监督，尤其在长时程探索效率上。
2. **BEV底层的空间-视觉候选空间**提供了一个统一、结构化的决策接口，有效融合了全局空间拓扑与局部视觉证据，相比文本坐标或第一人称行动预测更可靠。
3. **前沿意图标注（Future Frontier Evolution）**是恢复意图监督的关键，优于简单的姿态匹配或轨迹匹配。
4. **意图对齐目标函数**（方向平滑+硬分类相结合）能同时促进方向一致的探索和决定性的目标承诺。
5. IntentNav实现了学习策略中最先进的SR/SPL，且候选级界面无需额外微调即可零样本迁移到轮式、四足、人形机器人。

## 7. 优点

- **方法创新性**：
  - 首次将人类演示中的搜索意图显式建模为前沿演变，并转化为候选级监督。
  - BEV+视觉记忆+几何特征的三元候选表示简洁有效，避免了复杂场景图或多步提示。
  - 目标函数设计巧妙，平衡探索方向一致性与目标承诺。
- **实验结果**：
  - 在三大基准上大幅超越先前学习策略（如HM3D-v2上SR从73.7%提升到82.2%）。
  - 丰富的消融实验和搜索行为分析（ECR/RRR等）揭示了方法如何实现类人行为。
- **跨平台迁移**：同一训练策略直接部署到三个物理机器人（轮式、四足、人形），展示了良好的通用性，无需领域微调。
- **效率**：低频候选ID预测（约0.8秒/次）并可与运动重叠，支持实时部署。

## 8. 不足与局限

- **静态环境假设**：BEV地图和候选出生视图记忆假设环境静态，动态变化（如移动的人或物体）会导致前沿提取和候选排名过时，论文未处理。
- **高/低级反馈缺失**：路径点选择与局部规划/控制完全解耦，执行失败、绕路或局部规划器约束不会被反馈到VLM策略。论文承认这是未来方向。
- **训练数据局限**：仅使用MP3D场景的Habitat-Web演示进行训练，尽管零样本迁移到HM3D效果好，但未在更多样化的真实室内场景（如办公、仓库、户外）验证。
- **目标检测依赖**：在评估和部署中依赖在线物体检测器（YOLOE），其可靠性直接影响目标候选正确性，论文虽设计了验证流程（连续3帧检测、持久化检查），但检测器在低光照或遮挡下的失败风险未量化。
- **实验覆盖**：真实世界测试仅10个场景、8个类别，且缺乏与其他真实机器人部署方法的定量对比。论文未提供真实世界的SR/SPL数据。
- **计算资源**：VLM推理在RTX 4090上约0.8-1.4秒，对更轻量化边缘部署（如Jetson）可能不现实。LoRA微调需要4块A100，对资源有限团队有门槛。
- **未与最新方法全面比较**：虽然对比了许多方法，但部分2025-2026年同期工作（如OmniNav、Uni-Navid）已更新，可能存在未覆盖的更强基线。
