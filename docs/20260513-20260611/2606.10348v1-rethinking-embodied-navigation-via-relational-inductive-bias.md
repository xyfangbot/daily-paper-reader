## 摘要
目标导航要求智能体通过视觉观察在未知环境中定位目标。现有方法通常依赖开放词汇检测器或视觉语言模型（VLM）来回答在哪里搜索，但往往忽略了哪些语义线索不可靠。开放词汇感知容易产生系统性误导证据：误报、过时的静态先验以及因缺乏具身验证而导致的重复失败探索，这会污染地图构建和决策。此类错误源于真实场景中的结构化对象关系。为解决这一问题，我们提出DB-Nav框架，通过双重关系偏置重塑搜索空间。它将目标中心关系分解为激活偏置（传播上下文证据）和抑制偏置（通过感知混淆和行动级证伪抑制不可靠区域）。这些偏置统一到关系激活-抑制探索图中，利用在线观察和失败访问调整前沿探索值。在ObjectNav基准上的实验表明，DB-Nav在成功率（SR）和路径长度加权成功率（SPL）上显著优于现有方法，提供了一个轻量级、可解释且鲁棒的导航框架，无需昂贵的在线VLM推理。

## Abstract
Object navigation requires an agent to locate a target in an unknown environment through visual observations. Existing methods typically rely on open-vocabulary detectors or vision-language models (VLMs) to answer where to search, but often overlook what not to trust - which semantic cues are unreliable. Open-vocabulary perception is prone to systematic misleading evidence: false positives, outdated static priors, and repeated failed exploration due to lack of embodied verification, which contaminates mapping and decision-making. Such errors are rooted in structured object relations in real-world scenes. To address this, we propose DB-Nav, a framework that reshapes the search space via dual relational biases. It factorizes target-centric relations into an Activation Bias (propagates contextual evidence) and an Inhibition Bias (suppresses unreliable regions via perceptual confusion and action-level falsification). These biases are unified into a Relational Activation-Inhibition Exploration Graph that modulates frontier exploration values using online observations and failed accesses. Experiments on ObjectNav benchmarks show that DB-Nav significantly outperforms existing methods in success rate (SR) and Success weighted by Path Length (SPL), offering a lightweight, interpretable, and robust navigation framework without costly online VLM reasoning.

- **根源**：此类错误并非随机噪声，而是源于真实场景中对象关系的结构化偏差（如共现关系与混淆关系）。
- **动机**：需要一种机制同时利用正面的关系线索（共现激活）和抑制负面的关系线索（视觉混淆、失败访问），动态重塑搜索空间，而不是将所有语义证据视为同等有益。

## 2. 论文提出的方法论
### 核心思想
- 提出 **DB-Nav**（Dual Bias Navigation）框架，将目标中心的对象关系分解为两种协同偏置：
  - **激活偏置（Activation Bias）**：通过上下文共现传播正面搜索证据，指示值得探索的区域。
  - **抑制偏置（Inhibition Bias）**：通过显式建模感知混淆和行动级证伪（failed access）抑制不可靠区域。
- 两种偏置统一到**关系激活–抑制探索图（Relational Activation–Inhibition Exploration Graph）**中，将在线视觉观察和失败访问事件转换为语义源，动态调整前沿（frontier）的探索价值。

### 关键技术细节
1. **目标中心关系偏置构建**
   - 为每个目标相关类别 ℓ 分配三维类别–角色向量 \( b_g(\ell) = [c_g(\ell), a_g(\ell), i_g(\ell)]^\top \in \{0,1\}^3 \)：
     - \( c_g(\ell)=1 \)：目标承诺证据（目标类别及其同义词）
     - \( a_g(\ell)=1 \)：正面搜索激活（上下文共现类别）
     - \( i_g(\ell)=1 \)：负面抑制（视觉相似干扰物）
   - 在线感知输出对象观测 \( d_i = (p_i, s_i, \ell_i) \)，通过多视图累积和**多标签对象角色竞争**确定对象的主导标签 \( \ell^*_o \) 和证据强度 \( r_o \)，得到对象级关系证据 \( h_o = r_o b_g(\ell^*_o) \)。

2. **关系激活–抑制传播**
   - 构建局部关系图 \( G_t = (V_t, E_t) \)，包含对象证据节点、上下文假设节点、负面证据节点和候选前沿。
   - 空间传播核 \( \kappa(p_v, p_u) = \exp(-\frac{\|p_v-p_u\|^2}{R}) \cdot \mathbb{I}[\|p_v-p_u\|^2 \le R] \)（距离衰减，局部邻域）。
   - 前沿 \( f \) 的**激活值** \( A_t(f) \)：来自目标承诺对象和上下文假设节点的传播。
   - 前沿 \( f \) 的**抑制值** \( I_t(f) \)：来自干扰物对象和负面证据节点（失败访问事件）的传播。

3. **偏置条件探索与目标承诺**
   - 前沿最终得分：\( \tilde{S}_t(f) = \frac{S_t^0(f) + A_t(f)}{1 + I_t(f) + \bar{C}_t(f)} \)，其中 \( S_t^0 \) 为基线语义响应，\( \bar{C}_t \) 为归一化路径代价。
   - 目标承诺：当对象级目标承诺证据 \( h_{c_0^*,t} \ge \theta \)（阈值）时，切换到目标搜索规划器（TSP）直接接近目标，避免过早停止。

## 7. 优点
- **轻量高效**：无需任何训练或在线LLM/VLM推理，每episode仅需约102秒，远低于依赖LLM的方法。
- **可解释性**：激活和抑制偏置来源于显式的对象关系，可直观理解前沿得分变化。
- **鲁棒性**：通过多标签竞争和失败访问记忆，有效抵抗开放词汇感知下的误报、漏检和视觉混淆。
- **模块化**：可灵活替换感知模块（不同检测器），且对不同检测器均能提升性能。
- **零样本泛化**：无需在目标数据集上训练，预定义关系规则（或由LLM生成）即可直接部署。
- **双偏置平衡**：同时处理正面和负面证据，避免了传统方法过度依赖正面语义的倾向。
