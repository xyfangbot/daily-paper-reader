## 摘要
未知室内环境中的自主机器人需要可靠的碰撞避免和对象级理解。经典表示如TSDF支持安全规划但缺乏语义，而像高斯泼溅（GS）这样的逼真方法提供了丰富的视觉外观但存在软几何问题，限制了精确的障碍物避免。我们提出了LiftNav，一种基于GSFusion的TSDF+GS双地图的混合导航框架，并增强了基于YOLO的检测、基于TSDF的3D提升和B样条轨迹优化的实时流水线。这种设计无需密集的3D嵌入即可实现灵活的语义导航。我们进一步引入了一种基于铰链损失的碰撞惩罚，以提高轨迹平滑性和安全性。我们在使用Replica数据集的仿真中评估了我们的方法。与最先进的辐射场基线相比，我们展示了100%的可行率和更短的轨迹。

## Abstract
Autonomous robots in unknown indoor environments require both reliable collision avoidance and object-level understanding. Classical representations such as TSDF support safe planning but lack semantics, while photorealistic methods like Gaussian Splatting (GS) provide rich appearance yet suffer from soft geometry, limiting precise obstacle avoidance. We present LiftNav, a hybrid navigation framework built on GSFusion's TSDF+GS dual map, augmented with a real-time pipeline of YOLO-based detection, TSDF-based 3D lifting, and B-spline trajectory optimization. This design enables flexible semantic navigation without dense 3D embeddings. We further introduce a hinge-loss-based collision penalty that improves trajectory smoothness and safety. We evaluate our approach in a simulation using the Replica dataset. Compared against a state-of-the-art radiance field baseline we show a 100% feasibility rate and shorter trajectories.

## 2. 论文提出的方法论：核心思想、关键技术细节
### 核心思想
- **混合表示**：利用GSFusion同时维护TSDF（精确几何）和GS（逼真外观）双地图，避免单一表示的局限。
- **轻量语义提升**：不将语义嵌入3D高斯体（计算量大），而是通过实时2D检测（YOLOv8n-seg）+ 深度反投影 + DBSCAN聚类，从多视角图像中在线提取目标3D质心作为导航路点。
- **连续时间轨迹优化**：使用均匀B样条参数化路径，在TSDF梯度场上进行多目标优化，并引入**铰链损失碰撞惩罚**，实现平滑且安全的轨迹。

### 关键技术细节
1. **语义映射**：
   - 每帧RGB-D图像经YOLO检测得到2D边界框和类别。
   - 对每个检测框内的像素，利用GSFusion融合深度图和相机位姿，通过公式 \(p_W = T_{WB} \left(D(u,v) K^{-1} [u,v,1]^T\right)\) 反投影到3D世界坐标。
   - 取掩码区域的中位数作为该检测的3D质心，避免边界深度噪声。
   - 多视角累积点云后，对每个语义类别使用**DBSCAN**聚类，剔除稀疏噪声点，得到稳定实例质心作为航点。

2. **轨迹优化**：
   - **参数化**：\(p\)阶（通常\(p=8\)）均匀B样条，保证\(C^{p-1}\)连续性，平滑速度、加速度、加加速度。
   - **初始化**：先对3D占用网格（带1.5×机器人半径膨胀层）执行A*搜索得到骨架路径，再采样作为B样条控制点的初始值。
   - **目标函数**：\(J(Q) = w_{coll}L_{coll} + w_{dist}L_{dist} + w_{acc}L_{acc} + w_{jerk}L_{jerk}\)。
     - \(L_{coll}\)：复合碰撞损失，包含**铰链损失**（当距离\(d(p)\)小于安全裕度\(m\)时强推开）和指数项（在裕度外保持小梯度），公式为 \(\sum [\max(0,1-d(p)/m) + \alpha \exp(-\beta d(p))]\)。
     - \(L_{dist}\)：相邻控制点间欧氏距离平方，促进路径短。
     - \(L_{acc}, L_{jerk}\)：加速度和加加速度平方，约束动力学。
   - **后处理**：因语义目标质心常位于障碍物内部，优化后B样条路径两端截断1.5×机器人半径，再线性连接至实际起终点，保证安全且公平对比。

- **语义陷阱问题**：LiftNav能100%规划出路径，但会牺牲末端安全裕度（到达目标质心时平均裕度0.01m），导致严格成功率仅79%；而SplatNav在语义场景可行率大幅下降（如office3仅41%）。

## 7. 优点：方法或实验设计上的亮点
- **轻量语义提升**：将2D检测投影到TSDF几何上，无需训练3D语义GS，大幅降低计算和存储开销，适用于在线系统。
- **铰链碰撞损失设计**：结合硬边界（hinge）和软梯度项，避免SFC方法因拓扑约束而失败，同时保证优化连续。
- **双地图融合**：GSFusion同时输出TSDF和GS，一举两得，比单一GS+后处理成凸包更高效（重建时间相当，但规划时无需额外几何推导）。
- **B样条连续优化**：自然保证高阶平滑，且局部可控，优于分段线性或Bezier轨迹。
- **公平比较**：两端截断+线性连接操作，确保与SplatNav在路径长度指标上的公平性。
