## 摘要
在这项工作中，我们提出了一个结合多智能体强化学习（MARL）与模型控制的方法框架，以实现协同多智能体任务中安全且动态可行的动作。多智能体强化学习具有在长期规划中从离散不可微奖励中学习多智能体团队协作策略的优势。模型预测控制则具有鲁棒性，并在快速重规划的短时域框架中提供安全、动态可行的动作。我们提出了一种将演员-评论家模型预测控制扩展到MARL的算法，称为多智能体演员-评论家模型预测控制（MA-AC-MPC）。通过将其应用于多智能体追捕-逃避场景，我们展示了该算法的能力。具体而言，我们比较了使用MA-AC-MPC模型和多层感知器模型（MA-AC-MLP）的逃避者团队策略。追捕者团队采用增强比例导引法，因其被公认为先进的对抗控制律。我们还提供了一个异构环境的示例，其中无人机和全向轮式机器人协作实现可重复且成功的着陆：MA-AC-MPC在硬件上的成功率为100%，而MA-AC-MLP仅为60%。我们在硬件上证明了所提出的MA-AC-MPC算法在两种环境中的鲁棒性。

## Abstract
In this work, we propose a framework that combines multi-agent reinforcement learning (MARL) with model-based control to achieve safe, dynamically feasible actions in cooperative multi-agent tasks. Multi-agent reinforcement learning provides the advantage of learning cooperative policies for multi-agent teams from discrete non-differentiable rewards in a long planning horizon. Model-predictive control is robust and offers safe, dynamically feasible actions in a fast replanning framework for short horizons. We propose an algorithm that extends actor-critic model predictive control for MARL which we refer to as multi-agent actor-critic model predictive control (MA-AC-MPC). We demonstrate the capabilities of this algorithm by applying it to a multi-agent pursuit-evasion scenario. Specifically, we compare the evader team's strategy using the MA-AC-MPC model and a multi-layer perceptron model (MA-AC-MLP). The pursuer team uses augmented proportional navigation as it is accepted as an advanced adversarial control law. We also provide an example with a heterogeneous environment where a drone and omni-wheeled rover cooperate to achieve repeatable and successful landing with 100% success rate in hardware for MA-AC-MPC compared to 60% for MA-AC-MLP. We demonstrate the robustness of the proposed MA-AC-MPC algorithm in hardware for both environments.

#### 2. 方法论
*   **核心思想**：将单智能体的**演员-评论家模型预测控制 (AC-MPC)** 扩展到多智能体场景，提出**多智能体演员-评论家模型预测控制 (MA-AC-MPC)**。其核心是构建一个层次化的Actor网络：第一层（上层）是神经网络，作为“规划器”，输出MPC所需的关键参数（如参考轨迹、权重矩阵）；第二层（下层）是一个可微分的MPC求解器，作为“执行器”，接收上层参数并基于物理模型和约束计算出最终的安全、可行控制动作。
*   **关键技术与算法流程**：
    1.  **策略架构**：采用**集中式训练与分布式执行 (CTDE)** 范式。训练时使用一个全局Critic网络来评估联合策略；执行时每个智能体独立运行自己的Actor-MPC模块，仅依赖局部观测。
    2.  **Actor设计**：每个智能体的Actor分为两层：
        *   **成本网络 (Cost Network)**：一个神经网络，学习输出MPC的时变参考和权重矩阵。
        *   **可微分MPC求解器**：使用基于 `acados` 的开源库 `leap-c`，它能高效求解带非线性约束的最优控制问题，并支持梯度反向传播。这使得整个Actor成为一个端到端的可微分模块。
    3.  **训练算法**：使用**多智能体近端策略优化 (MAPPO)** 进行训练。训练期间，Critic使用全局状态信息评估动作价值。Actor的梯度可以通过可微分的MPC层反向传播到成本网络中，从而端到端地学习MPC的参数。
    4.  **死亡掩码 (Death Masking)**：当智能体在追踪-逃避任务中被捕获或“死亡”时，将其观测和状态向量置零，并添加活跃标志，以稳定Critic训练。
    5.  **课程学习 (Curriculum Learning)**：为复杂任务设计从易到难的课程，逐步增加环境参数（如初始间距、扰动强度）的难度，辅助模型稳定学习。

*   **效率解释**：由于将低层动力学和安全可行性问题“外包”给了MPC，神经网络可以专注于学习更抽象的策略（如路径规划、协作配合），从而提高了表征效率和样本效率。

#### 8. 不足与局限
*   **计算效率**：这是MA-AC-MPC最明显的局限。由于引入了一个可微分的MPC求解器，其**训练时间**是纯MLP方法的数倍（甚至十余倍），且目前无法利用GPU加速。这限制了其在需要快速原型设计或大规模超参数搜索场景下的适用性。

*   **方法对比范围**：论文主要与自身提出的MLP基线对比。虽然在引言中提及了其他MARL与MPC结合的方法（如Mallick等的方法，采用分布式MPC贡献价值函数），但在实验部分并未将其作为基线进行对比，使得性能优势的证明不具备完全的排他性。
