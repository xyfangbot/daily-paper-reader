## 摘要
视觉-语言-动作（VLA）模型在基准测试中取得了强劲表现，但在真实世界部署中仍面临困难，包括未见过的物体、背景变化以及不同的机器人实体。我们认为，这源于缺乏统一的几何感知操作表示，使得现有的VLA模型容易受到低级轨迹监督、不对齐的3D特征以及实体差异的影响。为了解决这一问题，我们提出了GEAR-VLA，一个用于学习统一的几何感知动作表示以实现泛化机器人操作的VLA框架。GEAR-VLA采用从粗到细的动作学习，通过多源具身预训练为VLM赋予具身推理和离散动作理解能力，然后通过潜在动作标记将动作语义连接到梯度解耦的DiT连续动作专家。它进一步通过将可训练的3D空间骨干与VLA表示对齐，同时冻结原始的VLM对齐视觉通路，执行语义对齐的3D集成。为了在机器人之间共享这一表示，GEAR-VLA使用了实体规范化，其中实体感知状态和实体不变动作将机器人差异限制在低级接口。大量的仿真和真实世界实验证明了强大的泛化能力：GEAR-VLA在LIBERO、零样本LIBERO-Plus和RoboTwin 2.0上达到了最先进的性能，在AgileX上达到了85.9%的成功率，在预训练未见过的LDT-01实体上达到了81.0%，并在包含212个未见物体的6360次试验通用抓取基准测试中获得了90.1%的成功率。代码和模型将在https://github.com/babynabeauty/GEAR-VLA发布。

## Abstract
Vision-Language-Action (VLA) models achieve strong benchmark performance but still struggle in real-world deployment with unseen objects, background shifts, and different robot embodiments. We argue that this stems from the lack of a unified geometry-aware manipulation representation, leaving existing VLAs vulnerable to low-level trajectory supervision, misaligned 3D features, and embodiment differences. To address this, we propose GEAR-VLA, a VLA framework for learning unified geometry-aware action representations for generalizable robotic manipulation. GEAR-VLA adopts coarse-to-fine action learning, where multi-source embodied pretraining equips the VLM with embodied reasoning and discrete action understanding before latent action tokens connect action semantics to a gradient-decoupled DiT continuous action expert. It further performs semantic-aligned 3D integration by aligning a trainable 3D spatial backbone with the VLA representation while freezing the original VLM-aligned visual pathway. To share this representation across robots, GEAR-VLA uses embodiment canonicalization, where embodiment-aware states and embodiment-invariant actions confine robot differences to the low-level interface. Extensive simulation and real-world experiments demonstrate strong generalization: GEAR-VLA achieves state-of-the-art performance on LIBERO, zero-shot LIBERO-Plus, and RoboTwin 2.0, reaches 85.9% success on AgileX and 81.0% on the pretraining-unseen LDT-01 embodiment, and obtains 90.1% success on a 6,360-trial universal grasping benchmark with 212 unseen objects. Code and models will be released at https://github.com/babynabeauty/GEAR-VLA.

# GEAR-VLA: 学习几何感知的动作表示以实现泛化机器人操作

## 1. 论文的核心问题与整体含义

- **研究动机**：现有的视觉-语言-动作（VLA）模型在标准基准测试中表现良好，但在真实世界部署中泛化能力不足，尤其在面对**未见物体、背景变化、不同机器人本体**时。作者指出，根本原因在于缺乏**统一的几何感知操纵表示**，导致三个关键缺口：
  - 动作表示缺口：基于动作标记的 VLA 倾向于轨迹拟合，而非具身推理。
  - 空间表示缺口：2D 视觉特征与 3D 几何信息未对齐，难以实现几何感知操作。
  - 本体表示缺口：不同机器人间的差异被引入共享表示层，降低跨本体迁移效率。
- **整体目标**：提出 GEAR-VLA，旨在学习一种**统一的、几何感知的动作表示**，该表示同时具备语义基础、几何意识，并将本体特异性限制在低级接口，从而提升对未见物体、场景和机器人本体的泛化能力。

## 2. 论文提出的方法论

### 核心思想
GEAR-VLA 通过**三个核心设计**实现统一几何感知动作表示：
1. **粗到细动作学习**：先让 VLM 获取具身推理和离散动作语义，再通过潜在动作标记连接梯度解耦的连续动作专家。
2. **语义对齐的 3D 集成**：冻结 2D 视觉通路，添加可训练的 3D 空间编码器（VGGT）并用零初始化投影器逐步注入 3D 特征，避免扰乱 VLM 语义空间。
3. **本体规范化**：使用**本体感知状态**（末端执行器位姿+关节角）和**本体不变动作**（相对末端执行器动作）将机器人差异限制在低级接口，通过轻量化状态投影器适应新本体。

### 关键技术细节
- **粗到细动作学习**：
  - **具身 VLM 预训练**：在多种数据上自回归训练 VLM（VQA、空间接地、轨迹推理、指向、掩码跟踪、操作视频）。对于有动作标签的数据，使用 FAST 风格动作标记离散化连续动作；对于无动作标签的视频，训练因果 VQ-VAE 生成潜在动作 ID（编码连续视频帧之间的动作相关变化）。目标函数为自回归交叉熵损失 \(L_{VLM}\)。
  - **连续动作生成**：附加一个 DiT 动作专家，使用流匹配损失 \(L_{FM}\) 生成连续动作块。DiT 仅接收从 VLM 输出的潜在动作标记的 K/V 缓存，并通过 **stop-gradient** 阻止连续动作损失回传到 VLM 主干，保护已学得的语义表示。

- **语义对齐 3D 集成**：
  - 采用 VGGT 作为 3D 空间编码器，利用多视图一致性提供几何结构。
  - 2D 视觉特征（冻结）和 3D 特征通过**扩展的视觉投影器**拼接：\(Z_{vis} = [H_{2D}; H_{3D}] W_{vis} + b\)，其中 \(W_{vis}\) 的 3D 部分初始化为零，使得初始阶段不扰动原始视觉 token 分布。训练过程中 3D 编码器逐步学习操作相关几何结构。

- **本体规范化**：
  - **动作输出**：采用**相对末端执行器动作**（Relative End-effector Action），所有未来目标位姿相对于当前末端执行器位姿表达，避免累积误差且减少对基坐标的依赖。
  - **状态输入**：使用末端执行器位姿和关节角作为本体感知状态输入，为每个机器人配备一个轻量级**状态投影器** \(f_{\psi_e}^s\) 将其映射到共享 VLA 表示空间。
  - **跨本体适应**：两阶段轻量调整——先冻结 VLA 主干对齐状态投影器，再进行端到端微调。
