## 摘要
视觉-语言-动作（VLA）模型在基准测试中取得了强劲表现，但在现实部署中面对未见物体、背景变化和不同机器人本体时仍遇到困难。我们认为这源于缺乏统一的几何感知操作表示，使现有VLA模型易受低级轨迹监督、3D特征错位以及本体差异的影响。为此，我们提出GEAR-VLA，一个学习统一几何感知动作表示以实现通用机器人操作的VLA框架。GEAR-VLA采用由粗到细的动作学习，通过多源具身预训练赋予VLM具身推理和离散动作理解能力，再通过潜在动作令牌将动作语义连接到梯度解耦的DiT连续动作专家。此外，GEAR-VLA通过将可训练的3D空间骨干与VLA表示对齐，同时冻结原始VLM对齐的视觉通路，执行语义对齐的3D集成。为跨机器人共享该表示，GEAR-VLA使用本体规范化，将具身感知状态和具身不变动作将机器人差异限制在低级接口。大量仿真和真实实验证明了强大的泛化能力：GEAR-VLA在LIBERO、零样本LIBERO-Plus和RoboTwin 2.0上达到最优性能，在AgileX上成功率达85.9%，在未预训练的LDT-01本体上达81.0%，并在包含212个未见物体的6,360次通用抓取基准测试中获得90.1%的成功率。代码和模型将在https://github.com/babynabeauty/GEAR-VLA发布。

## Abstract
Vision-Language-Action (VLA) models achieve strong benchmark performance but still struggle in real-world deployment with unseen objects, background shifts, and different robot embodiments. We argue that this stems from the lack of a unified geometry-aware manipulation representation, leaving existing VLAs vulnerable to low-level trajectory supervision, misaligned 3D features, and embodiment differences. To address this, we propose GEAR-VLA, a VLA framework for learning unified geometry-aware action representations for generalizable robotic manipulation. GEAR-VLA adopts coarse-to-fine action learning, where multi-source embodied pretraining equips the VLM with embodied reasoning and discrete action understanding before latent action tokens connect action semantics to a gradient-decoupled DiT continuous action expert. It further performs semantic-aligned 3D integration by aligning a trainable 3D spatial backbone with the VLA representation while freezing the original VLM-aligned visual pathway. To share this representation across robots, GEAR-VLA uses embodiment canonicalization, where embodiment-aware states and embodiment-invariant actions confine robot differences to the low-level interface. Extensive simulation and real-world experiments demonstrate strong generalization: GEAR-VLA achieves state-of-the-art performance on LIBERO, zero-shot LIBERO-Plus, and RoboTwin 2.0, reaches 85.9% success on AgileX and 81.0% on the pretraining-unseen LDT-01 embodiment, and obtains 90.1% success on a 6,360-trial universal grasping benchmark with 212 unseen objects. Code and models will be released at https://github.com/babynabeauty/GEAR-VLA.

# 论文《GEAR-VLA: Learning Geometry-Aware Action Representations for Generalizable Robotic Manipulation》详细中文总结

## 1. 核心问题与整体含义（研究动机和背景）
- **核心问题**：当前 Vision-Language-Action (VLA) 模型在基准测试中性能出色，但在真实部署中面对**未见物体、背景变化、不同机器人本体**时泛化能力不足。
- **根源**：现有 VLA 缺乏**统一的几何感知操作表示**，导致三方面瓶颈：
    - **动作表示**：将连续动作离散化为 token 会迫使 VLM 进行轨迹模仿而非具身推理；
    - **空间表示**：深度图、3D 位置编码等与 VLM 语义空间不对齐，直接注入会破坏语义表示；
    - **具身表示**：机器人特化的动作头或软提示会将机器人身份混入共享策略表示，降低跨本体迁移效率。
- **目标**：学习一个**语义有根基且几何感知的统一动作表示**，同时将本体特定适应限制在低级接口，提升 VLA 在未知物体、场景和本体上的泛化能力。

## 2. 方法论：核心思想、关键技术细节
### 2.1 总体框架
- 输入：多视图 RGB 图像 `It`、语言指令 `l`、机器人状态 `st`（末端位姿+关节角）。
- 输出：未来动作块 `A_t:t+H`。
- 三个核心设计：**粗到细动作学习**、**语义对齐的 3D 集成**、**具身规范化**。

### 2.2 粗到细动作学习（Coarse-to-Fine Policy Learning）
- **Stage 1：Embodied VLM 预训练**
    - 训练混合数据：视觉语言理解、空间接底、轨迹推理、目标跟踪、操作视频等。
    - 对带动作标签的机器人数据：使用 FAST 风格动作 token 提供离散监督。
    - 对无动作标签的操作视频：训练因果 VQ-VAE 生成**潜在动作 ID**（Latent Action IDs），捕捉短时视觉动态。
    - 所有任务统一为自回归 token 预测损失 `L_VLM`。
- **Stage 2：连续动作生成**
    - 附加一个**DiT（Diffusion Transformer）动作专家**，仅接收 VLM 输出的潜在动作 token 的 K/V 缓存。
    - 通过 **stop-gradient（sg）** 防止连续动作损失反向传播到 VLM 主干。
    - 使用流匹配损失 `L_FM` 训练 DiT：`L_FM = E[ ||v_phi(A_tau, tau, sg(h_la)) - (A - epsilon)||^2 ]`。
    - 潜在动作 token 作为受控接口，将离散动作语义稳定映射到连续控制。

### 2.3 语义对齐的 3D 几何集成
- 加入可训练的 **3D 空间编码器（VGGT）** 提取多视图几何结构。
- **关键策略**：
    - 冻结原有的 2D 视觉编码器（已与 LLM 语义空间对齐），保持视觉-语言对齐稳定。
    - 2D 和 3D 特征沿特征维度拼接，通过**扩展的视觉投影器**映射到 LLM 视觉 token 空间。
    - 新加的 3D 投影块**零初始化**（`W_vis^(0) = [W_Qwen; 0]`），初始阶段不扰动原有分布。
    - 训练过程中，3D 编码器逐渐学习操作相关的几何结构，形成几何感知的联合表示。

### 2.4 具身规范化（Embodiment Canonicalization）
- **动作侧**：采用**相对末端执行器动作**：
    - 相对于当前末端位姿定义未来动作：`ΔT_(t+i) = (T_ee^t)^{-1} T_ee^(t+i)`。
    - 避免绝对坐标依赖和步进式累积误差。
- **状态侧**：使用末端位姿 + 关节角作为配对状态输入，隐式编码本体信息（自由度、关节布局等）。
    - 每个机器人仅使用一个**轻量状态投影器**映射到共享表示空间。
- **跨本体迁移**：两阶段轻量适应——首先冻结共享主干，仅训练新机器人的状态投影器，再轻量端到端微调。

## 6. 主要结论与发现
- GEAR-VLA 通过**粗到细动作学习**、**语义对齐 3D 集成**和**具身规范化**，学习到一个统一的几何感知动作表示，显著提升了仿真和真实场景下的泛化能力。
- 在标准仿真基准和挑战性的零样本 OOD 设置中达到 **SOTA**。
- 在真实世界中成功迁移到**预训练未见的机器人本体**（LDT-01），且仅需少量数据（200 演示）。
- 在包含 212 个未见物体的通用抓取任务上，以 90.1% 的成功率大幅超越现有方法（π0.5 79.1%），尤其在高干扰场景中优势明显。
- 消融表明三个设计均不可或缺，其中 **3D 零初始化投影**和**具身规范化**的贡献最为关键。

## 7. 优点
- **方法创新**：
    - **粗到细学习范式**：先让 VLM 学习离散动作语义和具身推理，再通过解耦的 DiT 专家生成连续动作，避免轨迹拟合干扰语义。
    - **语义对齐 3D 集成**：零初始化 + 冻结 2D 支路的设计，在不破坏 VLM 语义空间的前提下逐步注入 3D 几何信息。
    - **具身规范化**：将本体差异限制在低级状态投影器，而非共享策略表示，极大提升跨本体迁移效率。
- **实验全面**：涵盖仿真 OOD 泛化、真实双机操作、跨本体迁移、大规模通用抓取，数据量大、任务多样。
- **数据高效**：真实场景仅需 200 演示即可适应新任务或新本体，相比同类基线更省数据。
- **开源承诺**：代码和模型将发布，促进可复现性。

## 8. 不足与局限
- **实验覆盖偏差**：
    - 真实任务仅限双臂操作和抓取，未验证移动操作、灵巧手操作或长时程任务（如长期任务规划）。
    - 消融实验主要在仿真 LIBERO-Plus 上完成，未提供真实场景下的消融结果（如对 AgileX 或通用抓取的逐项消融）。
- **算力资源需求高**：训练需 240 块 H200 GPU，总迭代超 100 万步，对大多数研究团队门槛较高。
- **潜在风险**：
    - 依赖多视图输入（头视图+双腕部），缺少该配置可能需适配。
    - 3D 编码器 VGGT 的泛化性可能受限于训练数据分布（如未见过的相机布局或极端光照）。
    - 两阶段微调策略虽轻量，但需人工指定任务划分，完全自动的跨本体适应尚未探索。
- **可解释性**：潜在动作 token 和 VLM-动作专家交互的黑盒程度较高，难以直接分析失败原因。
