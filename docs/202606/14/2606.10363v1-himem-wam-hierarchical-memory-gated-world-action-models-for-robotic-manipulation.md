## 摘要
世界动作模型（WAMs）已成为具身智能的一种新的强大范式，通过学习与动作相关的视觉动态，显著提升了泛化性和鲁棒性。然而，现有的WAMs在长时域机器人操作中仍难以应对任务相关记忆。为此，我们提出HiMem-WAM，一种分层记忆门控WAM，它集成了以运动为中心的潜在动作、高级技能潜在表示以及边界触发的记忆更新。具体而言，我们开发了一个分层潜在动作框架，联合学习低级运动和高级技能潜在表示，提供结构化的时间抽象。同时，一个边界感知记忆门在预测的技能转换处写入紧凑的任务状态，从而无需在测试时生成未来视频或光流估计即可实现因果推理。在LIBERO、LIBERO-PLUS、RMBench以及真实世界任务上的评估表明，HiMem-WAM的分层潜在表示提升了部署扰动下的鲁棒性，而记忆模块显著有利于依赖记忆的长时域操作。

## Abstract
World Action Models (WAMs) have emerged as a new powerful paradigm for embodied intelligence, learning action-relevant visual dynamics that significantly enhance generalization and robustness. However, existing WAMs still struggle with task-relevant memory in long-horizon robotic manipulation. To address this, we present HiMem-WAM, a Hierarchical Memory-Gated WAM that integrates motion-centric latent actions, high-level skill latents, and boundary-triggered memory updates. Specifically, we develop a hierarchical latent action framework that jointly learns low-level motion and high-level skill latents, providing structured temporal abstraction. Meanwhile, a boundary-aware memory gate writes compact task states at predicted skill transitions, enabling causal inference without test-time generation of future video or optical flow estimation. Evaluated on LIBERO, LIBERO-PLUS, RMBench and real-world tasks, HiMem-WAM shows that hierarchical latents improve robustness under deployment perturbations, and the memory module substantially benefits memory-dependent long-horizon manipulation.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 将策略分解为三个角色：**技能级规划器**（根据当前观测、语言指令、本体感觉和记忆选择高级技能潜在）、**运动级执行器**（将技能潜在展开为低级潜在动作块）、**动作解码器**（将低级潜在映射为可执行的控制信号）。
- 引入**边界感知记忆门**：仅在预测的技能转换处写入紧凑任务状态，通过阅读门检索历史上下文，实现因果推理，无需测试时视频生成或光流估计。

### 关键技术细节（三阶段训练管线）

#### 阶段 I：低级潜在动作分词器
- 从多视角RGB图像计算光流（DPFlow），使用变分自编码器将短时上下文（当前/下一帧、光流、本体感觉、语言）编码为低维潜在动作 \( z^l_t \)。
- 训练目标：重建光流 + 若存在动作标签则对齐真实动作 + KL散度正则化。
- 训练后冻结分词器，对所有轨迹和视频离线提取 \( Z^l \) 序列。

#### 阶段 II：层级潜在动作预训练（无外部记忆）
- **技能发现**：对 \( Z^l \) 序列进行层级分块，通过边界得分和注意力池化得到高级技能潜在 \( z^h_t \) 和边界标签 \( \bar{b}_t \)。
- **规划器+执行器预训练**：基于Qwen3-VL-4B-Instruct的规划器预测当前技能 \( \hat{z}^h_t \) 和边界分数 \( \hat{b}_t \)；执行器预测低级潜在动作块 \( \hat{Z}^l_{t:t+K-1} \)。
- 损失：MSE(技能预测, 真实技能) + MSE(潜在动作块, 真实潜在块) + BCE(边界预测, 真实边界)。

#### 阶段 III：记忆门控模块微调（动作标注演示）
- **记忆读取**：将当前状态 \( x_t \) 与外部记忆库 \( M_t \) 做注意力检索，由可学习读门 \( \alpha^r_t \) 控制信息注入。
- **记忆写入**：根据规划器输出的边界分数 \( \hat{b}_t \) 计算写门 \( \alpha^w_t \)，仅当 \( \alpha^w_t > \eta \) 时将当前状态、预测技能和池化潜在块组成的候选写入记忆库。
- **总损失**：动作预测损失 + 技能/潜在/边界损失 + 门控损失（BCE监督写门，L1稀疏约束读写门）。
- 训练后推理完全因果：仅需当前RGB、本体感觉、指令和记忆库，执行动作块并通过写门更新记忆。
