## 摘要
动态环境中的终身具身导航要求机器人从碎片化观测中形成持久场景理解，这对于依赖显式地图或场景图且难以泛化到结构化环境之外的现有方法而言仍然困难。我们提出AllDayNav，一种终身自学习导航框架，通过强化学习将场景动态隐式编码到大模型的十亿级参数中，并由自演化多模态记忆驱动，该记忆维护并更新视觉关键帧、语义描述和时间上下文，同时自主生成开放词汇指令、图像目标和结构化奖励。在跨房间、跨回合和跨任务场景的合成与真实环境实验中，AllDayNav实现了接近100%的成功率，并在路径效率和鲁棒性上持续超越基于地图、VLM和RL的强基线，证明了隐式、记忆驱动的强化学习作为显式映射的可扩展替代方案，用于可靠的终身导航。

## Abstract
Lifelong embodied navigation in dynamic environments requires robots to form persistent scene understanding from fragmentary observations, which remains difficult for existing methods that rely on explicit maps or scene graphs and struggle to generalize beyond structured settings. We propose AllDayNav, a lifelong self-learning navigation framework that implicitly encodes scene dynamics into the billion-scale parameters of a large model via reinforcement learning, powered by a self-evolving multimodal memory that maintains and updates visual keyframes, semantic descriptions, and temporal context while autonomously generating open-vocabulary instructions, image goals, and structured rewards. Experiments in both synthetic and real-world environments across cross-room, cross-episode, and cross-task scenarios show that AllDayNav achieves success rates approaching $100\%$ and consistently surpasses strong map-based, VLM, and RL baselines in path efficiency and robustness, demonstrating implicit, memory-driven reinforcement learning as a scalable alternative to explicit mapping for reliable lifelong navigation.

- **核心问题**：动态环境下的终身（lifelong）具身导航要求机器人在长时间跨回合操作中，从碎片化的自我中心观测中形成并持续更新对场景的稳定理解。现有方法（如显式地图、场景图、短时帧记忆）依赖结构化表示或静态预训练，无法在非结构化、动态变化的环境中进行持续自适应和知识积累。
- **研究动机**：受认知神经科学中“视觉心理意象”（visual mental imagery）启发——人类通过稳定的内部图像进行空间回忆与行动规划，作者希望机器人也能维护类似的、随时间演进的内部表示，并据此进行终身策略优化。
- **整体含义**：提出 AllDayNav，一种**隐式、记忆驱动的强化学习框架**，将场景动态编码进大规模模型参数，配合自演化多模态记忆，实现无需人工监督的终身自学习导航。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 将导航目标表示为**视觉目标图像**（而非符号指令），构建**持久的多模态记忆数据库**（存储视觉关键帧、语义描述、时间戳、嵌入向量）。
- 通过**记忆-策略协同演化**循环：探索 → 更新记忆 → 自我生成训练任务 → 强化学习优化策略 → 更优的探索。
- 使用**保守Q学习（CQL）** 稳定地从混合离线-在线数据中学习，并引入行为克隆（BC）正则化防止遗忘。

### 关键技术细节

1. **预训练VLA导航骨干**：
   - 双编码器：SigLIP（语义对齐）+ DINOv2（结构细节），特征拼接后经MLP投影。
   - 历史帧压缩：对过往帧使用全局平均池化（GAP）降token，并施加指数衰减时间注意力偏置。
   - 动作输出：预测 **K=8个局部航点**（相对位置和朝向），提供平滑运动规划。
   - 骨干为 **Qwen2-7B** 视觉语言模型，训练目标为航点MSE。

2. **自演化多模态记忆数据库**：
   - 每条记录：（RGB图像，VLM生成的文本描述，时间戳，LLaVE嵌入）。
   - 自主构建：每5步判断视觉嵌入变化是否超过阈值（0.15），若超过则候选帧；
   - 去重更新：与现有记忆计算余弦相似度，若低于0.7则插入新条目；若高于0.7且新图像对现有描述的文本对齐度更好，则替换旧图像。
   - 检索：用 **Qwen3-VL-8B-Instruct** 基于当前时间、指令和所有场景描述（含时间戳）进行语义检索，输出最佳匹配ID和置信度。

3. **自我指令生成与混合目标检索**：
   - 每10回合或记忆增长20%时，聚合记忆中的描述，用VLM生成50条多样化指令（含物体、功能、空间、时间等类别）。
   - 混合检索：优先从记忆检索（置信度阈值0.6），若置信度低或早期记忆稀疏（概率退火），则回退到互联网图像集合。
   - 训练时从指令集中采样，检索对应目标图像，驱动RL学习。

4. **保守Q学习策略优化**：
   - MDP：状态为当前RGB、目标图像、历史帧；动作为8维航点；奖励含终端成功+10、进度区间奖励（超过相似度0.5/0.6/0.7时+2）、时间惩罚-0.01、碰撞惩罚-0.1。
   - CQL损失：标准Bellman误差 + 保守正则项（惩罚Q值过估计），α=5.0。
   - 策略损失：最大化Q值 + BC正则（λ_bc=0.1），稳定更新。
   - 每100步交替更新评论家和策略，缓冲池B存储在线经验。
