## 摘要
深度强化学习在社会导航方面展现出潜力，但其实际部署仍受到模拟与现实之间持续存在的差距的阻碍，该差距源于简化的一阶动力学和特定情境下的人类状态估计流程。本文提出了一个统一框架来解决这些局限性，以生成适用于实际部署的动态可行导航策略。首先，理论分析表明，模拟与实际机器人位置之间的跟踪误差随控制阶数的增加呈指数衰减，这促使使用高阶控制输入作为深度强化学习的动作空间。针对差分驱动机器人开发了二阶控制公式，并辅以随机迭代线性二次型调节器，通过散度最小化目标对策略进行预训练。其次，为避免摄像头-激光雷达融合带来的额外系统复杂性，引入了仅使用二维激光雷达的基于聚类的人类跟踪流程。根据空间接近度和速度相似性关联人体检测结果，能够可靠区分附近行人，并通过时间聚合获得稳定的速度估计。第三，我们引入了无偏残差门控块，以平衡基于反应和记忆的行为，同时处理时变的人群密度，这两者对社会导航至关重要。由此产生的策略KinematicRL持续提升了运动学性能，并适应不同数量的检测到的人类。在实际环境中的实验表明，结合所提出的跟踪流程，KinematicRL可以在实际差分驱动机器人上以最小修改进行部署。

## Abstract
Deep Reinforcement Learning (DRL) has shown promise for social navigation, yet its real-world deployment remains hindered by a persistent sim-to-real gap arising from simplified first-order dynamics and context-specific human state estimation pipelines. This work presents a unified framework that addresses these limitations to produce dynamically feasible navigation policies suitable for real-world deployment. First, theoretical analysis reveals that tracking error between simulated and actual robot position decays exponentially with increased control order, motivating the use of higher-order control inputs as DRL action space. A second-order control formulation tailored to differential drive robots is developed, complemented by a stochastic iterative Linear Quadratic Regulator (iLQR) that pretrains the policy via a divergence minimization objective. Second, to avoid the added system complexity of camera-LiDAR fusion, a cluster-based human tracking pipeline using only 2D LiDAR is introduced. Human detections are associated according to both spatial proximity and velocity similarity, enabling reliable differentiation of nearby pedestrians and yielding stable velocity estimates through temporal aggregation. Third, we introduce an unbiased residual gating block to balance reaction- and memory-based behaviors while handling time-varying crowd sizes, both critical for social navigation. The resulting policy, KinematicRL, consistently improves kinematic performance and adapts to varying number of detected humans. Experiments in real-world environments demonstrate that, when combined with the proposed tracking pipeline, KinematicRL can be deployed on a real differential drive robot with minimal modifications.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：社会导航中深度强化学习（DRL）策略从仿真迁移到真实机器人时面临严重的 **sim-to-real gap**，主要原因有二：(1) 仿真中常使用简化的一阶动力学模型，而真实机器人无法瞬时执行速度变化，导致跟踪误差；(2) 人类状态（位置、速度）在仿真中是理想化的，真实世界中需从传感器测量中估计，而现有方法多依赖摄像头-激光雷达融合，增加系统复杂度和标定漂移。

- **整体含义**：本文旨在提出一个统一框架，同时解决动力学可行性与感知估计两大障碍，使得在仿真中训练的社会导航策略可**直接部署**在真实差分驱动机器人上，无需额外的底层控制器或大幅修改。

## 2. 方法论：核心思想、关键技术细节、公式/算法流程

### 核心思想
- **高阶控制降低跟踪误差**：理论证明（Theorem 1）指出，随着控制阶数 \(n\) 增加，机器人位置跟踪误差以 \(O(\Delta t^{n-k}/(n-k)!)\) 指数级衰减。因此，将深度强化学习的动作空间从一阶（速度）提升为**二阶（加速度）**，从根源上保证动态可行性。
- **随机 iLQR 预训练**：利用最大熵控制框架下的随机迭代线性二次型调节器为二阶策略生成专家演示，通过**前向 KL 散度最小化**（M-投影）进行模仿学习，避免直接使用MSE损失。
- **仅 LiDAR 的聚类人体跟踪**：使用 Li2Former 检测二维点云中的人类中心，通过空间-速度联合距离进行数据关联，并以历史加权平均估计人体速度，无需摄像头。
- **无偏残差门控 Transformer**：设计改进的 GRU 门控残差块，移除偏置项并修改跳跃连接，平衡反应（瞬时）与记忆（历史）行为，同时利用可变人群规模训练提升泛化性。

### 关键技术细节
1. **二阶控制动作空间**：对于差分驱动机器人，状态 \(x = [x, y, \theta, v, \omega]^\top\)，动作 \(u = [u_a, u_\alpha]\)（线加速度、角加速度），满足加速度上下界 \(a_{\min} \leq u_a \leq a_{\max}\)，\(\alpha_{\min} \leq u_\alpha \leq \alpha_{\max}\)，从而自然满足动态约束。
2. **随机 iLQR**：在最大熵控制框架下，通过线性-二次假设迭代求解最优高斯策略，公式为 \(u_t \sim \mathcal{N}(\hat{u}_t + K_t (x_t - \hat{x}_t) + k_t, Q_{u,u_t}^{-1})\)，其中 \(K_t\)、\(k_t\) 由 Q 函数导数递归计算。代价函数包含目标到达、平滑轨迹、碰撞避免三项（非凸碰撞项通过 Hessian 正则化处理）。
3. **聚类跟踪管线**：
   - **聚类维护**：每个行人用一个缓冲区（大小为 l）的历史位置和速度表示，质心速度通过时间衰减加权平均计算。
   - **数据关联**：距离度量同时考虑空间距离和速度相似性：\(J(\hat{p}_n^j, C_i^{j-1}) = (1-\alpha)\|\hat{p}_n^j - p_{\text{cluster},i}^{j-1}\| + \alpha \|\hat{v}_n^j - v_{\text{cluster},i}^{j-1}\|\)，再用匈牙利算法分配。
   - **聚类更新**：分配后使用卡尔曼滤波去噪，将去噪后的状态加入缓冲区。
4. **无偏残差门控块**：
   - 移除 GRU 中的偏置项 \(b_u\)，以避免对 padding 信息的错误更新。
   - 修改残差连接：第二个 GRU 的跳跃连接直接来自输入嵌入，而非中间状态，缓解信号衰减。
   - 采用 **场景级域随机化**：改变人类起始-目标配置、随机化速度，增加状态空间熵，避免注意力机制将人群视为单一实体。

### 算法流程
- 阶段一：使用随机 iLQR 滚动（3000  episodes）收集专家数据，采用 DAgger 进行多次迭代，最小化前向 KL 散度，得到预训练策略 \(\pi_{bc}\)。
- 阶段二：使用 PPO 算法（clipping, GAE）继续优化策略，奖励函数包括目标到达（+1.0）、碰撞（-0.25）、社交距离惩罚（0.5*(d_t - d_min)Δt）、时间惩罚（-0.01）。

## 6. 主要结论与发现

1. **高阶控制有效弥合 sim-to-real gap**：二阶控制动作空间使 KinematicRL 在所有运动学指标（振荡频率、急动度、曲率）上显著优于 SARL（一阶），且无动态不可行动作。
2. **随机 iLQR 预训练优于 MSE**：前向 KL 散度（M-投影）相比 MSE 和 I-投影，RL 收敛速度约快 2 倍，最终奖励更高。
3. **门控 Transformer 对可变人群规模鲁棒**：训练时使用可变人数（4-6人）的策略在测试 7-11 人时仍保持较高成功率，而固定人数训练策略性能急剧下降；SARL 在人数超过 9 后成功率下降更快。
4. **感知管道有效**：速度相似性（α=0.4）的数据关联显著优于纯空间度量（α=0.0），历史平均滤波的 MSE 最低（0.11 m/s）。
5. **无偏残差门控块是必要的**：移除 pre-LN、GRU 门控或修改残差连接都会导致训练失败。

## 7. 优点

- **理论坚实**：提供定理证明跟踪误差随控制阶数指数衰减，并用其指导动作空间设计。
- **轻量感知**：仅用 2D LiDAR 实现可靠人体跟踪，避免多传感器融合带来的标定和计算负担。
- **算法创新**：将随机 iLQR 与前向 KL 散度结合用于模仿学习，体现了对动作不确定性的利用；设计的无偏残差门控块解决了 Transformer 在强化学习中的训练不稳定和可变长度处理问题。
- **实验设计全面**：包含丰富的消融实验（模仿目标、网络模块、域随机化、感知噪声）和跨领域对比（几何方法、优化方法、DRL 基线）。
- **开源与可复现**：代码和 ROS 节点已公开，便于社区复现和扩展。

## 8. 不足与局限

1. **碰撞率仍然较高**：KinematicRL 在高度动态场景的碰撞率为 0.15，高于 SARL 的 0.01。作者解释这是由于二阶非完整约束的限制，但实际部署中 15% 的碰撞率不可接受。缺乏显式安全保证（如控制屏障函数）。
2. **真实实验定量不足**：仅展示一个 4 人场景的轨迹可视化，未提供多轮重复实验的成功率、碰撞率等统计结果，样本量不够。
3. **只考虑动态行人**：未讨论静态障碍物，实际场景中桌椅、墙壁等静态物体也需要处理。
4. **感知模块计算开销**：Li2Former 在无 GPU 的嵌入式板上无法运行，依赖外接笔记本或更高级的 Jetson；虽然作者测试了 Jetson Orin Nano，但未详细报告在嵌入式平台上的完整时延。
5. **缺乏与其他感知管线的公正比较**：跟踪部分仅对比了不同 α 和滤波方法，但未与 SORT、DeepSORT 等主流跟踪算法在同一框架下比较。
6. **假设人类为非合作**：训练时所有行人不观察机器人，而真实场景中存在合作避让，策略可能过于激进；且未验证与合作行人的交互效果。
7. **训练场景规模有限**：最大人群为 11 人，未测试更密集场景（如 20+ 人）的表现。
