## 摘要
视觉-语言-动作（VLA）模型从视觉-语言预训练中继承了共享的同步时钟，以统一速率处理每个输入。这与物理交互不一致，在物理交互中，高频模态以数百赫兹变化，视觉演变较慢，而语言在一个回合中保持不变。同步VLA对慢速模态过度采样，对快速模态欠采样，并将动作生成限制在最低有效频率。我们假设，解耦各模态的时间处理，让每个模态以其自身的传感器速率更新和保留信息，可以产生更强的表示和更鲁棒的控制。我们提出DAM-VLA，它维护每个模态的潜在缓冲区，以传感器速率刷新，并由动作头连续读取，通过门控交叉注意力集成新的高频模态，同时保持预训练骨干网络不变。在七个接触丰富的真实世界操作任务中，DAM-VLA的平均成功率是最强同步基线的两倍以上（95.2% vs. 40.95%），同时维持平滑、反应式的100 Hz控制。项目网站：https://intuitive-robots.github.io/DAM-VLA/

## Abstract
Vision-language-action (VLA) models inherit a shared synchronous clock from vision-language pretraining, processing every input at one rate. This is misaligned with physical interaction, where a high-frequency modality changes at hundreds of hertz, vision evolves more slowly, and language stays constant across an episode. A synchronous VLA oversamples slow modalities, undersamples fast ones, and caps action generation at the lowest effective frequency. We hypothesize that decoupling temporal processing per modality, letting each update and retain information at its own sensor rate, yields stronger representations and more robust control. We present DAM-VLA, which maintains per-modality latent buffers refreshed at sensor rates and read continuously by the action head, integrating new high-frequency modalities through gated cross-attention that leaves the pretrained backbone intact. Across seven contact-rich real-world manipulation tasks, DAM-VLA more than doubles the average success rate of the strongest synchronous baseline (95.2\% vs.\ 40.95\%) while sustaining smooth, reactive 100\,Hz control. ## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：当前视觉-语言-动作（VLA）模型继承自视觉-语言预训练，采用统一的同步时钟处理所有输入模态（如视觉、力/力矩、本体感知、语言）。这种设计在物理交互中存在根本性的不匹配：不同传感器以根本不同的速率产生有意义的信息（力/力矩可达100–500 Hz，RGB相机仅3–10 Hz），且每种信号的信息相关性时间尺度不同（力峰值持续毫秒，场景布局保持数秒）。同步VLA导致了三个挑战：
  1. **冗余计算**：昂贵的VLM编码器重复处理语义相同的视觉帧。
  2. **跨模态速率失配**：统一时钟同时欠采样快速更新模态和过采样慢速更新模态。
  3. **动作延迟**：策略执行必须等待最慢模态的完整观测捆绑，增加了端到端延迟并降低了有效控制频率。
- **整体含义**：解耦是解决多模态机器人学习的正确架构原则——让每个模态按照自身传感器速率更新、保留和贡献信息，而不是强制所有模态进入同步令牌流。这能产生更符合传感器信息结构的高质量表示，进而显著提升操作任务的成功率和控制频率。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- **解耦异步处理**：为每种模态维护独立的潜在缓冲区（latent buffer），以传感器自身速率更新；动作头在每个控制步骤连续读取所有缓冲区，不依赖单一模态的更新周期。
- **门控交叉注意力（Gated Cross-Attention, GCA）**：在VLA的动作专家（action expert）的每隔4个Transformer层中插入两个并行的GCA通路，用于融合视觉记忆和额外模态（如力/力矩）。GCA以零初始化的残差方式注入信息，保留预训练骨干权重不变，避免新令牌破坏预训练表示。

### 关键技术细节
1. **异步数据采集**：各传感器独立记录，带有时间戳。训练时，对每个动作标签，从各模态按其自然时间分辨率提取固定历史窗口：
   - 视觉：稀疏历史，16帧@25 Hz（约0.64秒语义上下文）。
   - 力/力矩和本体感知：密集历史，96个样本@100 Hz（约0.96秒高频接触和状态历史）。
2. **多模态异步潜在缓冲区**：
   - **语言令牌**：每个回合开始时编码一次，之后不变。
   - **视觉令牌**：主相机和腕部相机由视觉-语言编码器编码；为避免冗余重编码，视觉编码器每4个推理步骤调用一次，缓存VLM嵌入。
   - **本体感知令牌**：关节状态与动作令牌拼接，以100 Hz满控制频率读取并编码。
   - **力令牌**：关节力矩读数以100 Hz到达，经指数移动平均平滑后积累到滚动缓冲区。GRU编码后，通过交叉注意力压缩为力令牌`Z_ft`，每个控制步更新。
   - **短期视觉记忆**：每帧视觉更新将新帧嵌入追加到最多K帧的滚动缓冲区，GRU编码后通过可学习查询交叉注意力压缩为N_mem个记忆令牌`Z_mem`，在两次视觉更新之间保持有效。
3. **双通路门控交叉注意力**：
   - **视觉记忆通路**（全局门控）：使用零初始化的tanh缩放残差：
     ```
     Z^(ℓ+1) = Z^(ℓ) + tanh(α)·CA(LN(Z^(ℓ)), Z_mem)
     ```
     α为可学习标量，初始化为0，逐步增长，不破坏预训练表示。
   - **额外模态通路**（输入依赖门控，以力为例）：使用sigmoid门控，门的输入为力的均值池化令牌：
     ```
     Z^(ℓ+1) = Z^(ℓ) + σ(W·z̄_ft)·CA(LN(Z^(ℓ)), Z_ft)
     ```
     门初始化为接近关闭状态，允许网络学习何时力是有信息的（例如接触时激活，自由空间时抑制）。力查询的是预记忆更新的动作令牌，确保与视觉记忆通路正交。
4. **训练与推理异步性**：训练时，所有模态先对齐到100 Hz时间线以统一动作标签；视觉通过步长S采样恢复稀疏历史；力连续采样。推理时，视觉更新稀疏，力每步更新，动作生成不阻塞于视觉重编码。

## 6. 论文的主要结论与发现

- **RQ1**：同步处理存在性能上限，朴素频率缩放（将视觉帧简单上采样至100 Hz）反而导致性能下降（21.9% vs. 40.95%），因为冗余帧与不同动作标签配对产生矛盾训练信号。
- **RQ2**：异步解耦（DAM-VLA /F/M，40.0%）恢复因朴素频率缩放丢失的性能，接近标准同步基线（40.95%），并首次解锁了按钮（40.0%）和洗手液（20.0%）等接触任务。
- **RQ3**：在异步解耦基础上添加额外模态（力或视觉记忆）均进一步提升性能；结合两者（完整DAM-VLA）达到95.2%，是同步基线的两倍以上。视觉记忆稳定序列上下文，力提供精确接触终止信号，两者互补解决Lego和插头等困难任务。
- **RQ4**：整合机制至关重要：使用门控交叉注意力（GCA）保留预训练骨干的完整性，避免扁平拼接（X-VLA AFM，54.3%）对预训练表示的破坏。GCA的优势在手洗任务上明显：X-VLA AFM反复按压和回缩，而DAM-VLA一次干净按压。
- **总体结论**：让每个传感器以自身速率更新模型，比强制所有模态进入统一时钟，是构建更好操作策略的实用方法。DAM-VLA在7个接触丰富任务上平均成功率从40.95%提升至95.2%，同时实现100 Hz平滑反应式控制。

## 7. 优点

1. **架构设计创新**：首次在VLA中系统提出解耦异步多模态处理，为每种模态维护独立潜在缓冲区，从根本上解决了同步时钟的速率失配问题。
2. **保预训练骨干**：通过门控交叉注意力以零初始化残差方式注入新模态，不修改预训练自注意层权重，避免灾难性遗忘和表示破坏，易于扩展到更多模态。
3. **输入依赖门控策略**：力模态采用sigmoid门控，门值由力信号均值池化决定，使网络自适应学习何时力信息有用，无需显式接触检测。
4. **全面且公平的消融**：逐步添加组件，每种配置在相同条件下评估，清晰地分解了异步解耦、力、记忆、整合机制各自的贡献，实验设计严谨。
5. **实际系统验证**：在真实机械臂上执行7个多样化任务，与真实遥操作数据对比，结果具有现实意义；使用消费级GPU（RTX 4060 Ti）即可推理，展示了实用性和可部署性。
6. **性能显著提升**：在困难任务（Lego、插头、洗手液）上从零分提升至80–100%，证明方法能有效处理接触丰富、需要精确力的场景。

## 8. 不足与局限

1. **未在动作块内使用力进行在线修正**：力仅用于构建更好表示，而不在生成的动作块内进行在线修正。对于插头等需要极小对齐误差修正的任务（80%成功率），使用力实现中块修正可能是直接改进方向。
2. **视觉更新基于固定定时器而非场景变化**：相机以固定间隔（每4个推理步）更新，而非在场景实际变化时触发。引入基于变化检测的触发机制可进一步减少冗余编码并提高反应速度。
3. **力传感器来源受限**：力信号依赖于Franka内置关节力矩估计，而非专用高精度F/T传感器。虽然证明了无特殊硬件下的性能增益，但使用外部F/T传感器可能进一步改善接触检测和力控制。
4. **任务覆盖有限**：仅涉及桌面操作任务，未测试双臂移动操作、动态环境或高频视觉要求场景（如高速跟踪）。
5. **计算资源描述不够详细**：未明确报告精确的训练时间（小时）和GPU数量，但根据可用信息可推断为单节点GH200，算力足够但未探索大规模扩展。
6. **未对比其他异步VLA方法**：虽然与几种同步和消融基线对比，但未与异步相关工作的具体实现（如FiS-VLA、DuoCore、VLA-Cache等）进行直接数值比较（可能是因为任务设置差异或未复现）。作者在相关工作部分讨论了这些方法，但实验中未包含。
