## 摘要
本文提出了RepWAM，一种以表示为中心的世界动作模型（WAM），其构建于表示-视觉-动作分词器之上。现有的WAM通常继承自预训练视频生成模型的面向重建的视频分词器。尽管这些分词器保留了视觉保真度，但仅凭像素重建难以有效指导学习将未来预测与机器人控制相连接的遵循指令的动态。为解决这一问题，我们探索了用于以表示为中心的世界动作建模的语义视觉-动作隐空间。具体来说，我们训练了一个表示-视觉-动作分词器，将视觉输入映射为对齐的视觉和潜在动作标记。然后，我们预训练WAM以联合建模未来视觉状态以及在语言指令下连接这些状态的潜在动作，随后适配到真实机器人轨迹以实现闭环操作。在真实世界操作任务和仿真基准上的实验表明，RepWAM在各种操作环境中表现出色，而消融实验则凸显了语义视觉-动作分词化相对于面向重建替代方法的优势。这些结果确立了表示-视觉-动作分词化作为世界动作模型有前景的基础，并朝着通用机器人策略迈出了一步。代码和权重将在 https://github.com/wdrink/RepWAM 提供。

## Abstract
This work presents RepWAM, a representation-centric world action model (WAM) built on representation visual-action tokenizers. Existing WAMs typically inherit reconstruction-oriented video tokenizers from pretrained video generation models. Although these tokenizers preserve visual fidelity, pixel reconstruction alone provides limited guidance for learning instruction-following dynamics that connect future prediction with robot control. To address this, we explore a semantic visual-action latent space for representation-centric world action modeling. Specifically, we train a representation visual-action tokenizer that maps visual inputs into aligned visual and latent action tokens. We then pretrain our WAM to jointly model future visual states and the latent actions that connect them under language instructions, followed by adaptation to real robot trajectories for closed-loop manipulation. Experiments on real-world manipulation tasks and simulation benchmarks show that RepWAM delivers strong performance across diverse manipulation settings, while ablations highlight the value of semantic visual-action tokenization over reconstruction-oriented alternatives. These results establish representation visual-action tokenization as a promising foundation for world action models and a step toward generalist robot policies. Code and weights will be available at https://github.com/wdrink/RepWAM.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：现有世界动作模型（World Action Models, WAM）通常继承自预训练视频生成模型的**重建导向视频分词器**。这类分词器虽能保持像素级视觉保真度，但背后的潜在空间**缺乏语义结构**（如物体身份、空间关系、交互线索），且视觉潜在表示与机器人动作空间**相互分离**，导致逆动力学模型（IDM）需要反复弥合模态鸿沟。因此，指令跟随动态（instruction-following dynamics）的学习效果受限。
- **核心问题**：世界动作模型真正需要的**表示空间**应该是什么样？能否构建一个同时承载视觉语义和动作诱导状态变迁的统一潜在空间？
- **整体含义**：RepWAM 提出**表示-视觉-动作分词器（RepViTok）**，将视觉潜在表示与冻结的视觉基础模型对齐，并在同一空间中学习「潜在动作」作为视觉状态之间的变换，从而为 WAM 提供更语义化、更接近动作的底层表示，最终提升机器人操控性能。

## 2. 论文提出的方法论：核心思想与关键技术细节

- **核心思想**：设计一个**以表示为中心**的 WAM，其基础是一个同时产出语义对齐的视觉 token 和潜在动作 token 的分词器（RepViTok），然后在此统一潜在空间上训练因果世界动作模型。

### 2.1 表示-视觉-动作分词器（RepViTok）

1. **视觉分词（Visual Tokenization）**  
   - 使用 ViT 结构的自编码器；初始帧分 16×16 块，后续帧使用 4×16×16 tubelet；编码器含时间因果掩码和空间全自注意力。  
   - 训练损失包含重建损失（L1、感知损失、GAN 损失）和**特征对齐损失**：
     \[
     \mathcal{L}_{\text{align}} = \| \text{avg}(W_{\text{align}} z) - \text{avg}(G(o)) \|_2^2
     \]
     其中 \(G\) 是冻结的视觉基础模型（如 Perception Encoder），通过线性投影 \(W_{\text{align}}\) 将视觉潜在 \(z\) 拉向语义教师特征。

2. **潜在动作分词（Latent Action Tokenization）**  
   - 冻结视觉编码器后，训练一对模型：**逆动力学模型（IDM）** \(q_\phi\) 将连续两个视觉潜在 \(z_t, z_{t+1}\) 压缩为低维动作 token \(\ell_t\)（\(d_\ell \ll d_v\)）；**前向动力学模型（FDM）** \(f_\psi\) 根据 \(z_t\) 和 \(\ell_t\) 预测下一潜在 \( \hat{z}_{t+1} \)，具体通过预测传输矩阵 \(K_t\) 和残差 \(\delta_t\) 实现：
     \[
     \hat{z}_{t+1} = K_t z_t + \delta_t
     \]
   - 训练损失为前向预测损失 + 反向一致性损失（对逆转序 \((z_{t+1}, z_t)\) 也做同样预测）。

### 2.2 因果世界动作模型（Causal World Action Model）

- 将语言指令通过预训练文本编码器得到条件 token \(c\)；按块（chunk）组织视觉 token 和潜在动作 token，块大小为 \(k\)。
- 使用**因果扩散 Transformer**：采用块因果掩码（block-causal mask），每个块可关注之前所有块；块内视觉和动作 token 共享注意力权重，但使用各自独立的 FFN。
- 训练目标为**条件流匹配（Conditional Flow Matching）**，对视觉和潜在动作分量分别计算 velocity 回归损失，用超参数 \(\lambda_a\) 平衡。
