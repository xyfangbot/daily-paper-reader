## 摘要
视觉-语言-动作（VLA）模型在机器人操作中显示出巨大潜力，但其在测试时的可靠性受到单次动作预测的限制，即使是微小的动作错误也可能导致抓取失败、碰撞或任务进展错误。一个自然的替代方案是为VLA系统配备测试时验证，使得在执行为前能够提出并评估多个候选动作。然而，可靠的动作验证具有挑战性，因为它不仅需要区分候选动作之间细微的几何差异，还需要评估动作是否朝着任务目标有意义的推进。我们提出了VeriSpace，一个面向VLA系统中测试时动作选择的3D感知动作验证器。VeriSpace通过两个关键组件评估候选动作：双路径3D注入场景编码，构建同时保留视觉语义和显式3D几何的场景表示；以及空间接地动作推理，通过推理任务相关的空间关系、几何有效性和预期的目标进展来评估每个动作。这些组件共同实现了对细微但结果关键的候选动作的更可靠区分，同时与现有VLA策略完全兼容。在公开基准和真实世界机器人操作任务上的实验表明，VeriSpace在分布内和分布外设置中都持续提高了底层VLA策略和基于验证的先前方法的决策可靠性。

## Abstract
Vision-language-action (VLA) models have shown strong promise for robotic manipulation, but their reliability at test time remains limited by one-shot action prediction, where even small action errors can cause grasp failure, collision, or incorrect task progression. A natural alternative is to equip VLA systems with test-time verification, allowing multiple candidate actions to be proposed and evaluated before execution. However, reliable action verification is challenging because it requires not only distinguishing subtle geometric differences between candidate actions, but also assessing whether an action makes meaningful progress toward the task goal. We present VeriSpace, a 3D-aware action verifier for test-time action selection in VLA systems. VeriSpace evaluates candidate actions through two key components: Dual-Path 3D-Injected Scene Encoding, which constructs a scene representation that jointly preserves visual semantics and explicit 3D geometry, and Spatially-Grounded Action Reasoning, which evaluates each action by reasoning over task-relevant spatial relations, geometric validity, and expected goal progress. Together, these components enable more reliable discrimination between subtle yet outcome-critical action candidates while remaining fully compatible with existing VLA policies. Experiments on public benchmarks and real-world robotic manipulation tasks show that VeriSpace consistently improves decision reliability over both underlying VLA policies and prior verification-based methods, yielding substantial gains in both in-distribution and out-of-distribution settings.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：视觉-语言-动作（VLA）模型在机器人操作中展现潜力，但现有VLA系统在推理时通常采用“单次预测-立即执行”的模式，缺乏测试时审慎验证。微小动作误差（如位置偏移、姿态偏差）即可导致抓取失败、碰撞或任务中断，尤其在非结构化场景和需精细空间控制的任务中。
- **核心问题**：如何为VLA系统配备可靠的测试时动作验证机制，使其能从多个候选动作中筛选出最可能成功的动作，同时具备对细微几何差异和任务进展的评估能力？
- **整体含义**：提出VeriSpace，一个3D感知的动作验证器，通过显式利用场景3D几何和结构化空间推理，将动作评估从直接打分转变为更可靠的决策过程，兼容现有VLA策略，无需修改其训练或架构。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：采用“生成-验证”范式：先由冻结的VLA策略采样k个候选动作，再由VeriSpace评估每个动作并选优执行。VeriSpace构建于VLM（LLaVA-7B）之上，包含两个关键组件：
  - **双路径3D注入场景编码（Dual-Path 3D-Injected Scene Encoding）**：
    - 从RGB-D观测恢复3D坐标图，经正弦编码+MLP生成3D几何嵌入。
    - 构造两条互补的token流：3D几何标记（直接投影几何嵌入到VLM token空间）和空间增强视觉标记（CLIP视觉特征与3D几何嵌入逐元素相加）。
    - 通过最远点采样+球邻域搜索进行几何引导局部聚合，融入局部3D上下文。
  - **空间接地动作推理（Spatially-Grounded Action Reasoning）**：
    - 采用三步链式推理：先进行动作空间推理（分析物体/末端执行器的相对位置、接触、间隙）；再进行目标进展评估（预动作评估当前状态 vs. 目标，后动作评估预期状态转移）；最后估计验证得分。
  - 使用Bradley-Terry风格偏好损失训练动作排名，同时用交叉熵损失监督CoT推理序列。

- **数据集与场景**：

  - **真实世界**：Franka机器人，6个任务（4个分布内+2个分布外），含抽屉、不同高度等变化。
- **基准**：在SimplerEnv和LIBERO上报告平均成功率。
- **对比方法**：

  - 测试时验证方法：V-GPS、Robomonkey、MG-Select。
  - 额外对比3D-VLA：SpatialVLA、3DS-VLA。
- **公平性措施**：统一候选动作数k=8，采样温度=1，保持其他参数与官方实现一致；所有实验在相同条件下进行。

- **超参数**：batch size 128（每GPU 16），学习率2e-5，LoRA参数r=512, α=128，输入分辨率224×224。
- **VLM基础**：LLaVA-7B（Vicuna-7B），采用Metric Depth Anything V2估计深度，Grounding DINO检测物体，SpatialRGPT生成CoT数据。

- **实验数量**：

  - LIBERO：4个子集×2种VLA基线，共8组对比，每组50次试验。
  - 真实世界：6个任务（4 ID+2 OOD）各50次试验。

- **充分性**：实验覆盖仿真和真实世界、分布内和分布外设置，多组消融验证各组件贡献，跨多种VLA基线验证泛化性。对比方法均为近期SOTA，实验设计较全面，结果统计可靠（多次随机种子）。但缺少在更多真实机器人平台（如差分机器人）上的验证。

## 6. 主要结论与发现

- **VeriSpace显著提升决策可靠性**：在SimplerEnv上，基于OpenVLA提升18.0个百分点（55.0% vs. 37.0%）；基于π0-FAST提升3.5个百分点（60.5% vs. 57.0%）。
- **在LIBERO上持续领先**：基于OpenVLA平均75.2%（+5.9 pp），基于π0-FAST平均94.2%（+6.1 pp），超越先前最佳方法MG-Select。
- **真实世界有效**：分布内平均73.0%（+13.0 pp），分布外平均71.0%（+18.0 pp），尤其对未见物体和空间配置鲁棒。
- **即插即用**：兼容多种VLA模型（OpenVLA、π0-FAST、SpatialVLA、Octo），平均提升3~18 pp。
- **关键设计有效**：3D输入、双路径编码、空间接地推理均为性能关键，缺失任一组件均导致显著下降。

## 7. 优点

- **方法创新**：首次将显式3D几何与结构化空间推理结合用于VLA测试时验证，解决了2D下难以区分细微几何差异的问题。
- **实用性强**：完全即插即用，不修改底层VLA策略的训练或架构，便于部署。
- **实验充分**：覆盖仿真、真实世界、分布外场景，多组消融和跨模型验证，证明泛化性和鲁棒性。
- **性能突出**：在多项基准上超越先前验证方法，尤其在高空间需求任务（如叠方块）上提升巨大（+34 pp）。
- **效率可控**：通过KV缓存复用和并行验证，实际推理时间仅增加约0.07秒，适合实时部署。

## 8. 不足与局限

- **实验覆盖有限**：
  - 真实世界仅使用Franka机器人单一平台，未验证其他机械臂（如UR5、KUKA）或其他形态（如移动操作）。
  - 任务类型以拾放为主，未涵盖更复杂的操作（如装配、柔性物体操作）。
- **依赖深度估计精度**：方法依赖Metric Depth Anything V2进行单目深度估计，在极端光照或透明物体场景下可能失效（未评估）。
- **合成CoT数据质量**：通过自动化管道（SpatialRGPT）生成CoT标注，可能引入噪声或偏差，未与人工标注对比。
- **扩展性挑战**：候选动作数k增大时，成功率达到饱和，且推理时延线性增长（尽管已优化）。
- **开放性问题**：
  - 未与基于强化学习的值函数方法（如V-GPS）在分布外泛化上深入对比。
  - 未讨论失败案例的模式分析（如哪些空间配置下VeriSpace仍然出错）。
