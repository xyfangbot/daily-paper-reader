## 摘要
在本报告中，我们介绍Hy-Embodied-0.5-VLA，简称HyVLA-0.5，这是一个涵盖完整机器人学习栈的端到端系统：数据收集、模型设计、继续预训练和监督微调、强化学习后训练以及实际部署。该栈中的每个组件都扮演着独特的角色。

## Abstract
In this report, we present Hy-Embodied-0.5-VLA, abbreviated as HyVLA-0.5, an end-to-end system that spans the full robot learning stack: data collection, model design, continued pre-training and supervised fine-tuning, RL post-training, and real-world deployment. Each component serves a distinct role in this stack.

# 论文详细总结：Hy-Embodied-0.5-VLA

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：当前视觉-语言-动作（VLA）模型在机器人操控中展现出潜力，但将其转化为可部署的通用机器人仍面临三大耦合挑战：（1）数据收集方面，传统遥操作依赖主从接口，操作不自然且缺乏力反馈，而人类演示数据精度不足；（2）模型架构方面，通用VLM未针对机器人控制优化，离散动作预测限制控制频率与精度；（3）训练与部署方面，标准模仿学习难以达到最后精度，强化学习依赖脆弱的奖励模型，且高频率闭环控制部署未得到充分重视。
- **整体含义**：通用机器人不可能仅由单一模型涌现，必须构建一个从数据采集到真实部署的完整机器人学习堆栈。HyVLA-0.5正是这样一个端到端系统，联合设计了数据、模型、强化学习后训练和部署四个组件。

## 2. 方法论

### 核心思想
- 将VLA建模视为完整管线的组成部分，而非孤立问题。系统包括：**定制数据采集设备**、**基于Mixture-of-Transformers的VLM骨干+流匹配动作专家**、**紧凑记忆编码器**、**delta-chunk动作表示**、**基于偏好优化的离线RL后训练（FlowPRO）**、以及**异步推理与贝塞尔平滑部署**。

### 关键技术细节

#### 2.1 数据收集：Hy-UMI-10K
- **定制指尖UMI设备**：配合运动捕捉笼，采集超过10,000小时的自我中心、亚毫米精度的人类演示。
- 特点：指尖形态恢复自然触觉感知；运动捕捉提供高保真动作标签（替代SLAM）；自我中心视角提供全局语义上下文；数据集超过1M episodes，70个任务，6个任务族（洗衣房、厨房、个人护理等）。

#### 2.2 模型架构
- **骨干**：Hy-Embodied-0.5（4B参数，Mixture-of-Transformers架构，原生分辨率视觉编码）。
- **动作专家**：双塔流匹配（dual-tower flow matching），预测连续动作块（chunk）。使用条件流匹配（conditional flow matching）模拟分布 \( p(A_t | o_t) \)。损失函数为 \( L_{\text{fm}}(\theta) = \mathbb{E}[\| v_\theta(A_t^\tau, o_t) - (\epsilon - A_t)\|_2^2] \)。
- **紧凑记忆编码器**：基于时间-空间注意力压缩多帧历史，无新增可学习参数（复用ViT投影）。
- **动作表示**：delta-chunk，以末端执行器帧表示，解耦策略学习与具体运动学。

#### 2.3 持续预训练与监督微调（SFT）
- 预训练：在Hy-UMI-10K上训练200K步，批量大小1024，学习率5e-5，使用流匹配损失。
- SFT：分为Track A（目标机器人适应，使用同平台遥操作数据）和Track B（仅UMI跨本体转移，无目标机器人遥操作）。训练60K步，批量大小32，学习率2.5e-5。

#### 2.4 强化学习后训练：FlowPRO
- 引入Proximalized Preference Optimization（PRO）的离线RL算法。通过干预-回滚管道收集成对成功/失败轨迹，转换为密集状态偏好元组。
- 损失函数：\( L_{\text{RPRO}}(\theta) = \lambda_{\text{PRO}} L_{\text{PRO}}(\theta) + \lambda_{\text{SFT}} L_{\text{SFT}}(\theta) \)。其中 \( L_{\text{PRO}} \) 包含对比项和邻近正则项，避免奖励黑客问题。
- 无需奖励模型或值函数，直接利用失败案例进行策略改进。

#### 2.5 部署
- **异步推理**：重叠骨干前向传递与动作执行。
- **贝塞尔平滑**：使用三次贝塞尔曲线保证C1连续过渡，避免块间跳跃。
- **平台映射**：通过相对-EE变换将动作映射到不同机器人（固定基座臂、浮动基座人形）。

## 3. 实验设计

### 数据集与场景
- **预训练**：Hy-UMI-10K（10,000小时自我中心UMI数据）。
- **模拟评估**：RoboTwin 2.0基准（50个双手操作任务，Clean和Randomized设置，共2,750 episodes，超过6M帧）。
- **真实机器人**：Dobot X-Trainer（Track A，4个任务，每任务300演示，共18小时）；JAKA K1（Track B，1个任务，300 UMI演示，1.2小时）；Astribot S1（Track B，1个任务，200 UMI演示，1.5小时）；Unitree G1（力模态验证，1个任务，400 UMI演示，2.2小时）。
- **FlowPRO实验**：Dobot X-Trainer上4个长视野双手任务（Bottle, Cap, USB, Zip），每任务3轮后训练。

### 基准方法
- **模拟**：对比π0、π0.5、ABot-M0、LingBot-VLA、starVLA、Motus、JoyAI-RA、Qwen-VLA。
- **真实**：DAgger（正样本聚合）、π0.6*（优势条件回归，相同偏好数据）。
- **消融**：移除紧凑记忆编码器、移除UMI预训练。

## 6. 主要结论与发现

1. **全栈系统有效性**：HyVLA-0.5在模拟RoboTwin 2.0上达到90.9%（Clean）和90.1%（Randomized）平均成功率，超过所有对比方法（如π0、π0.5、JoyAI-RA等）。
2. **UMI预训练的价值**：消融实验表明，去除UMI预训练后模拟性能下降（88.1% vs 90.9%）；在真实Track A任务中，UMI预训练显著提升关键子步骤精度，如折叠眼镜、拉拉链等。
3. **跨本体转移成功**：在Track B中，仅使用UMI演示（无目标机器人数据）即可在JAKA K1和Astribot S1上实现可部署性能，效果优于π0和π0.5。
4. **FlowPRO显著提升**：经过3轮后训练，任务成功率接近天花板（Bottle 99%, Cap 99%, USB 98%, Zip 94%），且完成时间缩短明显优于DAgger和π0.6*。
5. **力模态可用**：Unitree G1成功区分轻重盒子，证明UMI工作站采集的触觉信号可被策略利用。
6. **部署流畅性**：异步推理+贝塞尔平滑有效消除了动作块间的跳跃。

## 7. 优点

- **系统性**：并非孤立优化模型，而是联合设计了数据、表示、训练、部署全流程，组件之间互相支撑。
- **数据创新**：定制指尖UMI设备解决了传统遥操作和SLAM式UMI的精度与触觉反馈问题；10K小时大规模高质量数据。
- **动作表示**：delta-chunk + 末端执行器帧解耦策略与机器人运动学，利于跨本体迁移。
