## 摘要
零样本物体目标导航（ZS-OGN）要求具身智能体在没有预先训练的情况下探索并定位目标物体。为此，近期的方法利用了基础模型。但它们通常依赖静态先验知识且缺乏适应性，导致重复错误和代价高昂的试错。本文提出一种自进化ZS-OGN框架，能够在测试时持续改进。具体地，我们通过从过往轨迹中提取可行动知识来构建智能体规则记忆。然后，我们提出一种基于上置信界的检索策略，通过平衡语义相关性和历史成功率来选取有效规则。此外，我们引入一种记忆引导的预反思模块，在执行动作前预测潜在结果，从而减少低效探索。大量实验表明，我们的方法优于现有的零样本基线，在更少的不必要步骤下实现了10.1%的成功率提升。

## Abstract
Zero-Shot Object-Goal Navigation (ZS-OGN) requires embodied agents to explore and locate target objects without any prior training. To this end, recent methods leverage foundation models. But they typically rely on static priors and lack adaptation, which leads to repeated errors and costly trial and error. In this paper, we propose a self-evolving ZS-OGN framework that enables continuous test-time improvement. Specifically, we build an agentic rule memory by extracting actionable knowledge from past trajectories. Then, we propose a retrieval strategy based on upper confidence bound, selecting effective rules by balancing semantic relevance and historical success. In addition, we introduce a memory-guided preflection module that forecasts potential outcomes before action, reducing inefficient exploration. Extensive experiments show that our method outperforms existing zero-shot baselines, achieving a 10.1\% improvement in success rate with fewer unnecessary steps.

## 一、论文的核心问题与整体含义（研究动机和背景）

- 零样本物体目标导航（ZS‑OGN）要求具身智能体在无预先训练的情况下，在未知环境中探索并定位目标物体。现有方法大多依赖大语言模型/视觉语言模型提供的静态先验知识，缺乏在线自适应能力，导致智能体在测试时重复犯相同错误（如被视觉相似物体误导），且试错成本高昂。  
- 关键挑战在于：如何在有限步数预算下，同时实现**在线自适应**和**动作预判**，从而避免低效探索。作者提出 EvolveNav 框架，将导航转化为持续自我改进的过程，使智能体从过去的成功与失败中学习可行动的导航规则，并前瞻性地评估候选动作的风险。

## 二、论文提出的方法论

- **核心思想**：构建一个无需微调的测试时自进化框架，包含两个紧密耦合的模块：  
  - **智能体规则记忆**：在每轮导航结束后，智能体通过大语言模型分析轨迹，提取关键决策步骤，并利用**语义驱动的信用分配**（基于相邻步骤的语义相似度增益）量化每个步骤的贡献，生成可复用的导航规则。规则存入记忆库，并通过**基于上置信界（UCB）的动态权重更新**平衡已有规则与新规则的利用与探索：  
    \[
    \text{UCB}(r) = \mu_r + \beta \sqrt{\frac{\ln T}{N_r}}
    \]  
    其中 \(\mu_r\) 为规则的历史期望效用（通过动量式迭代更新），\(T\) 为已完成轮次总数，\(N_r\) 为规则被检索的次数，\(\beta\) 控制探索程度。新规则初始 UCB 设为无穷大以确保被尝试。  
  - **记忆引导的预反思模块**：在每个决策时刻，智能体从规则记忆中检索 top‑K 规则，并结合当前候选前沿点的局部观测（几何距离、可见物体等），让大语言模型先对各前沿点进行**失败风险预测**，再选择最优、风险最低的方向执行。这实现了从“事后修正”到“事前规避”的转变，大幅减少物理试错成本。

- 整体流程：  
  1. 利用 RGB‑D 观测实时构建 2D 占据网格地图，提取候选前沿点。  
  2. 通过预反思模块评估每个前沿点的风险，选择最优方向，并由低层导航控制器执行移动（最多 H 步）。  
  3. 每轮导航结束后，提取关键步骤并生成新规则，更新记忆库及 UCB 权重。

## 六、论文的主要结论与发现

- EvolveNav 在 HM3D 上达到 **67.3% SR** 和 **33.9% SPL**，在 MP3D 上达到 **49.0% SR** 和 **19.1% SPL**，显著优于所有零样本基线（SR 提升最高达 10.1%）。

- 通过规避试错，智能体生成了更直接、高效的导航路径，避免了陷入局部陷阱。

## 七、优点

- **创新性地结合了自进化记忆与预反思**，将零样本导航从静态先验驱动转变为动态经验驱动，实现了测试时的持续改进。  
- **规则记忆采用 UCB 管理**，既利用了历史成功规则，又保证了新规则的探索，避免知识固化。  
- **预反思模块将纠错提前到动作执行前**，显著减少了物理试错步骤，提高了步数利用率。  
- 方法无需任何参数微调，完全基于大语言模型的推理和 prompt 注入，具有较好的通用性。  
- 在复杂多楼层、大尺度场景（MP3D）上的表现尤为突出，证明了其跨环境泛化能力。

## 八、不足与局限

- **依赖 2D 视觉模型**：持续的 2D 检测错误可能直接导致导航失败，缺乏多视角验证或主动感知。  
- **对非常规布局敏感**：例如“厨房中的床”等违反常理的空间配置可能使规则失效，导致低效循环，规则更新策略需进一步优化。  
- **实验未报告多次运行的统计波动**，无法判断性能的鲁棒性。  
- **未考虑多智能体协作**，当前为单智能体系统，在大规模环境中的扩展性有限（未来工作提及）。  
- **未讨论预反思和规则生成的推理延迟**，在实际实时机器人上部署可能存在挑战。
