## 摘要
为了在真实家庭中长时间协助人类，具身智能体必须记住用户习惯、世界状态和过去的交互。现有的长期记忆基准主要评估以语言为中心的检索和问答，而具身基准通常关注短视野任务执行，不测试动态环境中长期记忆的使用。我们提出WorldLines，一个面向项目驱动的长视野具身家务辅助基准。它构建了带有对话、动作、执行反馈、物体和设备状态变化的时间扩展的家庭轨迹，并将其转换为基于证据的样本，用于记忆问答和具身任务规划。我们进一步提出ObsMem，一个基于观察者的记忆框架，它维护可见性感知记忆和行为原生状态轨迹，以进行状态感知决策。实验揭示了在部分可观测性、被覆盖的世界状态以及将长期记忆转化为具身计划方面的持续挑战，而ObsMem为这一设置提供了更强的参考架构。

## Abstract
To assist humans over extended periods in real homes, embodied agents must remember user routines, world states, and past interactions. Existing long-term memory benchmarks mainly evaluate language-centric retrieval and question answering, while embodied benchmarks often focus on short-horizon task execution without testing long-term memory use in dynamic environments. We introduce WorldLines, a project-driven benchmark for long-horizon embodied household assistance. It constructs temporally extended household traces with dialogues, actions, execution feedback, object and device state changes, and converts them into evidence-linked samples for Memory QA and Embodied Task Planning. We further propose ObsMem, an observer-grounded memory framework that maintains visibility-aware memories and action-native state trails for state-aware decisions. Experiments reveal persistent challenges in partial observability, overwritten world states, and translating long-term memory into embodied plans, while ObsMem offers a stronger reference architecture for this setting.

## 二、论文提出的方法论
- **WorldLines基准构建**
  - 项目驱动轨迹生成管道：基于Habitat/HSSD家庭场景世界接地 → 项目规划（长期生活主题，如健身计划、家务组织） → 闭环轨迹模拟（导演/演员/执行器，生成带时间戳的对话、人类活动、机器人动作、设备操作、执行反馈及状态变化） → 携带记忆（跨天笔记，保持连续性） → 证据链接样本构造（设定内容截止点，避免未来信息泄漏）。
  - 每个样本包含可见历史 \( H_{<c_i} \)、问题 \( q_i \)、基础真相状态 \( S_{c_i} \)、证据链 \( E_i \)、参考答案或计划 \( y_i^* \)、任务类型 \( \tau_i \)。
  - 两个任务族：Memory QA（召回历史事件、状态变化、偏好、习惯）和Embodied Task Planning（生成状态一致的可执行计划或下一步决策）。
- **ObsMem：基于观察者的记忆框架**
  - 观察者门控输入：只有机器人直接观察到的事件才进入记忆；对话中的报告信息作为“报告原子”单独存储。
  - 类型化记忆构建：
    - 事件轨迹（Event Track）：仅追加，保留历史证据。
    - 状态轨迹（State Track）：维护当前快照和历史，支持当前状态查询和被覆盖状态恢复。
    - 信念轨迹（Belief Track）：基于干预事件、行动者、矛盾证据，用确定性规则标记事实的信念状态（fresh / stale / uncertain / contradicted）。
    - 承诺轨迹（Commitment Track）：记录请求、提醒、计划等未来义务。
  - 查询时检索：根据问题意图（当前状态、过去事件、承诺等）路由到相应记忆视图，再用证据选择器选出互补的紧凑证据捆绑。
  - 逐步情节合并：检测情节边界后创建可立即检索的情节卡片，并可选地将摘要、事实原子、承诺写回对应轨迹。

## 三、实验设计
- **数据集/场景**：WorldLines基准，基于Habitat/HSSD家庭场景，包含310个Memory QA样本和21个Embodied Planning样本（规划样本平均7.6个目标动作、3.1个记忆状态约束）。
- **对比方法**：A-mem（官方实现，智能体记忆演化）、Mem0（官方默认提取/更新管道）、MemoryOS（分层记忆更新）、GraphMem（基于规范重实现，图构建和扩展）以及本文的ObsMem。
- **评估指标**：
  - Memory QA：Judge（LLM-as-judge归一化得分）、Perfect Rate（满分比例）、Session Any@5（至少一个正确会话在top-5）、Event R@5（正确答案事件在top-5中的平均召回率）。
  - Embodied Planning：Plan Judge、State Consistency、Precondition Validity、Memory Use、Action Order。
- **控制设置**：所有方法接收相同截止控制的可见历史；答案生成上下文上限为5条记录；使用相同的回答生成模型（Google Gemini 3.5 Flash）和judge模型（GPT-4o）。
- **Judge验证**：80个样本，人类标注者间Fleiss κ=0.71，GPT-4o与多数人类标签一致率87.5%，Spearman相关系数0.82。

## 七、优点
- **新颖的基准设计**：WorldLines是首个同时覆盖长期记忆和动态物理世界状态的具身基准，具有严格的截止控制和证据链注释，测试智能体的世界状态维持能力，而非仅是文本检索。
- **记忆框架的层次化与类型化**：ObsMem区分观察与报告、当前与历史、确定与不确定，支持不同类型的查询路由到合适的记忆视图，提升了回答的精度和可解释性。
- **公平的实验控制**：所有方法使用相同可见历史、相同上下文长度上限、相同生成模型，减少不公平因素。
- **丰富的诊断指标**：除整体得分外，还报告Session Any@5和Event R@5，揭示了仅靠会话检索的不足；消融实验精细地分析每个组件贡献。
- **下游规划验证**：超越了纯QA，检验记忆对实际动作规划的帮助，更具应用价值。

## 八、不足与局限
- **模拟环境局限**：所有实验在Habitat/HSSD模拟环境中进行，未考虑感知噪声、执行误差、真实人类行为的开放性；缺乏视觉观察信息（仅使用文本结构化信息）。
- **样本规模偏小**：Memory QA仅310个样本，Planning仅21个样本，可能不足以支撑强统计结论；消融实验子集仅62个样本。
- **ObsMem的部署依赖**：ObsMem依赖于结构化输入（实体标识、可见性注释、动作模式），在真实部署中需要感知、定位、接地模块提供这些信号，增加了系统复杂度。
- **延迟与效率**：ObsMem的平均延迟（5.13秒）高于其他基线，且返回记录数更少（平均3.4条），结构化检索和信念评估增加了计算开销。
- **未探索多模态融合**：基准和记忆框架目前仅处理文本/结构化轨迹，未与视觉感知、点云等结合，限制了在更真实场景中的应用。
- **人类行为多样性有限**：项目驱动轨迹虽有一定随机性，但仍是基于规则和大模型生成的脚本化行为，未涵盖真实的家庭多任务交织和意外事件。
