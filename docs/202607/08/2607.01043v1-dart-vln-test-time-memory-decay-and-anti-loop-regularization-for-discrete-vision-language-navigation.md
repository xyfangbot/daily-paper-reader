## 摘要
基于记忆的离散视觉语言导航（VLN）代理必须在部分可观测性下行动，然而即使是强大的冻结骨干网络在测试时仍然脆弱。两种常见的失败模式是记忆读取时的过时历史证据以及动作选择期间的低效局部回溯。我们提出DART-VLN，一种面向离散VLN的无训练测试时控制框架。DART-VLN结合了测试时记忆衰减（一种读取侧记忆重加权规则，无需重写存储内容即可抑制过时和冗余证据）与防循环正则化（一种轻量级的下一跳惩罚项，可在动作选择期间阻止立即反转）。该框架不引入新的可学习参数，并保持学习到的骨干网络不变。在R2R和REVERIE上的实验显示出一致的模式：仅衰减在读取侧提供了稳定的收益，而衰减+防循环在关键设置中实现了最佳的整体质量-效率权衡，产生更短的轨迹、更低的运行时间和改进的导航性能。行为分析进一步证实，防循环正则化减少了局部回溯，并在冻结骨干网络下提高了路径效率。总体而言，结果表明适度的测试时控制可以在无需重新训练的情况下使基于记忆的离散VLN更可靠和高效。

## Abstract
Memory-based discrete vision-language navigation (VLN) agents must act under partial observability, yet even strong frozen backbones remain vulnerable at test time. Two common failure modes are stale historical evidence at memory readout and inefficient local backtracking during action selection. We present DART-VLN, a training-free test-time control framework for discrete VLN. DART-VLN combines Test-Time Memory Decay, a read-side memory reweighting rule that suppresses stale and redundant evidence without rewriting stored content, with Anti-Loop Regularization, a lightweight next-hop penalty that discourages immediate reversals during action selection. The framework introduces no new learnable parameters and leaves the learned backbone unchanged. Experiments on R2R and REVERIE show a consistent pattern: decay-only provides stable read-side gains, while decay+anti-loop achieves the best overall quality-efficiency trade-off, yielding shorter trajectories, lower runtime, and improved navigation performance in key settings. Behavioral analysis further confirms that anti-loop regularization reduces local backtracking and improves path efficiency under frozen backbones. Overall, the results show that modest test-time control can make memory-based discrete VLN more reliable and efficient without retraining.

## 一、论文的核心问题与整体含义（研究动机和背景）
- **研究背景**：离散视觉语言导航（VLN）要求智能体在部分可观测环境下，根据自然语言指令和视觉观察进行顺序决策。基于记忆的离散VLN方法通过存储历史视点、视觉特征或地图级上下文来辅助长程推理，已成为主流范式。
- **核心问题**：即使使用强大的预训练骨干网络（frozen backbone），测试时仍存在两种典型失效模式：  
  - 记忆读取时的陈旧/冗余证据：历史记忆槽中的过时或重复信息在聚合时仍保持相同权重，导致决策噪声。  
  - 动作选择时的低效局部回溯：智能体容易发生立即反转和短循环，导致轨迹延长、步数浪费和运行时增加。
- **研究动机**：探索是否可以通过轻量级的测试时控制（不重新训练、不修改架构）来改善冻结骨干网络的推理行为，提升导航质量与效率。

## 二、论文提出的方法论
- **核心思想**：提出DART-VLN，一个无训练的测试时控制框架，包含两个互补机制，直接集成到现有推理循环中，不引入新可学习参数，保持骨干网络不变。
- **关键技术细节**：
  - **测试时记忆衰减（Test-Time Memory Decay）**：  
    - 读取侧操作：在记忆聚合时对每个记忆槽进行重新加权，抑制过时和冗余证据，但不重写存储内容。  
    - 维护三个轻量级元数据：槽年龄 \(a_i\)（当前步数与上次刷新步数之差）、访问次数 \(c_i\)、新颖性 \(n_i\)（通过指数滑动平均更新特征变化）。  
    - 读权重公式：  
      \[
      w_i = \text{clip}\left( \exp(-\lambda a_i) \left(1 - \alpha \frac{c_i}{c_i+1}\right) (0.5 + 0.5 n_i), \, w_{\min}, w_{\max} \right)
      \]  
      其中：\(\exp(-\lambda a_i)\) 为衰减项，\(\alpha\) 控制重复抑制强度，新颖性项软性偏好仍存在特征变化的槽。
    - 仅作用于读取侧，与基线存储结构兼容，是一种“读取侧去噪规则”。
  - **防循环正则化（Anti-Loop Regularization）**：  
    - 动作侧操作：在每次动作选择前，对候选目标视点的原始分数施加一个轻量惩罚，抑制立即回溯和重复访问。  
    - 惩罚项：  
      \[
      p_t(v) = \beta_{\text{back}} \cdot \mathbb{I}[h(v) = v_{t-1}] + \beta_{\text{rev}} \cdot \mathbb{I}[\text{visit}(h(v)) \ge k]
      \]  
      其中：\(h(v)\) 是从当前视点到候选视点的图下一跳（第一跳）；第一项惩罚直接返回上一视点；第二项对重复访问次数超过阈值 \(k=2\) 的下一跳施加弱惩罚。  
    - 调整后分数：\(s'_t(v) = s_t(v) - p_t(v)\)，然后取 \(\arg\max\) 选择动作。
    - 仅应用于测试时，用于确定性 argmax 推理，不修改停止头或引入规划模块。
- **算法流程**：在每个步中，先编码当前观测，计算记忆读权重并聚合得到候选分数；然后对每个候选视点计算惩罚并调整分数；选择分数最高的动作；执行后更新元数据。详见算法1。
