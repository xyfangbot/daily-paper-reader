## 摘要
当前的视觉-语言-动作（VLA）模型在机器人操作方面表现出色，但由于依赖即时观测，往往难以处理需要长期记忆和推理的非马尔可夫任务。现有解决方案面临“频率-能力悖论”：更强的推理模型对于实时控制来说太慢，而更快的模型又缺乏足够的推理能力。为了解决这一架构性错位问题，我们提出了HiMe，一种分层具身记忆框架，它将具身智能解耦为用于执行的高频执行器、用于工作记忆的哨兵以及用于长期策略的计划器。我们还引入了一个基于跨模态语义模式和主动管理机制的动态知识系统，使机器人能够通过“添加、更新和删除”操作保持记忆可塑性。这种分层设计有效平衡了实时执行与慢速思考规划之间的冲突，显著提升了长程任务的成功率。实验表明，该方法不仅优于平面记忆基线，还展现出根据人类偏好自我修正内部知识的新能力。

## Abstract
Current Vision-Language-Action (VLA) models excel at robotic manipulation but often struggle with non-Markovian tasks requiring long-term memory and reasoning due to their reliance on immediate observations. Existing solutions face a ''frequency-competence paradox,'' where stronger reasoning models are too slow for real-time control, while faster models lack sufficient reasoning capabilities. To resolve this architectural misalignment, we propose HiMe, a Hierarchical Embodied Memory framework that decouples embodied intelligence into a high-frequency Executor for execution, a Sentry for working memory, and a Planner for long-term strategy. We also introduce a dynamic knowledge system based on cross-modal semantic schemas and active management mechanisms, allowing robots to maintain memory plasticity through ''Add, Update, and Delete'' operations. This hierarchical design effectively balances the conflict between real-time execution and slow thinking planning, significantly improving success rates in long-horizon tasks. Experiments demonstrate that this approach not only outperforms flat memory baselines but also exhibits the novel ability to self-correct its internal knowledge based on human preferences.

## 二、论文提出的方法论
- **核心思想**：提出 HiMe 层次化具身记忆框架，受人类认知的多重存储结构启发，将具身智能解耦为三个功能层，分别对应不同时间分辨率的记忆与处理。
  - **Executor（执行器）**：管理瞬态记忆，是一个高频VLA模型，直接将当前观测和活跃子目标映射为动作，保证物理稳定性和实时性。
  - **Sentry（哨兵）**：管理工作记忆（短时记忆），是一个轻量VLM，异步监测执行器进度，在检测到子任务完成或环境状态变化时触发Planner，避免频繁调用重型模型。
  - **Planner（规划器）**：管理情景记忆（长期记忆），是一个重型VLM，仅在Sentry触发时才被调用，进行记忆检索、更新和重规划。
- **关键技术细节**：
  - **跨模态语义模式（What to memorize）**：情景记忆采用对象中心表示，视觉经验与高密度文本描述深度锚定，使Planner不仅能检索视觉特征，还能检索隐含的所有权、程序规则和用户偏好。
  - **主动管理机制（How to memorize）**：引入 Add（添加新事实）、Update（更新过时条目）、Delete（删除冗余/冲突信息）三种显式操作，赋予机器人知识可塑性，保持记忆与环境进化对齐。
  - **记忆结构**：情景记忆包含两部分：
    - 上下文记忆：多模态键值存储，累积任务相关信息，支持通过文本键检索。
    - 程序记忆：有序的文本子目标列表，每个子目标带有状态（active/pending/done）。
  - **决策流程**：Executor根据当前子目标生成动作；Sentry每隔一定步数（n_m=5）检查子目标完成情况；一旦触发，Planner首先进行上下文检索，然后联合更新上下文记忆和程序记忆，输出新的活跃子目标。
  - **实现细节**：Planner使用GPT-4o（零样本/少样本），Sentry使用Qwen3-VL-8B，Executor基于π0.5微调。内存后端使用向量数据库和OpenAI text-embedding-3进行语义检索。

## 三、实验设计
- **实验场景**：设计了三个真实桌面操作任务，覆盖不同记忆挑战：
  - **Object Search（物体搜索）**：机器人需检查不透明盒子内容、推断存储规则、动态更新记忆、检索偏好对象。
  - **Counting（计数）**：机器人需解读视觉食谱、记录已处理材料、根据用户偏好调整成分。
  - **Rearrangement（重排）**：机器人执行“清理-恢复”两阶段操作，需回忆原始空间布局和用户放置偏好。
- **评估设置**：使用WidowX-250臂和并行夹爪，双摄像头（第三视角和腕部视角）。Executor以2Hz运行，预测10个动作的块，其中5个开环执行。Sentry每10个执行步骤查询一次。
- **Baseline对比**：
  - Transient Memory：标准层次VLA，Planner按固定周期调用，只接收当前观测。
  - Transient Memory w/ Sentry：引入Sentry触发，但Planner仍无记忆。
  - Flat Memory：Planner按固定周期接收最近8帧+FIFO队列（类似MemER）。
  - HiMe w/o Sentry：完整Planner记忆但移除Sentry，固定周期调用。
  - HiMe (Ours)：完整框架。
  - Human High-level：人类提供正确子目标作为上限。
- **评估指标**：Task Progress（完成子目标比例）、API Calls（每子任务Planner平均调用次数）、Memory Hit Rate（所需信息在内存中的命中率）。每个任务对每种方法进行20次试验。

## 六、论文的主要结论与发现
- HiMe在三个长程操作任务上平均任务进度达到90%，显著优于所有基线（Transient Memory 26%，Transient Memory w/ Sentry 56%，Flat Memory 65%，HiMe w/o Sentry 68%），接近人类最高水平94%。
- Sentry机制的价值：即使Planner无记忆，引入Sentry也能提升性能（14%→26%），因为Sentry强制了Planner的时序一致性，减少任务切换噪声；同时通过聚合子任务过程信息提供高质量工作记忆，降低Planner幻觉。
- 跨模态记忆优于单一模态：纯文本丢失空间细节，纯图像难以提取语义和逻辑，两者结合（文本+图像）在平均任务进度上达到最佳（90%）。
- 主动记忆管理（Add/Update/Delete）优于被动存储：FIFO因遗忘早期关键信息表现最差（68%），无管理虽保留全部历史但因冗余和冲突略低（86%），HiMe通过主动更新和删除维持一致性，达到90%。
- 效率和可靠性优势：HiMe相比Flat Memory减少API调用约3倍（例如Object Search中从5.4降至1.8），同时记忆命中率更高（94% vs 68%），减少重复探索。
- 记忆可扩展性：随着任务轮次增加，记忆大小增长但任务进度下降（单轮92.5%，两轮76.3%，三轮66.7%），表明长时间演化场景下维持正确记忆仍是挑战。

## 七、优点
- **创新的层次化架构**：首次将具身记忆明确分为瞬态、工作、情景三层，并分别由不同时间分辨率的模型管理，从根本上解决了实时性与长期规划的冲突。
- **跨模态语义记忆设计**：将视觉经验与文本描述深层绑定，使机器人既能处理空间定位，又能处理语义逻辑和用户偏好，优于纯文本或纯图像记忆。
- **主动记忆管理机制**：引入Add/Update/Delete操作，使记忆能够随环境和用户意图动态进化，具有自纠正能力，这在机器人领域是新颖的。
- **高效的触发机制**：Sentry以轻量模型监测子任务完成，仅当需要时才调用重型Planner，大幅减少计算开销和API成本，同时保证任务一致性。
- **全面的实验验证**：在真实机器人上设计了覆盖不同记忆挑战的三个任务，进行了多基线对比、充分消融和额外分析（开源Planner、可扩展性、延迟），结论可信度高。
- **良好的通用性**：框架与模型无关，主实验使用GPT-4o，开源实验使用Qwen3-VL-30B均取得一致结果，表明其可移植性。

## 八、不足与局限
- **缺乏标准仿真基准**：所有评估均在真实机器人上进行，不便于受控比较和基准级复现，限制了与更广泛文献的精确对比。
- **任务类型有限**：当前任务仅包含pick-and-place等相对简单的操作原语，未涉及更精细、更灵巧的操作技能（如组装、烹饪等），验证范围有待扩展。
- **工作记忆窗口与触发机制依赖于经验参数**：缓冲区大小（8帧）、监测间隔（5步）等未系统优化，可能影响在不同任务下的通用性。
- **记忆可扩展性存在下降趋势**：随着任务轮次增多（3轮后），即使使用主动管理，任务进度仍下降（92.5%→66.7%），表明在极长水平或持续变化环境中，记忆维护仍是瓶颈。
- **Sentry的保守性**：Sentry的召回率较低（约35%），倾向于漏报（将完成的子任务误判为未完成），虽通过固定间隔回退解决，但可能导致额外延迟或死循环风险。
- **Planner依赖于商业API**：主实验使用GPT-4o，虽然补充实验使用了开源模型，但开源Planner的性能仍低于GPT-4o，且开源部署需要较大GPU资源（2×H100）。
- **硬件依赖性**：实验仅在一款机械臂（WidowX-250）上进行，未验证在其它硬件（如灵巧手、移动机器人）上的迁移性。
