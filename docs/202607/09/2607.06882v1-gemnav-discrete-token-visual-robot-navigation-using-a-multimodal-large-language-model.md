## 摘要
基于大型预训练模型的视觉导航策略迄今为止遵循一个通用配方：专用的视觉编码器、定制的动作头以及在数千小时的跨实体数据集上的训练。我们质疑这种配方的必要性。本文介绍GemNav，一种视觉机器人导航策略，它通过仅在语言塔上使用低秩适应（LoRA），无需辅助视觉编码器且无需连续回归头，来适配一个冻结的多模态大语言模型（MLLM）用于中短期航点导航。航点和分类导航信号共享由语言模型头生成的单一离散令牌词汇表，而一个软解码辅助损失恢复了纯交叉熵训练所丢弃的度量结构。在单个8.7小时的开源语料上（比竞争训练集小约三个数量级），该策略零样本迁移到四个物理上不同的未见环境，并在涵盖开放停车场、障碍停车场、长距离室外化工厂和室内仓库的20次真实世界试验中，在目标0.25-0.42米范围内停止。对短图像历史的调节改善了离线指标，但对机器人没有带来益处，这表明一旦预训练视觉特征到位，时间上下文的贡献达到上限。这些结果表明，冻结的MLLM的离散令牌适应可以为基础模型机器人导航提供一种数据高效的、可部署的替代方案。

## Abstract
Visual navigation policies built on large pretrained models have so far followed a common recipe: a dedicated visual encoder, a bespoke action head, and training on thousands of hours of cross-embodiment datasets. We ask whether this recipe is necessary. In this paper, we introduce GemNav, a visual robot navigation policy that adapts a frozen Multimodal Large Language Model (MLLM) for short-to-medium horizon waypoint navigation using Low-Rank Adaptation (LoRA) on the language tower alone, with no auxiliary visual encoder and no continuous regression head. Waypoints and categorical navigation signals share a single discrete token vocabulary generated by the language-model head, and a soft-decoded auxiliary loss recovers the metric structure that pure cross-entropy training discards. On a single 8.7-hour open corpus, roughly three orders of magnitude smaller than competing training sets, the policy transfers zero-shot to four physically distinct unseen environments and stops within 0.25-0.42m of the goal across 20 real-world trials covering an open carpark, an obstacle carpark, a long outdoor chemical yard, and an indoor warehouse. Conditioning on short image histories improves offline metrics but yields no robot benefit, pointing to a ceiling on what temporal context adds once pretrained vision features are in place. These results indicate that discrete-token adaptation of frozen MLLMs can provide a data-efficient, deployable alternative for foundation model robot navigation.

## 二、论文提出的方法论
- **核心思想**：将视觉导航转化为**条件序列预测**任务，保持 MLLM（Gemma 4-E2B-it）的视觉塔冻结，仅对语言塔应用 LoRA（秩 r=32，α=16），通过语言模型头生成离散 token，统一表示连续航点轨迹和分类导航信号（<goal_reached> / <goal_unreachable>）。
- **关键技术细节**：
  1. **航点离散化**：K=64 个均匀区间覆盖 [-15m, 15m]，每轴 0.469m 分辨率。航点序列表示为 18 个 token：<bot_traj> + 16 个值 bin token（8 个 (x,y)）+ <eot_traj>。
  2. **停止信号**：用相同 token 语法包裹：<bot_traj> + <goal_reached>/<goal_unreachable> + <eot_traj>。
  3. **辅助损失**：在标准交叉熵损失基础上，增加软解码回归损失（λ=0.1），通过对值 bin token 的 softmax 概率加权预测连续值，恢复度量结构。仅用于轨迹样本，不用于停止样本。
  4. **目标规格**：支持图像目标（ego）、2D 坐标目标（pose）或两者联合（ego+pose）。2D 坐标也用值 bin token 编码，前缀 <goal_coord>，使模型遇到的条件与生成的 token 表示一致。
  5. **提示构建**：使用 Gemma 4 的用户轮模板，包含任务描述、当前（及可选的过去）图像帧、目标图像（可选）、目标坐标 token（可选），最后以 Trajectory: 触发助理轮。
  6. **训练流程**：四阶段 warm-start 链（A → B → C1 → C2），每阶段 40,000 步，阶段内 LoRA 适配器从上一阶段初始化，逐步引入所有模态。
- **关键公式**：
  - 量化：b(v) = min(K-1, ⌊ (v+B)/(2B) · K ⌋)，c(b) = -B + (b+0.5)·2B/K。
  - 软解码预测：â_k = c^T π_(k,a)，其中 π_(k,a) 是值 bin token 的 softmax。
  - 总损失：L = L_CE + 0.1·(1/(2N) Σ Σ (â_k - a_k)^2)。

## 六、论文的主要结论与发现
- **主要结论**：冻结的 MLLM（视觉塔不动）通过离散 token 适应（LoRA + 共享词汇）可数据高效地实现零样本迁移导航，无需专用视觉编码器或连续回归头。
- **关键发现**：
  1. 在仅 8.7 小时小数据集上训练后，在 4 个未见真实环境中成功完成所有 pose 模态试验，停止误差 0.25–0.42m。
  2. 辅助软解码回归损失将验证 ADE 降低 23%（相对于纯交叉熵）。
  3. 短图像历史（h=2/4）改善离线 ADE，但实际部署中无益甚至有害（h=4 成功率下降 20%），归因于时间滞后轨迹效应。
  4. 基于距离的 goal 采样器比基于固定帧偏移的采样器更有利于部署（后者导致 OOD 位姿 FDE 上升到 2.88m，且全部失败）。
  5. 纯图像目标（ego）停止不可靠（仅 1/5 成功），依赖位姿坐标才能稳定停止。

## 七、优点
- **方法论创新**：首次将离散 token 统一表示航点和停止信号应用于机器人导航，无需任何连续回归头或额外动作头，设计简洁。
- **数据高效**：仅用 8.7 小时单一平台数据（比 OmniVLA 的 9,500 小时小三个数量级）即实现跨场景迁移，证明冻结 MLLM 的视觉表示足够强大。
- **软解码辅助损失**：在不增加参数的前提下恢复了离散 token 的度量结构，原理清晰且效果显著（ADE 降低 23%）。
- **实验设计严谨**：涵盖消融、基线对比、离线与在线一致性分析，并诚实地报告了负面结果（历史深度、数据混合），为社区提供有价值的洞见。
- **零样本多模态融合**：训练时未同时见过的 pose+ego 联合模态，在阶段 C1 中零样本迁移即取得接近专门训练的性能（ADE 0.43m vs 0.35m）。
- **开源贡献**：计划发布 TokenWalker 数据集以确保可复现性。

## 八、不足与局限
- **跨实体未测试**：仅在一个平台（Spot）和一个语料（SCAND）上训练和部署，跨机器人泛化性尚未验证。
- **纯图像目标停止不可靠**：与先前 SOTA 方法类似，依赖位姿坐标才能稳定发出停止信号，限制了纯视觉目标导航的实用性。
- **动作空间限制**：输出仅为 2D (x,y) 航点，无法表达原地旋转（模型会过滤 yaw 差 >30° 的训练样本），且会过滤目标在机器人后方的样本（x_g < -0.3m）。
- **存在时间滞后轨迹效应**：较长历史窗口导致策略倾向于延续过去运动，在闭环中引起超调，说明离线 ADE 不能完全代表部署性能。
- **数据集覆盖有限**：训练集 SCAND 为社交性导航数据，TokenWalker 为室外工业场景，室内工业场景的分布差异可能未被充分覆盖。
- **训练算力未明确**：论文未报告训练所需的总 GPU 数或小时数，仅给出 per-phase 步数和硬件列表，复现成本难以评估。
