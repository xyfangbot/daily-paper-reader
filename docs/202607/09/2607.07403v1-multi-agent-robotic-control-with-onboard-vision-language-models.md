## 摘要
视觉语言模型（VLM）和视觉语言动作（VLA）模型在机器人控制中展现出潜力，但在可解释性、泛化能力和计算需求方面仍面临重大挑战。本文提出了一种多智能体系统（MAS）架构，通过在机载硬件上部署专用智能体来克服这些限制——消除对外部计算的依赖。该系统在一个模拟工业仓库中控制一款多用途自主移动机械手，完成五类任务：安全检查、仓库维护、仓库搜索、包裹质量验证以及响应人类请求。全程使用紧凑型VLM（3-200亿参数），并采用微调以提高包裹检测准确性。一种新颖的“Megamind”编排智能体缓解了较小模型在长时域规划中固有的上下文保留问题。该系统在使用AMD Ryzen(TM) AI迷你PC的硬件在环仿真中进行了验证。结果表明，完全机载的MAS架构是云依赖部署的一种可行且高性价比的替代方案，具有很高的实际迁移潜力。仿真环境已根据Apache 2.0许可证作为开源发布。

## Abstract
Vision Language Models (VLMs) and Vision Language Action (VLA) models have shown promise in robotic control. Yet, they face significant challenges regarding explainability, generalization, and compute requirements. This paper presents a Multi-Agent System (MAS) architecture that addresses these limitations by deploying specialized agents on onboard hardware - eliminating dependence on external compute. The system controls a multi-purpose autonomous mobile manipulator in a simulated industrial warehouse, fulfilling five task categories: safety inspection, warehouse maintenance, warehouse search, package quality verification, and responding to human requests. Compact VLMs (3-20B parameters) are used throughout, with fine-tuning applied to improve package inspection accuracy. A novel "Megamind" orchestration agent mitigates context retention issues inherent to long-horizon planning with smaller models. The system was validated in a hardware-in-the-loop simulation using an AMD Ryzen(TM) AI mini PC. Results demonstrate that a fully onboard MAS architecture is a viable, cost-efficient alternative to cloud-dependent deployments, with strong potential for real-world transfer. The simulation environment has been released as open source under the Apache 2.0 licence.

- 现有解决方案（如隐层可解释性技术、链式思维干预、约束函数、将模型限制在“安全”机器人上）都存在泛化局限或实际部署困难。
- 本文旨在证明：基于多智能体系统（MAS）的架构，通过在机器人本地硬件（机载）上部署专用智能体，并利用紧凑型VLM（3-200亿参数），能够在不依赖外部计算的情况下有效控制多用途自主移动机械手，完成多样化的工业仓库任务。

## 二、论文提出的方法论
- **核心思想**：采用多智能体系统（MAS）架构，将复杂的长时域任务分解为多个专用智能体（Agent），每个智能体负责一个子任务，从而避免单一VLM因上下文窗口限制导致的关键信息丢失问题。
- **关键组件**：
    - **Megamind（编排智能体）**：采用两状态自反馈循环（规划-分析）智能体，负责根据当前机器人状态和任务队列选择下一个任务并委派给子智能体，然后在子智能体返回结果后分析任务是否完成，如需恢复则生成修正步骤并追加到任务队列。该显式控制环将任务进度、委派和恢复外部化，使紧凑型LLM能支撑多步机器人任务。
    - **Inspection Agent（检测智能体）**：两阶段工作流。第一阶段：VLM审核前向摄像头图像，生成自然语言描述并标记最多三个潜在问题；第二阶段：将标记的问题分类为可抓取的箱子（box）、可抓取的垃圾（trash）、不可操作的障碍物（other）或无相关问题（nothing）。对于可抓取物体，从仿真获取3D位姿，输出结构化JSON。
    - **Safety Agent（安全智能体）**：三阶段流水线：视觉（VLM描述场景并标记安全危害）→检索（基于FAISS向量数据库查询OSHA 29 CFR 1910法规，使用Qwen3-Embedding-0.6B和Qwen3-Reranker-0.6B重排序）→推理（VLM结合原图、场景描述和检索到的法规摘录，判断是否违规，输出违规标识符、摘录、严重等级和理由）。处理不同危害时独立保持上下文窗口较小，且通过结构相似性指数（SSIM）跳过视觉相似的连续帧以减少推理次数。
    - **MoveIt和Nav2智能体**：分别提供机械臂和移动平台的低层控制，通过RAI框架封装为工具，接收Megamind指令并报告状态。
- **VLM微调**：基础模型LFM2-VL-3B在包裹质量检测任务（T4）上表现不足，因此基于仿真生成的数据集进行微调。数据集包含三个标注：异常（True/False）、箱体状况（good/damaged）、安全危险（True/False）。使用Qwen3-256B-A22B作为教师模型，生成合成自然语言描述训练数据，微调一个epoch后箱体状况标注准确率从76.7%提升至91.5%，F1分数从0.755升至0.915（主要提升在真阴性从54%到95.5%，假阳性从46%到4.5%）。
- **用户交互**：通过HRI（人机接口）提供图形界面，支持自然语言指令。
