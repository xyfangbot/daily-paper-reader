## 摘要
主流视觉-语言-动作（VLA）模型在马尔可夫假设下主要根据当前观察预测动作，因此难以处理长期、时间依赖的任务。现有的记忆增强型VLA要么扩展观察窗口，要么从记忆库中检索历史信息作为辅助策略端上下文。然而，它们将记忆置于VLA推理的原始潜在嵌入空间之外，阻碍了历史经验与多模态推理及动作生成的自然交织。为此，我们提出了LaMem-VLA，一种潜在记忆原生框架，它将历史经验重构为潜在记忆标记，并直接将其与VLA推理交织。其核心是，LaMem-VLA引入了四个协调组件：（i）一个策展人，将历史经验组织成两个互补的短期和长期记忆库；（ii）一个搜索者，利用多模态认知查询两个记忆库以检索上下文相关的证据；（iii）一个凝聚器，将检索到的证据重构为紧凑的短期和长期潜在记忆标记；（iv）一个织入器，将这些记忆标记与当前观察和指令注入到一个连续的嵌入序列中。通过完全在同一连续潜在空间中表示、检索和消费历史经验，LaMem-VLA使记忆能够直接参与VLA推理，并在有界上下文中指导动作生成。在SimplerEnv和LIBERO上的大量实验证明了我们的LaMem-VLA的优越性。

## Abstract
Mainstream Vision-Language-Action (VLA) models predict actions primarily from the current observation under a Markovian assumption, thus struggling with long-horizon, temporally dependent tasks. Existing memory-augmented VLAs either expand the observation window or retrieve history from the memory bank as auxiliary policy-side context. However, they leave memory outside the native latent embedding space of VLA reasoning, preventing historical experience from being fluidly interleaved with multimodal reasoning and action formation. To this end, we introduce LaMem-VLA, a latent-memory-native framework that reconstructs historical experience into latent memory tokens and directly interweaves them with VLA reasoning. At its core, LaMem-VLA introduces four coordinated components: (i) a curator that organizes historical experience into two complementary short-term and long-term memory vaults; (ii) a seeker that queries both vaults using the multimodal cognition to retrieve context-relevant evidence; (iii) a condenser that reconstructs the retrieved evidence into compact short-term and long-term latent memory tokens; and (iv) a weaver that injects these memory tokens with the current observation and instruction into one continuous embedding sequence. By representing, retrieving, and consuming historical experience entirely in the same continuous latent space, LaMem-VLA enables memory to directly participate in VLA reasoning and guide action generation under a bounded context. Extensive experiments on SimplerEnv and LIBERO demonstrate the superiority of our LaMem-VLA.

- **本文动机**：将历史经验表示为与VLA推理空间兼容的**潜在记忆令牌**，使记忆能够直接在模型嵌入空间中被存储、检索和消费，从而消除马尔可夫假设的限制，提升长时操作任务的性能。

## 二、论文提出的方法论
- **核心思想**：提出**LaMem-VLA**框架，通过四个协调模块将历史经验组织成**短期视觉记忆**和**长期语义记忆**，并将其压缩为固定长度的潜在记忆令牌，直接注入VLA推理序列，与当前观测、指令和动作查询令牌在同一连续潜在空间中交互。
- **四个关键组件**：
  - **潜在记忆策展人（Curator）**：维护两个互补的记忆库。短期记忆库（Short-term Memory Vault）存储当前episode的视觉感知证据；长期记忆库（Long-term Memory Vault）存储动作隐藏状态，保留任务进度和动作连续性证据。当容量超限时，通过相邻相似度合并冗余单元。
  - **潜在记忆搜索者（Seeker）**：基于当前多模态认知表示（视觉令牌+指令令牌）构建上下文感知查询，利用余弦相似度从两个记忆库中分别检索Top‑K个相关单元。
  - **潜在记忆凝聚器（Condenser）**：将检索到的原始证据（可能冗余）与可学习记忆槽结合，通过轻量Transformer（记忆形成器）压缩为固定长度的潜在短期记忆令牌（\(L_s\)）和长期记忆令牌（\(L_l\)）。
  - **潜在记忆织入器（Weaver）**：将凝聚后的记忆令牌（带位置/类型嵌入）与当前视觉令牌、指令令牌、动作查询令牌拼接成连续的输入序列 \(S_t = [\tilde{M}_{\text{short}}; \tilde{M}_{\text{long}}; X_t; I; Q_{\text{action}}]\)，使记忆参与自注意力计算，产生记忆增强的动作令牌。
- **动作生成**：记忆增强后的动作令牌输入扩散动作专家（基于DiT），通过条件去噪生成连续动作片段（7‑DoF末端执行器控制向量）。
- **算法流程**（文字描述）：
  1. 当前观测 \(o_t\) 和指令 \(I\) 经VLM编码得到视觉令牌 \(X_t\) 和指令令牌 \(I\)，并预置可学习动作查询 \(Q_{\text{action}}\)。
  2. Curator更新两个记忆库：短期库写入压缩后的视觉令牌，长期库写入当前动作隐藏状态。
  3. Seeker基于多模态令牌构建查询，从两个库中各检索Top‑K证据。
  4. Condenser将检索证据与可学习槽融合，生成固定长度的短期/长期潜在记忆令牌。
  5. Weaver将两种记忆令牌与 \(X_t, I, Q_{\text{action}}\) 拼接，送入VLM进行自注意力计算，得到记忆增强的动作令牌。
  6. 动作令牌通过扩散动作专家去噪，输出动作片段。

## 三、实验设计

## 六、论文的主要结论与发现
- **性能提升**：LaMem-VLA在SimplerEnv上平均成功率73.9%（比CogACT高16.6点，比π0高4.7点）；在LIBERO上平均97.6%（比MemoryVLA高1.1点，比CogACT高4.4点），尤其长期任务提升显著（Long‑10比MemoryVLA高2.4点，Long‑90高1.4点）。
- **记忆协同性**：短期视觉记忆与长期语义记忆互补，联合使用效果最佳；移除任何一方都会导致性能下降。
- **潜在集成优于策略端条件**：将记忆令牌直接注入VLM输入序列（潜在空间）比作为策略端外部条件更有效。
- **检索数量与令牌数量影响**：K=8时最佳；短期记忆令牌 \(L_s=8\)、长期记忆令牌 \(L_l=4\) 在性能与效率间取得较好平衡。
