## 摘要
近期，视觉-语言-动作（VLA）模型在多种任务中展现出强大的泛化能力。然而，物理环境中的有效机器人操作从根本上需要几何理解和空间推理。尽管一些VLA方法尝试融入3D信息，但它们受限于当前3D编码管线中的数据可用性和几何信息损失，且未能联合捕捉动态环境中的3D几何与时序结构化动作。为应对这些局限，我们引入Lift3D-VLA，这是一个统一的VLA框架，为模型配备显式3D点云推理能力，并实现时间连贯的动作生成。首先，基于我们先前的工作Lift3D，提出一种增强的2D模型提升策略，以几何方式对齐3D点与预训练的2D位置嵌入。该设计使得在VLA视觉编码器内可直接进行点云编码，同时最小化空间信息损失。基于显式3D输入，我们提出几何中心掩码自编码（GC-MAE），这是一个双目标自监督框架，在重建当前点云的同时预测其未来几何演化。这一公式使2D视觉编码器能够内化3D结构与物理动力学。为充分利用3D表示，我们进一步设计分层时序动作建模，利用LLM的多个层级协同预测动作块，从而实现时间一致性的预测。在22个模拟任务和8个真实世界操作任务中，Lift3D-VLA在MetaWorld和RLBench上的平均成功率分别比此前最优VLA方法高出10.8%和11.1%，并超越最强真实世界基线4个百分点，同时展现出对分布外扰动的更强泛化能力。

## Abstract
Recently, Vision-Language-Action (VLA) models have demonstrated strong generalization across diverse tasks. However, effective robotic manipulation in physical environments fundamentally requires geometric understanding and spatial reasoning. While some VLA approaches attempt to incorporate 3D information, they are constrained by limited data availability and geometric information loss in current 3D encoding pipelines, and fail to jointly capture 3D geometry and temporally structured actions in dynamic environments. To address these limitations, we introduce Lift3D-VLA, a unified VLA framework that equips models with explicit 3D point cloud reasoning and enables temporally coherent action generation. First, building upon our previous work Lift3D, an enhanced 2D model-lifting strategy is proposed to geometrically align 3D points with pretrained 2D positional embeddings. This design enables direct point-cloud encoding within the VLA vision encoder while minimizing spatial information loss. Based on explicit 3D inputs, we propose Geometry-Centric Masked Autoencoding (GC-MAE), a dual-objective self-supervised framework that reconstructs the current point cloud while predicting its future geometric evolution. This formulation allows the 2D vision encoder to internalize both 3D structure and physical dynamics. To fully exploit 3D representations, we further design layer-wise temporal action modeling, which leverages multiple layers of the LLM to collaboratively predict action chunks, enabling temporally consistent predictions. Across 22 simulated tasks and 8 real-world manipulation tasks, Lift3D-VLA achieves 10.8% and 11.1% higher mean success rates on MetaWorld and RLBench than the best-performing prior VLA methods, and outperforms the strongest real-world baseline by 4 percentage points, while exhibiting stronger generalization to out-of-distribution perturbations.

## 一、论文的核心问题与整体含义（研究动机和背景）
- 现有 VLA 模型虽然通过视觉感知、语言指令和动作生成在机器人操作中展现出强大的泛化能力，但物理世界中的操作从根本上需要 3D 几何理解与空间推理（如可到达性、遮挡、接触关系），而纯 2D VLA 管线在杂乱或动态环境中难以可靠捕捉这些几何约束。
- 已有引入 3D 信息的方法主要分为两类：直接编码点云/体素/多视图（但缺乏大规模 3D 预训练数据和成熟的 3D 基础编码器，难以学到可迁移的 3D 表示）；或通过跨模态变换（如将 2D 特征提升到 3D、将 3D 点云投影到多视图），但这些变换本质上有损，会削弱 2D 预训练表示与 3D 结构之间的对应关系，限制可扩展性。
- 作者之前的工作 Lift3D 提出了一种“重用 2D 预训练”的范式，通过渐进增强 2D 骨干网络来获得 3D 感知能力，但仍存在两个关键局限：一是其隐式增强仅基于 RGB 和深度信号进行掩码重建，未显式强制学习连贯的 3D 结构；二是未联合建模动态环境中的几何演化与时间结构化动作，导致在长时域任务中表现脆弱。
- 本文旨在解决上述问题，提出 Lift3D-VLA，一种统一框架，使 VLA 模型具备显式 3D 点云推理能力和时间连贯的动作生成能力。

## 二、论文提出的方法论
- **总体框架**：基于 Prismatic VLM 骨干（7B LLaMA2），采用双编码器设计（SigLIP + DINOv2）处理 2D 图像，并引入专门的 3D 点云分词器（含最远点采样、k-近邻聚合和可学习线性投影），生成 256 个点云 token；所有模态的 token 拼接后送入 LLM 进行多模态推理与动作预测。
- **2D 模型提升策略**（基于 Lift3D）：将点云 token 的空间坐标投影到多个虚拟平面（六面体投影），利用相机参数对齐前视图与观察视角，然后通过平均多个视角的预训练 2D 位置嵌入来获得 3D 位置嵌入，使 2D 视觉编码器能够直接处理点云，并最小化空间信息损失。
- **几何中心掩码自编码（GC-MAE）** ：
  - 利用 VGGT 从大规模机器人数据（140K 轨迹）的 RGB 观测中合成伪 3D 点云，作为自监督训练目标。
  - 设计双分支解码框架：静态分支负责从掩码后的可见点云 token 重建当前帧中被掩码点的 3D 坐标（使用倒角距离损失 \(L_{\text{static}}\)）；动态分支负责用当前可见 token 预测下一帧对应点的几何坐标（\(L_{\text{dynamic}}\)）。
  - 总损失 \(L_{\text{MAE}} = L_{\text{static}} + \lambda L_{\text{dynamic}}\)，通过 LoRA 微调视觉编码器的注意力层，保持参数高效并避免灾难性遗忘。
- **分层时间动作建模**：
  - 不依赖单一解码头或仅用最后一层 LLM 预测动作块，而是为动作块中的每个时间步分配一个对应的 LLM 中间层（如对于 H=4 的动作块，均匀选择第 20、24、28、32 层）。
  - 每个指定层上附加一个动作预测头（\(\hat{\epsilon}_k = \phi_k(h_{l_k})\)），采用扩散模型（DDPM）进行去噪，各层同时监督，利用深层对浅层特征的关注建模时间依赖性。
  - 训练分两阶段：第一阶段用 GC-MAE 进行自监督学习（15 个 epoch）；第二阶段用下游任务监督信号微调 LLM 和动作投影 MLP（300 epoch 全微调或 100 epoch LoRA）。

## 七、优点

## 八、不足与局限

- **推理效率未报告**：未评估模型推理速度或部署到实际机器人上的实时性，这对实际应用至关重要。
