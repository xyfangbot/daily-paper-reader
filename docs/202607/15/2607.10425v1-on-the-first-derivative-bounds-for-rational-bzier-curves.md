## 摘要
本文研究了有理Bézier曲线一阶导数的尖锐上界。一个长期存在的猜想认为，对所有次数，线性界$\|\mathbf{R}'(t)\| \le nΩ\max\|Δ_i\|$成立。我们证明该界对$n \leq 6$确实成立，从而解决了最后一个未解决的低次情况。该问题被重新表述为在紧致盒子上最大化一个方差型函数。通过使用块论证，我们证明最优值只能出现在一维面上，从而将任务简化为有限个多项式不等式，并通过实量词消去精确验证。一个显著的实用特性是该界可以在线性时间内相对于次数进行计算，使其对实时几何处理具有吸引力。同样的结构分析说明了$n=7$时的不成立，并概述了如何计算真正的坏情况常数。

## Abstract
In this paper we investigate sharp upper bounds for the first derivative of rational Bézier curves. A long-standing conjecture posited that the linear bound $\|\mathbf{R}'(t)\| \le nΩ\max\|Δ_i\|$ holds for all degrees. We prove that the bound is indeed valid for $n \leq 6$, thus resolving the last open low-degree case. The problem is reformulated as maximizing a variance-like function over a compact box. Using a block argument we show that optima can only appear on one-dimensional faces, reducing the task to a finite family of polynomial inequalities, which are verified exactly via real quantifier elimination. A notable practical feature is that the bound can be evaluated in linear time with respect to the degree, making it attractive for real-time geometric processing. The same structural analysis illustrates the failure for $n=7$ and outlines how the true worst-case constant can be computed.
