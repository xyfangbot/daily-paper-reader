## 摘要
零样本目标导航旨在使智能代理能够在没有特定目标训练的情况下，在陌生环境中探索并导航到未知类别的物体。在零样本导航任务中，通常利用预训练的大模型来引导代理的导航。然而，现有的基于大语言模型的零样本目标导航方法仅仅将LLM用作平面推理工具，直接关联对象或区域，缺乏类人房间语义到对象定位的分层空间认知建模，导致探索盲目性强、语义关联准确性不足，未能充分发挥LLM的常识推理潜力。本文提出了一种由LLM驱动的分层房间到对象（HRO）框架，用于零样本目标导航，该框架引导代理以从粗到细的方式探索并导航到目标物体。在Gibson和HM3D数据集上的实验验证了我们的HRO框架相比现有基于LLM的方法在成功率和泛化性方面更优，凸显了LLM在零样本目标导航中的强大潜力。

## Abstract
Zero-shot object-goal navigation aims to enable an intelligent agent to explore and navigate to objects of unknown categories in an unfamiliar environment without specific target training. In zero-shot navigation tasks, pre-trained large models are usually employed to leverage their prior knowledge for guiding the agent's navigation. However, existing zero-shot object-goal navigation methods based on large language models (LLMs) merely utilize LLMs as flat reasoning tools to directly associate objects or regions. They lack the hierarchical spatial cognition modeling of human-like room semantics to object localization, which leads to strong blindness in exploration, insufficient accuracy in semantic association, and failure to fully unleash the common-sense reasoning potential of LLMs. This paper proposes an LLM-driven hierarchical room-to-object (HRO) framework for zero-shot object-goal navigation, which guides the agent to explore and navigate to the target object in a coarse-to-fine manner. Experiments on Gibson and HM3D datasets verify that our HRO framework achieves superior success rate and generalization over existing LLM-based methods, underscoring LLMs' strong potential for zero-shot object-goal navigation.

## 一、论文的核心问题与整体含义（研究动机和背景）
- **研究问题**：零样本目标导航（Zero-Shot Object Goal Navigation）要求智能体在未见过目标类别的情况下，在陌生室内环境中导航到该类物体。现有基于大型语言模型（LLM）的方法（如 ESC、L3MVN）只是将 LLM 用作“平面推理”工具，直接关联物体与区域，缺乏类似人类“由房间类型推断物体位置”的层次化空间认知。
- **核心动机**：人类在寻找物体时，会先根据观察到的物体判断房间类型（如看到床和衣柜推断是卧室），再根据房间功能定位目标（如电视通常在客厅或卧室）。现有 LLM 方法忽略了这一层次结构，导致探索盲目、语义关联不准确，且未能充分发挥 LLM 的常识推理潜力。
- **研究意义**：提出一种模仿人类“先判断场景，再寻找物体”的层次化 HRO（Hierarchical Room-to-Object）框架，将房间类型作为语义桥梁，实现粗到细的导航，旨在提高零样本导航的成功率和泛化性。

## 二、论文提出的方法论
- **核心思想**：将零样本目标导航分解为三个层次（高层、中层、底层），形成“房间推理 → 区域决策 → 动作执行”的闭环，以房间类型为中间语义表示，引导智能体从粗粒度语义理解逐步细化为目标定位。
- **关键技术细节**：
  1. **地图表示**：构建语义地图（尺寸 M×M，通道数 K = C+2），前两个通道记录障碍物与探索区域，其余 C 通道对应各类物体。使用 Mask R-CNN 对 RGB-D 观测进行语义分割，投影生成 2D 语义地图。
  2. **高层-房间类型推理（LLM-Driven Room Type Inference）**：
     - 提取前沿点（frontier）候选集（数量 n=4），基于混合准则评分（距离 + 面积）。
     - 预定义 7 种常见室内房间类型：客厅、卧室、浴室、厨房、餐厅、办公室、走廊。
     - 对每个候选前沿，收集其局部窗口内的已知物体集合 O，构造提示模板 `Prompt(O, r) = "A room containing " + concat(O) + " is likely a " + r + "."`，用 GPT-2 计算每个候选房间类型 r 的语言模型损失（作为兼容性分数），并通过 softmax 获得房间类型概率分布 P(r|O)。
  3. **中层-目标导向语义亲和力评分（Goal-Oriented Semantic Affinity Scoring）**：
     - 建立常识知识库 M: G → 2^R，映射目标物体 g 到可能出现的房间类型集合（如 bed→{bedroom}，tv→{living room, bedroom}）。
     - 对候选前沿 f_i，计算语义亲和力分数 S_Affinity = max_{r∈M(g)} P(r|O)，即目标物体 g 与观测物体 O 推断出的房间分布的最大匹配程度。
  4. **底层-路径规划与执行（Path Planning and Execution）**：
     - 最终前沿优先级 S_fi = α * (归一化 S_Affinity) + (1-α) * S_MC_geometric。
     - 选择最高分前沿后，用快速行进法（Fast Marching Method）规划最短路径，并生成动作序列（前进、转向等），反复执行直至成功或达到最大步数 500。

## 七、优点
- **方法创新**：首次将人类层次化空间认知（房间→物体）显式建模到零样本导航框架，提出粗到细的三层架构，填补了现有 LLM 方法“扁平推理”的空白。
- **零样本且无训练**：完全依赖 LLM 的常识推理和在线语义地图，无需任何任务特定训练、标注数据或微调，泛化性强。
- **可解释性**：通过显式的房间类型推理和亲和力评分，可直观理解智能体决策依据（例如“因为有花瓶，所以可能是客厅，再去寻找电视”）。
