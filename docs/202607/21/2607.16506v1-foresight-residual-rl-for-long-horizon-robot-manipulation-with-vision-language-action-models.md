## 摘要
视觉-语言-动作（VLA）策略提供了强大的通用操作先验，但在涉及高精度、接触密集的装配任务中常因长期信用分配和子任务耦合而失败：当前技能在几何上成功的状态可能对后续技能是脆弱的。我们展示了在冻结VLA基策略上的残差强化学习（RL）中的这种失败模式：恒定的稀疏成功奖励虽能孤立地改进每个子任务，但当技能链式执行时却几乎无增益，因为终端状态质量不受控。我们提出预见性残差RL，通过向每个子任务的稀疏成功奖励中添加一个离线估计的预见值（即当前子任务终端状态下后续子任务成功概率的条件估计）来优化交接质量。具体地，我们（i）从基策略终端状态的图像中训练视觉预见预测器，使用下游滚动统计数据进行标注；以及（ii）通过反向预见归纳，利用预测器输出作为奖励乘数来训练残差策略。在Isaac Gym中基于扳手的螺母拧紧三阶段装配任务（抓取、移动-插入、旋转）上，我们的方法实现了85.6%的全任务成功率，优于标准子任务残差RL（54.5%）和VLA基线，同时保持每个子任务的成功率不变。这些结果强调，提升长期性能需要塑造每个子任务产生的成功状态，而不仅仅是关注是否成功。

## Abstract
Vision-Language-Action (VLA) policies offer strong general-purpose manipulation priors, but often fail on tight-tolerance, contact-rich assembly due to long-horizon credit assignment and subtask coupling: a state that is geometrically successful for the current skill can be brittle for downstream skills. We show this failure mode in residual reinforcement learning (RL) over a frozen VLA base policy: constant sparse success rewards improve each subtask in isolation yet yield little or no gain when skills are chained, because terminal state quality is uncontrolled. We propose Foresight Residual RL, which optimizes handoff quality by augmenting each subtask's sparse success reward with an offline-estimated foresight value -- the probability of future subtask success conditioned on the terminal state of the current subtask. Concretely, we (i) train a visual foresight predictor from images of terminal states of the base policy, labeled using downstream rollout statistics, and (ii) train residual policies via backward foresight induction, using the predictor output as a reward multiplier. On a three-phase wrench-based nut-tightening assembly task in Isaac Gym (grasp, move-insert, rotate), our method achieves 85.6% full-task success, outperforming standard subtask residual RL (54.5%) and VLA baselines, while leaving per-subtask success unchanged. These results highlight that improving long-horizon performance requires shaping which successful states are produced at each sub-task, not only whether success occurs.

## 一、论文的核心问题与整体含义（研究动机和背景）
- **研究动机**：视觉-语言-动作（VLA）策略在通用操作中表现优异，但在高精度、接触密集的长期装配任务（如用扳手拧紧螺母）中常失败。原因在于子任务之间存在因果耦合：当前子任务的终端状态（即使被判定为几何成功）可能对后续子任务脆弱，导致链式执行时性能急剧下降。
- **核心问题**：标准残差强化学习（Residual RL）仅用恒定的稀疏成功奖励优化每个子任务的孤立成功率，忽略了终端状态质量对下游任务的影响。这种“优化各子任务成功率”的做法在链式任务中几乎无效，因为终端状态质量未受控制。
- **整体含义**：提升长期操作性能的关键不仅在于子任务是否成功，更在于产生什么样的成功状态（即终端状态的质量）。论文提出通过预见性残差强化学习（Foresight Residual RL）来显式优化终端状态的“未来导向”价值。

## 二、论文提出的方法论
- **核心思想**：在保留VLA基策略（π0）冻结的前提下，为每个子任务训练一个残差策略。残差策略的奖励信号不再是简单的子任务成功谓词（β_k），而是乘上一个离线估计的**预见值**——即当前终端状态下，后续子任务成功的概率。从而引导残差策略产生更有利于下游执行的终端状态。
- **关键技术细节**：
  1. **定义预见值函数**：对于子任务k（k < K），其终端状态s的预见值V_{k+1:K}(s)定义为从s开始执行后续所有子任务策略所获得的最终阶段成功期望。本文采用一阶近似：仅考虑下一个子任务k+1的成功概率。
  2. **离线训练视觉预见预测器**：步骤：
     - 用基策略π_k^0滚动收集N个成功的终端状态（图像+状态）。
     - 对每个终端状态，用下游策略π_{k+1}执行K_rep次独立滚动，记录成功次数κ_i，得到标签y_i = κ_i / K_rep。
     - 训练一个神经网络p_ϕ（基于DINOv2/S14特征，LoRA微调，二项式负对数似然损失）将终端观测映射到[0,1]概率。训练后，在RL训练时可直接提供瞬时的预见估计，免去在线蒙特卡洛开销。
  3. **反向预见归纳训练（Backward Foresight Induction）**：从最后一个子任务（k=K）开始，向前训练。对k=K，奖励为β_K（无预见）；对k<K，奖励为 r_t = β_k(s_{t+1}) · p_ϕ(o_{t+1})。残差策略输出小幅度修正：a_t = π_k^0(o_t) + α·π_k^res(o_t)，α=0.1，使用PPO训练。
- **算法流程**（文字说明）：离线收集数据→训练预见预测器→按反向顺序（从K到1）依次训练各子任务的残差策略，训练时用预测器输出作为奖励乘数。

## 三、实验设计

- **基准方法**：

  - π0（链式）：解耦成三个子任务，各用π0基策略链式执行（无残差）。
  - π0 + 残差（标准）：每个子任务用残差RL训练，奖励为β_k（恒定成功奖励）。
