## 摘要
视觉-语言-动作策略是通用机器人控制的有前途的基础，但长时间跨度的类人机器人移动操作要求机器人将任务对象视为跨运动、接触、遮挡和恢复的持久物理实体。我们将此问题研究为对象状态发散：用于调节全身动作的对象状态可能与用于判断动作是否达到预期物理关系的状态不同。我们提出持久对象令牌化（POT），该方法从RGB-D观测中维护角色索引的3D对象记录，并将其转换为全身动作专家的对象令牌。实例化为POT-VLA，相同的对象记录调节动作生成并支持几何谓词检查，从而产生一个对象状态既可操作又可验证的闭环执行系统。在Unitree G1上，POT-VLA在八个真实世界任务族中将匹配的直接GR00T-N1.7基线从39/80成功提高到71/80成功。在与外部Being-0对齐的参考中，POT-VLA在对齐的服务任务上达到44/50成功，而Being-0论文报告的成功率为37/50。最大的增益出现在需要维持3D关系的任务上，这表明持久的以对象为中心的状态是可验证的人形VLA执行的有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 一、论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：人形机器人在长时间跨度（long-horizon）的全身移动操作（loco-manipulation）中，面临**对象状态发散（object-state divergence）**问题：用于调节动作生成的对象状态，与用于判断动作是否达成预期物理关系的对象状态可能不一致。这导致微小误差（如抓握偏差、放置偏移）被累积，引发过早的子任务切换、错误对象操作或无效恢复。
- **研究背景**：现有视觉-语言-动作（VLA）策略通常将对象信息隐式编码在视觉-语言特征中，缺乏显式、持久、可验证的3D物理状态表示。而人形机器人跨步态、遮挡、接触和恢复的操作，要求将任务对象视为持久的物理实体。
- **整体含义**：提出**持久对象令牌化（POT）**方法，通过维护与更新角色索引的3D对象记录，实现闭环执行的“行动-验证”循环，使对象状态既可指导动作生成，又可验证动作的物理后果，从而显著提升人形机器人长时间操作的成功率。

## 二、论文提出的方法论
- **核心思想**：构建一个**共享的对象状态记忆**（role-indexed object memory），该记忆由同一组3D对象记录组成，同时供给**动作专家**（用于生成下一段动作）和**谓词验证器**（用于检查动作是否达成目标物理关系），形成“维持-行动-观测-验证-恢复”的闭环。
- **关键技术细节**：
  1. **持久对象令牌化（POT）**：从RGB-D观测中，通过SAM3等分割模型获取对象掩码，经深度反投影和坐标变换，在机器人基坐标系下构建每个任务对象的记录，包括：角色ID（如TARGET、DESTINATION、SUPPORT、HANDOVER_PARTNER）、可见性、置信度、2D边界框、3D质心、3D范围、可选的朝向、以及相对关系特征（如末端执行器-对象偏移、目标-目的地位移、包含/支撑关系等）。
  2. **对象令牌序列化**：将对象记录映射为固定槽位（K=8）的特征张量（每槽33维），称为**持久3D对象令牌**。未使用槽位填充并掩码。令牌中包含角色嵌入、置信度门控等，供动作专家使用。
  3. **动作专家嵌入**：基于GR00T-N1.7全身体动作专家，将对象令牌插入其DiT自注意力序列中（状态令牌、对象令牌、动作令牌），使动作生成可感知显式3D对象状态。训练时使用与部署一致的演示侧车（object-token sidecar）进行微调。
  4. **谓词验证与恢复**：验证器使用与动作专家相同的刷新后对象记忆，执行几何谓词检查（如包含、支撑、接近、距离等），判断子任务是否完成。支持状态：进行中、完成、阻塞、失败、不确定。基于诊断结果触发重观测、重新定位、重试或任务级重规划。

## 六、论文的主要结论与发现
- **核心结论**：持久对象中心状态（POT）是人形VLA可验证执行的有效抽象。POT-VLA在真实人形机器人上显著优于直接基线：总成功率从39/80（48.75%）提升至71/80（88.75%）。在外部对齐任务上达到44/50（88%），高于Being-0报告的37/50（74%）。
- **发现**：
  - 最大增益出现在需要维持3D关系的任务（如堆叠、双球放置、衣物运输、抽屉操作），验证了“对象状态发散”是主要失败模式。
  - 对象令牌条件提供了最大增益（15/40→31/40），谓词验证提供额外增益（31/40→34/40），说明显式3D状态主要缓解动作前的接地错误，验证主要捕获残留的错误完成。
  - 泛化测试中，新颖实例和布局偏移下POT-VLA仍保持高成功率（9/10），而基线下降明显。
- **定性观察**：角色感知3D令牌减少了目标搜索振荡，改善了接触相关定位（如手柄、杯子、小球、小物体、衣物、容器区域），持久记录减少了逐块身份抖动，几何监督实现了本地恢复而非全局语言重规划。

## 七、优点
- **方法论创新**：提出**持久对象令牌**这一新概念，将3D物体状态显式编码为可插入VLA动作头的令牌，且实现闭环“行动-验证”共享状态，解决了对象状态发散这一关键瓶颈。
- **工程实用性**：不依赖仿真器、物理引擎或学习动力学模型，直接基于RGB-D观测和机器人基坐标构建状态，适用于真实环境。
- **实验验证强度**：在真实人形机器人上完成多任务、多场景、多干扰条件的充分验证，消融和泛化测试设计严谨，结果具有说服力。
- **可扩展性**：方法通用，不绑定特定VLA策略或本体，可适配其他动作专家和机器人平台。对象令牌和谓词验证的设计支持结构化恢复（重观测、重接地、重试、重规划）。

## 八、不足与局限
- **局限**：
  - 依赖于对象记录质量，受限于SAM3分割、RGB-D传感器可靠性、相机外参校准精度。在严重遮挡、光照变化或传感器噪声下可能退化。
  - 当前仅限于头戴单目RGB-D（固定视角），未扩展到主动多视图记忆，可能遗漏出现在视野外的对象状态变化。
  - 动作专家仍为GR00T-N1.7，其本体覆盖范围（Unitree G1 + Dex3-1手）有限，未在更复杂灵巧手或双足平衡挑战下测试。
  - 几何谓词主要针对刚性、规则交互（包含、支撑、接近），对于柔性物体（如衣物）的复杂变形、以及人际交互中的社会性信号（如“接受”手势）未充分处理。
- **实验覆盖风险**：
  - 外部参考Being-0并非本地复现，任务对齐可能存在差异，直接数值对比说服力有限。

- **偏差风险**：实验环境为固定办公室布局，未在多种办公布局下系统测试；任务语言指令固定，未评估语言歧义性影响；所有试验由论文作者操作执行，未进行跨操作员一致性验证。
