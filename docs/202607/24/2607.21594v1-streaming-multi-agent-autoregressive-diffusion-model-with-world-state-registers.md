## 摘要
多智能体交互式世界模型不仅应生成一致的观测结果，还应维护跨智能体持久存在且随视角演化的世界状态。现有自回归视频扩散管道将观测历史作为条件上下文传递，这使得在多智能体和多视角设置中难以维护共享状态。我们提出WorldWeaver (W^2)，一种流式多智能体视频扩散模型，它通过跨智能体世界状态寄存器（可学习令牌）增强扩展过程：这些寄存器存储共享世界信息、追踪个体智能体状态，并在每个生成块后动态更新。我们利用涵盖个体智能体状态、全局状态视图（包括鸟瞰图）和场景文本的监督信号来锚定这些寄存器。我们进一步通过混合Transformer架构改进模型，该架构对世界状态建模和视觉帧建模使用独立的权重。在两个智能体的Minecraft视频生成的广泛实验中，显式的世界状态建模提高了逻辑一致性和生成质量。

## Abstract
Multi-agent interactive world models should not only generate consistent observations, but also maintain world states that persist across agents and evolve across views. Existing autoregressive video diffusion pipelines carry forward observation history as conditioning context, which makes shared state difficult to maintain in multi-agent and multi-view settings. We present WorldWeaver (W^2), a streaming multi-agent video diffusion model that augments rollout with cross-agent world state registers: learnable tokens that store shared world information, track individual agent status, and are dynamically updated after each generated chunk. We ground these registers with supervision signals spanning individual agent status, global state views including bird's-eye views, and scene text. We further improve the architecture with a Mixture-of-Transformers design that uses separate weights for world state modeling and visual frame modeling. Extensive experiments in two-agent Minecraft video generation show that explicit world-state modeling improves logical consistency and generation quality.

## 二、论文提出的方法论
- 核心思想：在流式自回归视频扩散模型中增加一组可学习的**世界状态寄存器（World State Registers, WSR）**，作为跨智能体共享的持久状态，并在每个生成块后动态更新。这些寄存器存储全局场景信息、个体智能体状态及语义描述。
- 关键技术细节：
  - **世界状态寄存器**：一组K个可学习令牌，与帧令牌交错排列（[x0, r0, x1, r1, ...]），形成因果序列：每个寄存器ri在生成下一帧xi+1前被提交，并作为条件。
  - **监督信号**：包括三种互补类型：1）个体智能体状态（位置、速度、方向）；2）鸟瞰视图（全局几何布局，用DINOv2特征监督）；3）场景文本（语义描述，通过冻结的Llama模型基于交叉熵损失）。
  - **模型架构**：采用**混合Transformer（Mixture-of-Transformers, MoT）** 设计，将世界状态寄存器令牌和视觉帧令牌分别用不同的权重参数处理，但共享注意力机制，避免状态建模与视觉生成之间的参数冲突。
  - **三阶段训练课程**：Stage 1（双向训练）——在同步多智能体数据上微调双向教师模型，学习跨智能体场景结构。Stage 2（因果训练）——将双向模型转换为因果学生模型，使用流匹配损失和寄存器监督损失，并施加因果注意力掩码。Stage 3（自强制训练）——学生模型在自身生成的帧和提交的寄存器上进行自回归展开，使用DMD分布匹配损失（Lsf）与寄存器损失（Lreg）联合优化，解决训练-测试不匹配问题。
- 公式与算法：

  - 寄存器监督损失：Lreg = Σ_{i,m} λ_m d_m(h_m(r_i), y^m_i)

## 三、实验设计

- 基准（Benchmark）：使用Solaris原测试集，评估指标包括VLM准确性（度量视频中世界关系是否正确，如相对位置、跨智能体一致性）和FID（视觉真实性）。还引入辅助排名指标WorldScore = (平均VLM)/(平均FID×100)。
- 对比方法：
  - Frame concat：将两个智能体观测沿通道拼接（类似Multiverse方法）。
  - Solaris：多智能体世界模型基线，使用双向注意力同步多智能体观测。作者重新训练Solaris模型以保证公平比较。

## 六、论文的主要结论与发现
1. 显式的世界状态寄存器能在不增加推理代价的情况下显著提升多智能体视频生成的逻辑一致性和视觉质量。
2. 无监督的寄存器已带来提升（WorldScore从81.0到93.8），但添加明确监督信号（尤其场景文本）进一步改善（增至103.2），三者组合最佳（105.1）。
3. 混合Transformer（MoT）在寄存器承载丰富语义时优于密集Transformer，分离状态与视觉权重能避免参数冲突。
4. 半监督实验表明，在少量有标签数据基础上加入无标签视频数据可进一步提高生成质量（WorldScore从63.2升至90.3），表明WSR可扩展到标签受限场景。
5. 自强制阶段对寄存器变压器进行分步冻结可以稳定训练，提升VLM准确率。
