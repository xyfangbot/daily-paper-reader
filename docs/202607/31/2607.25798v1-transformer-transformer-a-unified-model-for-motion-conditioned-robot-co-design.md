## 摘要
机器人操作性能的一个常被忽视的因素是机器人自身的本体。受此问题启发，我们研究了运动条件下的机器人协同设计，其目标是生成完整的机器人设计，使其能够跟踪目标末端执行器轨迹（来自人类演示），同时优化用户定义的奖励。我们提出了Transformer Transformer，一种在RoboTokens上训练的扩散Transformer，RoboTokens是机器人本体、状态和动作的统一标记化。相同的架构可跨本体空间（例如轮式双臂、四足、人形）和用例（本体生成、跨本体控制器）使用。Transformer Transformer不是过拟合于单一奖励函数，而是一个动力学模型，其与奖励无关的状态和动作预测可转换为特定奖励的价值预测。这些价值预测用于引导本体扩散朝向高价值机器人设计，我们称之为“动力学自引导”过程。跨多个设计空间的实验显示了对未见奖励和轨迹的零样本优化，相比进化基线提升了性能和运行时间。最后，我们制作了一个优化的ALOHA设计，与原始设计相比，跟踪误差降低了70%以上。

## Abstract
An often overlooked factor of robot manipulation performance is the embodiment of the robot itself. Motivated by this problem, we study motion-conditioned robot co-design, where the goal is to generate complete robot designs that track target end-effector trajectories (from human demonstrations) while optimizing user-defined rewards. We introduce Transformer Transformer, a diffusion transformer trained on RoboTokens, a unified tokenization of robot embodiments, states, and actions. The same architecture can be used across embodiment spaces (e.g., wheeled bimanual, quadrupeds, humanoids) and use cases (embodiment generation, cross embodiment controller). Rather than overfitting to one reward function, Transformer Transformer is a dynamics model, whose reward-agnostic state and action predictions can be converted into reward-specific value predictions. These value predictions are used to steer embodiment diffusion towards high value robot designs, through a procedure we call Dynamics Self-Guidance. Experiments across multiple design spaces show zero-shot optimization of unseen rewards and trajectories, improving performance and runtime over the evolutionary baseline. Finally, we fabricated an optimized ALOHA design, which reduced tracking error by over 70% compared to the original design.

- 完整的机器人设计意味着需要在大规模异构设计空间上进行推理，涵盖运动学（kinematics）、几何（geometry）和动力学（dynamics）参数。
- 这一问题的核心挑战在于：传统进化算法虽然可行但需要大量仿真时间；基于梯度的方法受限于表示；针对单一奖励的训练方法无法泛化。论文旨在开发一个统一模型，集设计生成、性能评估和控制于一体，提供"一站式"的机器人协同设计方案。

## 二、论文提出的方法论
- 核心思想：将机器人协同设计问题重构为一个统一的条件扩散生成问题。作者认为，与其训练一个专门针对某种奖励的设计优化器，不如训练一个通用的、奖励无关的动力学模型，在推理时再通过梯度引导实现特定奖励的优化。
- RoboToken：一种统一的机器人表示与token化方案，能表征任意铰接式机器人的本体（embodiment）、状态和动作，其设计目标包括：
  - 完整性（Complete）：涵盖本体token（links、fixed joints、sliding/rotating joints、ball joints、motors）和动力学token（状态与动作），每个token是连续值向量。
  - 灵活性（Flexible）：支持可变数量的token表征任意连接关系；通过ID引用来支持异构状态/动作空间和被动关节（如Cassie腿部机构）。
  - 一致性（Consistent）：预处理阶段自动规范变换约定、拆分惯性张量、折叠冗余的坐标偏移，减少网络学习负担。
  - 可扩展性（Extensible）：可以方便地增加新的token类型，例如将目标末端执行器位姿作为条件token。
  - 可优化性（Optimizable）：相比MJCF文本和自回归LLM，连续值的token化表示天然支持全局控制和端到端梯度回传。
- Transformer Transformer架构：基于扩散Transformer（DiT）的架构，在单一模型中通过不同的掩码建模方案同时充当生成器、评论家和控制器：
  - 运动到机器人生成（Motion-to-Robot Optimization）：以目标运动为条件，同时扩散本体token和动力学token，非自回归地预测整个时间轨迹，避免自回归误差累积。通过运行n个平行扩散过程并用奖励函数对候选排序，得到零阶优化器。
  - 跨本体控制（Cross-Embodiment Control）：以本体token、当前状态和目标运动为条件，预测专家动作，实现具身感知的全身体控制。
  - 训练细节：对每个token类型学习线性投影到DiT隐空间，加入token ID的嵌入；使用DDIM调度器；训练时随机或连续子采样8个时间步；由于领域具有SE(2)等变性（受重力影响，非SE(3)），应用平面变换增强。
- Dynamics Self-Guidance：这是论文的核心方法创新。在扩散过程的每一步，模型预测噪声并去噪到上一步；由于每一步是可微的，可以将可微奖励函数对embodiment token求梯度作为引导信号（类似分类器引导的DDIM），将模型"奖励无关"的动力学预测转化为"奖励特定"的价值预测，从而引导扩散过程生成高价值设计。该方法无需训练额外的动力学模型或可微仿真器。
- 数据收集与生成：
  - 使用UMI夹具扩展（基于ARKit）收集76条真实运动轨迹（56训练、20验证），包括投掷、拧螺丝、开抽屉、擦洗等技能，以及UMI双臂洗碗演示。
  - 设计了三个不同侧重点的设计空间：固定基座机械臂（运动学设计）、四足操控机器人（动力学控制）、移动双手机器人（任务复杂度）。
  - 控制策略：非腿式机器人使用Mink差分逆运动学求解器（DiffIK）；腿式机器人使用强化学习（PPO）训练全身控制器（WBC），每种离散设计变体训练一个专家策略（128个RL专家），连续变体作为策略观测。

## 六、论文的主要结论与发现
- RoboToken能够统一表示不同机器人本体空间：token序列长度从28到101，覆盖质量、自由度跨度极大的各类机器人。
- Transformer Transformer能对未见奖励函数和未见目标轨迹实现零样本设计优化：在所有三个设计空间上均优于CMA-ES基线，优化速度快若干数量级（如ViperX单轨迹优化0.5秒 vs CMA-ES 47.5秒；双臂多轨迹20.7秒 vs CMA-ES约3.2小时）。
- 扩散生成具有多样性：改变目标轨迹或奖励函数会系统地改变生成设计的分布；同一奖励下也能产生多样候选设计。
- 扩散组合（Diffusion Composition）实现了零样本多轨迹优化：一次优化可生成适配26条轨迹的通用设计，而CMA-ES的时间随轨迹数量线性增长。
- 增加测试时采样种子数（test-time compute）能够提升设计奖励，在所有设计空间和奖励函数中一致成立。
- Dynamics Self-Guidance与Zeroth Order互为替代品：当采样预算有限（如单样本）时，引导方法优势显著；当采样预算充足时，零阶排序可以弥补差距。引导的价值在于样本昂贵时（更大模型、更长episode、交互式使用）。
- 同一模型可以直接控制其生成的机器人（跨本体控制），虽然存在一些离群embodiment，但总体与专家控制器性能呈正相关（Pearson r = 0.53）。
- 实物验证结果：优化后的ALOHA设计使布料展开甩动任务的跟踪误差降低73%（13.0cm→3.5cm），最大关节速度降低30%（2.57→1.82 rad/s），同时设计了倒挂式臂装以实现更高效的"腋下甩动"而非"过顶甩动"。

## 七、优点
- 统一的机器人表示（RoboToken）是重要贡献：设计上兼顾完整性、灵活性、一致性、可扩展性、可优化性，解决了异质机器人在同一框架下表示的难题。
- 统一的架构（一个DiT同时充当生成器、评论家和控制器）将传统上需要多个模型、多个阶段、多种目标函数的协同设计流程压缩为一个GPU可并行化的扩散过程，极大简化了优化流程。
- 奖励无关的动力学建模 + 推理时自引导是该方法的理论亮点：模型不依赖特定奖励函数训练，而是作为一个通用动力学模型，通过Dynamics Self-Guidance在推理时引导生成，这赋予其零样本适应任意可微奖励的能力。
- 非自回归的时间推理方式开辟了第二维度并行化：相比CMA-ES需要串行跑完整仿真，模型可仅用8个时间步就推理长时程动力学，极大加速了设计评估。
- 面向真实世界的验证：不仅做了仿真实验，还制作了实机ALOHA平台，证明了方法对未建模/错误建模动力学（气动阻力、布料摩擦、重力影响等）的鲁棒性。
- 消融实验设计得当，如大小模型对比、Zeroth Order与DGS的替代关系、测试时计算扩展趋势等，有助于深入理解模型行为。
- 作者有较好的可重复性意识，附录提供了详细的RoboToken schema、超参数、奖励定义、数据生成细节和额外的指标表格。

## 八、不足与局限
- RoboToken的几何表示仅限于primitive-based（基本几何体），无法处理复杂形状（mesh）、场景/物体信息和触觉信息；论文在Limitations中明确承认了这一限制。
- 奖励函数的适用范围有限：仅覆盖基于embodiment、状态和控制的奖励，不涉及结构强度、外观、成本等其他工程约束。
- 扩散模型的固有局限：生成的designs只能落在训练分布内，无法外推——例如四足数据训练无法生成六足机器人；link长度也不能超出训练范围。这限制了模型发现全新形态的能力。
- 预测精度问题：对于四足设计空间，模型预测奖励与真实仿真奖励之间的相关性较低（论文图7显示），因为需要推理学习式全身控制器在不连续接触和摔倒风险下的行为，这限制了DGS在该空间的引导效果。
- 跨本体控制仍然不完美：论文承认存在离群embodiment，学习到的控制器与专家策略之间存在性能差距（追踪误差5.9–6.6cm vs oracle 4.8cm），完全替代128个RL专家还需进一步改进。
- 数据生成开销巨大：训练128个RL专家策略花费大量计算资源（每个16小时A100），且需要使用CMA-ES对ViperX/ALOHA设计空间的数据进行"增强预处理"才能获得合理的训练数据质量；这本身构成了对进化算法的隐性依赖。
- 缺乏与更广泛方法的定量对比：没有与DiffuseBot、Dynamics-guided diffusion、BodyGen等最新协同设计方法进行直接benchmark对比。
- 训练详情不够透明：论文未充分披露Transformer Transformer模型本身的训练GPU数量/型号、总训练时间、能耗等关键算力信息，降低了可复现性和资源可评估性。
- 多轨迹优化依赖diffusion composition作为近似方法，论文未深入分析组合推理的理论性质或失败模式。
- 测试时计算扩展存在上限：论文观察到引导设计性能并不总是随着更多优化时间而稳健提升，需要更好的推理方案来改善。
