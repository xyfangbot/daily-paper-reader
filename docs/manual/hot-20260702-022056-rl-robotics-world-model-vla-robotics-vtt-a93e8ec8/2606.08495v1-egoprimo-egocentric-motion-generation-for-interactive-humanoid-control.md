## 摘要
人形机器人需要能够适应场景上下文、任务要求和用户意图的全身运动。运动跟踪可以复现指定轨迹，而人形机器人视觉-语言-动作系统提供了语义接口，但两者均未能为广泛全身行为提供可扩展且交互式的先验。我们提出EgoPriMo（面向人形机器人的自我中心运动先验），这是一个统一框架，通过学习人类自我中心演示中的先验知识。给定自我中心观测和文本提示，EgoPriMo能够重建、生成并预测基于SMPL的全身运动。语言被用作高层控制信号，而非完整的运动规范。EgoPriMo的核心是一个三流DiT（三重扩散Transformer），它联合建模身体动力学、自我中心视觉上下文和文本；任务条件掩码通过同一检查点处理不同任务和缺失模态的数据。在Nymeria和EgoExo4D上的实验表明，单个检查点在自我中心运动生成上优于UniEgoMotion，同时支持重建和预测；生成的SMPL运动可由宇树科技人形机器人控制器执行。这些结果表明了一条从可扩展的自我中心观测到可泛化且交互式人形运动先验的实用路径。

## Abstract
Humanoid robots require whole-body motions that adapt to scene context, task requirements, and user intent. Motion tracking reproduces specified trajectories, and humanoid vision-language-action systems provide semantic interfaces, but neither offers a scalable and interactive prior for broad full-body behavior. We introduce EgoPriMo (Egocentric Motion Prior for Humanoid Robots), a unified framework that learns such priors from egocentric human demonstrations. Given egocentric observations and a text prompt, EgoPriMo reconstructs, generates, and forecasts SMPL-based full-body motion. Language is used as a high-level control signal rather than a complete motion specification. At the core of EgoPriMo is a Triple-stream DiT that jointly models body dynamics, egocentric visual context, and text; task-conditioning masks route different tasks and missing-modality data through the same checkpoint. Experiments on Nymeria and EgoExo4D show that one checkpoint improves egocentric motion generation over UniEgoMotion while supporting reconstruction and forecasting; the generated SMPL motions can also be executed by a Unitree humanoid controller. These results indicate a practical path from scalable egocentric observations to generalizable and interactive humanoid motion priors.

## 二、论文提出的方法论
- **核心思想**：提出 EgoPriMo 框架，接收自我中心观测（egocentric video）和文本提示，输出基于 SMPL 的全身运动序列。语言仅提供高层控制（如意图、时机、交互风格），视觉观测提供场景具体的接地信息。该框架统一支持三种任务：**重建**（从完整观测恢复运动）、**生成**（从部分观测和文本生成完整运动）、**预测**（根据过去观测预测未来运动）。
- **关键技术细节**：
  1. **Triple-stream DiT（三流扩散Transformer）**：分别对**身体运动 token**、**自我中心图像 token** 和**文本 token** 进行独立流处理，每个流拥有自己的输入投影、QKV投影、输出投影和MLP。通过**联合注意力**进行跨模态融合，运动 token 可查询图像和文本 token。之后进入单流 DiT 块进行更深层融合。使用 RoPE 编码运动和图像 token 的时间顺序。
  2. **任务条件掩码**：通过改变可见模态（图像、文本、辅助位姿线索）和时间跨度来统一不同任务。缺失模态由学习到的掩码 token 替代。同一检查点无需任务专用头即可处理重建、生成、预测。
  3. **流匹配（Flow Matching）目标**：训练条件速度场 v_θ，目标函数 L 计算预测速度与真实速度的加权 MSE，权重由任务掩码 w_t 和填充掩码 p_t 控制。
  4. **异构数据训练**：混合使用 Nymeria（自我中心视频+SMPL+文本）、HumanML3D（文本-运动对）和 EgoExo4D（自我中心运动数据），缺失模态用掩码 token 替代。

## 六、论文的主要结论与发现
1. **单一检查点可统一多项自我中心运动任务**：EgoPriMo 在重建、生成、预测三项任务上均优于或接近 UniEgoMotion，尤其在几何精度（MPJPE）、物理合理性（空中比率、脚滑）和语义相似性上显著领先。
2. **Triple-stream DiT 优于单流拼接**：在相同数据混合下，三流架构相比单流拼接降低了 MPJPE 和脚滑，物理合理性更好。
3. **异构数据训练提升泛化**：加入 HumanML3D 和 EgoExo4D 数据后，MPJPE 从 0.560m 降至 0.477m，空中比率和脚滑也明显改善。
4. **生成运动可用于真实人形机器人控制**：通过 Unitree 控制器，EgoPriMo 生成的 SMPL 参考运动可驱动机器人执行如踢球、挥手跳舞等动作。

## 七、优点
- **方法论创新**：提出三流 DiT 架构，分别处理身体运动、自我中心视觉和文本，保留模态特定表示后再融合，设计合理。
- **统一性与简洁性**：通过任务条件掩码，单个检查点支持三种不同任务，无需任务专用头，便于异质数据训练和部署。
- **可扩展性**：利用丰富的自我中心人类演示数据（低成本、易获取），而非依赖昂贵的动作捕捉或手摇遥操作。
- **物理合理性提升**：在脚滑、空中比率等指标上大幅优于基线，表明对接触和运动自然的建模更好。
- **实用性**：输出标准 SMPL 表示，可直接与现有机器人控制器对接，形成从感知到运动再到控制的完整流水线。

## 八、不足与局限
- **脚滑问题依然存在**：尽管比基线改善显著，但脚滑仍是主要物理伪影，表明接触建模有待加强。
- **语言交互评估有限**：仅通过提示词演示进行定性评估，缺乏系统化的语言指令变化、指代消解、多轮反馈等能力的定量测试。
- **机器人评估单一**：仅使用宇树科技的一种控制器和平台，未在多种人形机器人上验证泛化性，也未在真实环境中进行闭环策略测试（当前为开环运动参考）。
- **数据偏差与泛化风险**：训练数据主要来自 Nymeria（固定环境、实验室场景）和 EgoExo4D（可能有偏），对野外复杂环境（如拥挤人群、杂乱场景）的泛化能力未经充分验证。
- **长时程运动生成未深入评测**：虽然使用 240 帧（约 8 秒），但未评估更长持续时间或包含复杂交互行为的运动生成质量。
- **消融实验覆盖不全**：仅在生成任务上做架构和数据的消融，未在重建和预测任务上对比不同架构设计。
